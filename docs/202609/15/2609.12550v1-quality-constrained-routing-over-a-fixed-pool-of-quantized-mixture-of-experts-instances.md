## 摘要
量化混合专家（MoE）服务可以为一个基础模型保留多个预物化实例，但量化损伤会随请求和位宽的不同而剧烈变化。由于实例物化和副本数量会消耗内存并且需要缓慢的重配置，我们将其视为上游预置决策，并研究固定常驻池内的路由。在这一固定池边界内，我们在类别级期望质量退化预算和实测实例容量下，为每个请求进行路由，以最大化建模吞吐量。为了预测这种请求特定风险，我们引入 FWP（脆弱性加权困惑度），它由参考实例预填充时的提示 token 计算得到，并针对候选实例退化进行校准。FWP 的基础是一个精确的双专家亲和性–脆弱性分解，以及一个条件式多层 top-$k$ 展开，其偏置、交互、路由变化、可分离性和高阶项均保持显式。利用这些校准风险，一个窗口级线性规划产生有符号的约简奖励得分，在最优价格和原始可行平局分配下与 LP 最优解 KKT 一致。在 88 个扩展 Qwen 提示上，量化全部 6,144 个专家块的完整 W2、W3 和 W4 实例分别产生 $0.9437$、$0.1832$ 和 $0.0513$ 的平均 $Δ$NLL。在相同总体和 $τ=0.1513$ 下，FWP 分配达到 $1.284\times$ 的离线基于模型的乘数，而请求无关混合为 $1.253\times$，静态 W4 为 $1.000\times$，实现了 $2.5\%$ 的相对 FWP 增量增益。

## Abstract
Quantized Mixture-of-Experts (MoE) services can hold several pre-materialized instances of one base model, but quantization damage varies sharply across requests and bitwidths. Because instance materialization and replica counts consume memory and require slow reconfiguration, we treat them as upstream provisioning decisions and study routing within a fixed resident pool. Within this fixed-pool boundary, we route each request to maximize modeled throughput under a class-level expected quality-degradation budget and measured instance capacities. To predict this request-specific risk, we introduce FWP (Fragility-Weighted Perplexity), computed from prompt tokens on a reference-instance prefill and calibrated to candidate-instance degradation. Underlying FWP is an exact two-expert affinity--fragility decomposition and a conditional multi-layer top-$k$ expansion whose bias, interaction, route-change, separability, and higher-order terms remain explicit. Using these calibrated risks, a window-level linear program yields a signed reduced-reward score that is KKT-consistent with the LP optimum under optimal prices and primal-feasible tie allocation. On 88 extended Qwen prompts, complete W2, W3, and W4 instances quantizing all 6,144 expert blocks incur mean $Δ$NLL of $0.9437$, $0.1832$, and $0.0513$. Under the same population and $τ=0.1513$, FWP allocation reaches a $1.284\times$ offline model-based multiplier versus $1.253\times$ for request-agnostic mixing and $1.000\times$ for static W4, an incremental $2.5\%$ relative FWP gain.

- **两时间尺度边界**：实例物化与副本数选择属于上游预置决策（消耗内存、需缓慢重配置），在路由周期内不可变；论文只研究**固定常驻池内**的内层路由问题。
- **核心问题**：服务系统应如何在固定池的多个量化实例之间，为每个请求路由，以在类别级质量退化预算与实测实例容量下最大化吞吐？
- **意义**：与 DeepSeek-V3 每十分钟调整冗余专家、请求分发在更快时间尺度的生产实践一致；为质量约束的 MoE 服务提供可部署的路由方案。

## 2. 方法论

### 核心思想
- 用**专家脆弱性**（专家对量化的敏感度）与**专家亲和性**（请求对该专家的激活强度）两个正交量分解质量损失；通过请求级风险信号 FWP 与窗口级 LP 将风险转化为分配决策。

### 关键技术细节
- **精确双专家亲和–脆弱分解**：在双专家 top-1 MoE 模型下，ΔQ(b) = α·Δr(br) + (1−α)·Δc(bc)，亲和权重与内在脆弱函数严格分离。
- **居中噪声约简形式**：在零均值扰动下方差按 2^(−2b) 缩放，得到 ΔQ(b) = α·cr·2^(−2br) + (1−α)·cc·2^(−2bc) + r(b)，余项满足 |r(b)| ≤ κ·Σ2^(−3bj)；另给出有偏噪声的 2^(−b) 分支（带符号系数）。
- **FWP（脆弱性加权困惑度）**：对非 padding 提示 token，以专家平均路由范数倒数归一化权重 wi(x)，对 token 级 NLL 加权：
  - ℓ_FWP(x; b) = (1/|Ip|) Σ wi(x)·(−log pb(xi|x<i))
  - **放大恒等式**：Δℓ_FWP − Δℓ = Cov_i(wi, di)，即 FWP 恰好当逆路由范数权重与 token 退化正协方差时放大平均退化。
- **窗口级 LP 与 KKT 一致分数**：
  - 目标：max Σ Lg·xga，约束含需求、容量、类别平均质量风险 Σ(bℓga − τg)·xga ≤ 0（带符号，允许低于预算的分配抵消高于预算的分配）。
  - 对偶得约简奖励：Rga = Lg − πa·sga − νg·(bℓga − τg)，加入配额跟踪项后为 Sga = β·dga + Rga。
  - **定理 3.2**：在最优价格与按原始最优流量比例分配平局时，分数与 LP 最优解 KKT 一致；任意贪心平局规则仅保证平稳性，不保证原始可行。
- **算法流程**：离线锁定池与校准风险映射 → 在线对请求计算参考实例 FWP → 对每个端点算分数 → argmax 选择 → 若目标实例非参考实例需二次 prefill（KV 不跨量化实例复用）→ 每控制窗口更新价格。

  - 跨位宽预测（W2 预测 W3）仅达 Spearman 0.586、AUROC 0.747，应作为校准特征而非直接质量测量。
