## 摘要
量化混合专家（MoE）服务可以持有同一基础模型的若干预物化实例，但量化损伤会因请求和位宽的不同而剧烈变化。由于实例物化和副本数量会消耗内存且需要缓慢的重配置，我们将其视为上游供给决策，并研究固定常驻池内的路由。在这一固定池边界内，我们为每个请求进行路由，以在类别级期望质量退化预算和实测实例容量下最大化建模吞吐量。为了预测这种请求特定的风险，我们引入 FWP（脆弱性加权困惑度，Fragility-Weighted Perplexity），它由参考实例预填充上的提示令牌计算得到，并针对候选实例的退化进行校准。FWP 的基础是一个精确的双专家亲和性—脆弱性分解，以及一个条件式多层 top-$k$ 展开，其中偏置、交互、路由变化、可分离性和高阶项均保持显式。利用这些校准后的风险，窗口级线性规划产生一个带符号的约简奖励分数，该分数在最优价格和原始可行并列分配下与 LP 最优解 KKT 一致。在 88 个扩展 Qwen 提示上，量化全部 6,144 个专家块的完整 W2、W3 和 W4 实例分别带来 0.9437、0.1832 和 0.0513 的平均 ΔNLL。在相同总体和 τ=0.1513 下，FWP 分配达到 1.284× 的离线基于模型的倍率，而请求无关混合为 1.253×，静态 W4 为 1.000×，即 FWP 获得 2.5% 的相对增量收益。

## Abstract
Quantized Mixture-of-Experts (MoE) services can hold several pre-materialized instances of one base model, but quantization damage varies sharply across requests and bitwidths. Because instance materialization and replica counts consume memory and require slow reconfiguration, we treat them as upstream provisioning decisions and study routing within a fixed resident pool. Within this fixed-pool boundary, we route each request to maximize modeled throughput under a class-level expected quality-degradation budget and measured instance capacities. To predict this request-specific risk, we introduce FWP (Fragility-Weighted Perplexity), computed from prompt tokens on a reference-instance prefill and calibrated to candidate-instance degradation. Underlying FWP is an exact two-expert affinity--fragility decomposition and a conditional multi-layer top-$k$ expansion whose bias, interaction, route-change, separability, and higher-order terms remain explicit. Using these calibrated risks, a window-level linear program yields a signed reduced-reward score that is KKT-consistent with the LP optimum under optimal prices and primal-feasible tie allocation. On 88 extended Qwen prompts, complete W2, W3, and W4 instances quantizing all 6,144 expert blocks incur mean $Δ$NLL of $0.9437$, $0.1832$, and $0.0513$. Under the same population and $τ=0.1513$, FWP allocation reaches a $1.284\times$ offline model-based multiplier versus $1.253\times$ for request-agnostic mixing and $1.000\times$ for static W4, an incremental $2.5\%$ relative FWP gain.

## 2. 方法论

### 2.1 请求风险信号：FWP（脆弱性加权困惑度）

- 复用文献中"专家路由器范数变化 = 脆弱性指标"的思想：对请求 $x$ 的非 padding 提示 token 集合 $I_p(x)$，令 $\bar\Lambda_i(x)$ 为 token $i$ 激活专家的平均路由器范数，构造请求内归一化权重
  $w_i(x) = (\bar\Lambda_i(x)+\epsilon_w)^{-1} / \frac{1}{|I_p(x)|}\sum_j (\bar\Lambda_j(x)+\epsilon_w)^{-1}$，
  再定义 $\ell_{\text{FWP}}(x;b) = \frac{1}{|I_p(x)|}\sum_i w_i(x)\big(-\log p_b(x_i\mid x_{<i})\big)$。
- **在线流程**：在指定的**参考实例**上做一次 prompt prefill，得到原始 FWP 值；离线校准映射再结合提示长度、声明的类别特征，预测**候选实例**的退化。在线不使用同一未见请求的全精度分数。
- **代价**：若目标实例 ≠ 参考实例，因 KV 状态一般无法在不同量化实例间迁移，需执行并计费**第二次 prefill**。

### 2.2 理论基础（分层、显式声明适用边界）

- **双专家 top-1 稀疏 MoE 模型**（稀有专家质量 $\alpha<1/4$，边际 $0<m_r<m_c$）：得到**精确的亲和性—脆弱性分解**
  $\Delta Q(b) = \alpha\Delta_r(b_r) + (1-\alpha)\Delta_c(b_c)$——概率是亲和性权重，局部项是内在脆弱性函数，两者不可混同。
- **中心化噪声下的二阶约化形式**（定理 3.1）：$\Delta Q(b)=\alpha c_r 2^{-2b_r}+(1-\alpha)c_c 2^{-2b_c}+r(b)$，其中 $c_j=\frac12\ell''(m_j)v_j>0$，余项 $\le \kappa\sum_j 2^{-3b_j}$。**有偏/确定性量化**则是另一支 $2^{-b}$ 的**带符号**一阶项（引理 B.2），不能复用正的脆弱系数。
- **稀有专家更脆弱**（命题 B.2）：若 $0<m_r<m_c$ 且 $v_r\ge v_c$，则 $s_r>s_c$。经由路由器—边际链接假设（Assumption B.1）可得到 $s_j$ 被一个关于路由器边际代理的单调递减上界控制（命题 B.3），据此构造受限的结构化系数族用于消融。
- **多专家多层 top-k 桥接**（定理 B.2）：条件式分块泰勒展开，显式保留偏置项、交互项、可分离性残差、**路由翻转项**（$E_{\text{flip}}$）与三阶余项；需要 $\frac12\mathrm{tr}(H_{jj}\Sigma_j)=\rho_j(x)c_j+\epsilon_j(x)$ 才能还原亲和性—脆弱性代理。该桥接是**条件性的**，不是任意架构的定理。
- **请求内 FWP 放大恒等式**（命题 3.1）：
  $\Delta\ell^{\text{audit}}_{\text{FWP}}(x;b)-\Delta\ell(x;b)=\mathrm{Cov}_{i\in I_p(x)}(w_i(x),d_i(x;b))$。
  即 FWP 相对普通 prompt 平均 NLL 的增益，精确等于"逆路由器范数权重"与"token 退化"的请求内协方差；为正时 FWP 放大退化信号。作者指出双专家 top-1 模型中权重退化为常数、协方差为零，因此该模型只能启发脆弱性、不能证明部署 FWP 的放大性。
