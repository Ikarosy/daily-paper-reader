## 摘要
近期的基础模型正朝着原生多模态视觉语言模型（VLM）方向发展，使 VLM 成为下一代基础模型的核心形态。然而，其大型语言主干导致高内存占用，并且自回归解码受内存带宽制约，这使得边缘部署十分困难。仅权重的训练后量化是一种实用方案，但将 VLM 推向极低比特位宽仍具挑战：现有免旋转方法在 2-3 比特下受离群值困扰，而基于旋转的方法虽提升精度，却带来额外运行时开销。我们提出 SPHQuant，一种面向 VLM 的免旋转球面仅权重量化框架。SPHQuant 不在笛卡尔坐标中直接量化权重，而是将每个 8 维权重向量分解为坐标符号、半径和一个正向单位方向。这种表示将离群值的幅度隔离到半径中，同时使方向保持有界且统计上规整。基于这一洞见，SPHQuant 为半径分配额外精度，以缓解离群值导致的精度下降。它进一步使用紧凑的正方向码本，并通过角度参数化微调码本条目，以保持单位球面约束。我们还设计了一个硬件友好的 GEMV 内核，使方向码本足够小以便共享内存查找，并高效打包半径比特。实验表明，SPHQuant 在性能上匹配当前最先进的极低比特量化方法，同时在 RTX A6000 上将解码吞吐量较 QTIP 提升 30.3%。代码将在 https://github.com/Pushazf/SPHQuant 发布。

## Abstract
Recent foundation models are moving toward native multimodal Vision-Language Models (VLMs), making VLMs a central form of next-generation foundation models. However, their large language backbones make edge deployment difficult due to high memory footprint and memory-bound autoregressive decoding. Weight-only post-training quantization is a practical solution, but pushing VLMs to extreme low bit-widths remains challenging: existing rotation-free methods suffer from outliers at 2-3 bits, while rotation-based methods improve accuracy at the cost of additional runtime overhead. We propose SPHQuant, a rotation-free spherical weight-only quantization framework for VLMs. Instead of quantizing weights directly in Cartesian coordinates, SPHQuant decomposes each 8D weight vector into coordinate signs, radius, and a positive unit direction. This representation isolates outlier magnitude into the radius while keeping directions bounded and statistically regular. Based on this insight, SPHQuant allocates extra precision to the radius to mitigate accuracy degradation induced by outliers. It further uses a compact positive-direction codebook and fine-tunes codebook entries through angular parameterization to preserve the unit-sphere constraint. We also design a hardware-friendly GEMV kernel that keeps the direction codebook small enough for shared-memory lookup and packs radial bits efficiently. Experiments show that SPHQuant matches the performance of state-of-the-art extreme low-bit quantization methods while improving decode throughput over QTIP by 30.3% on RTX A6000. Code will be released in https://github.com/Pushazf/SPHQuant.

# SPHQuant 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景趋势**：基础模型正从纯文本 LLM 走向原生多模态 VLM（如 Qwen3.5、Gemma4），VLM 成为下一代基础模型的核心形态，但语言主干主导了参数量存储与解码阶段的内存流量。
- **部署痛点**：十亿级参数需要大设备内存，自回归解码是 memory-bound，边缘部署（移动助手、端侧 OCR、文档理解、具身智能、实时视觉推理）需要低延迟、隐私保护、弱网依赖。
- **量化现状**：仅权重训练后量化（PTQ）是实用方案，4-bit 已广泛采用，但要把 VLM 压到 **2–3 bit** 以适配内存受限设备仍然困难：
  - 免旋转方法（如 ParoQuant 的成对 Givens 旋转）在 2–3 bit 因线性量化局限而精度骤降；
  - 基于旋转的方法（QTIP 的随机 Hadamard 非相干处理 + 网格编码量化）精度好，但引入额外推理算子开销；
  - 把离群权重保留为 FP16 可提精度，但需要硬件不友好的稀疏-稠密混合计算。
- **核心论点**：困难不仅来自位宽受限，更来自**权重被表示与量化的坐标系**。在笛卡尔坐标下，单个离群权重会撑大整组的量化范围，压低非离群权重的有效信息密度——这在 4-bit 尚可忍受，在 2–3 bit 极具破坏性。
- **整体含义**：论文提出一种**免旋转的球面坐标表示**，把离群幅度与有界方向解耦，从而在极低比特下同时兼顾精度与推理效率。

## 2. 方法论

### 2.1 核心思想
将每个 8 维权重向量从笛卡尔坐标变换到球面坐标，显式解耦**半径（承载离群幅度）**与**方向（落在单位球面上、统计规整）**，再对两者差异化分配比特。

### 2.2 关键技术与算法流程

- **球面分解**：对 `w ∈ R^8`，
  - 符号 `s = sign(w)`，取正卦限 `w+ = |w|`；
  - 半径 `r = ||w+||₂`；
  - 正单位方向 `d = w+ / max(r, ε)`，其中 `d ∈ S⁷₊`（8 维单位球正卦限）。
  - 重构：`ŵ = r̂ · s ⊙ d̂`。
- **两个支撑性经验观察**：
  1. **半径比原始权重更平滑**：以 99.9 分位/50 分位比值（tail ratio）衡量，各层半径分布显著比笛卡尔权重平滑（例：坐标从 1 增到 5，半径只翻倍）；
  2. **方向已接近均匀分布**：8D 向量分解出的角度分布与随机高斯（均匀单位方向）参考高度吻合，因此方向可用码本充分刻画。
- **符号分离与码本规模控制**：
  - 符号用 8 bit 精确存储且量化过程中不变；
  - 方向信息分配 `7B` bit，扣除 8 个符号位后，码本索引为 `K_dir = 7B − 8` bit，码本大小 `|C| = 2^(7B−8)`；
  - B=2 时码本仅 64 条目、1 KiB（FP16），可放入共享内存；若用带符号码本则需 256 KiB（28 倍），超出 GPU 共享内存实际可用规模。
- **方向码本初始化与指派**：以正比于 `r_i²` 的概率采样归一化方向（高幅值向量影响更大）做**球面 k-means**；按余弦相似度 `z_i = argmax_k d_iᵀ c_k` 指派索引。
- **半径的预量化拟合**：不直接量化原始 `r_i`，而先沿指派方向做最小二乘投影 `˜r_i = ⟨(w_i)+, c_{z_i}⟩`（因 `c` 是单位向量，闭式解即内积），再对其做**组内均匀量化**（每组 128 个标量权重 = 16 个 8D 向量）。
- **离群感知的径向比特分配**：把额外比特全部给半径。为证明增益源自"给对地方"而非"多用比特"，设计**匹配平均比特的控制实验**（见第 3 节）。
- **角度参数化码本微调**：
  - 直接用欧氏梯度更新 8D 单位向量会含切向分量，需投影或重归一化，会丢弃有效更新、降低优化效率；
  - 改用 7 个超球角 `θ₁..θ₇` 参数化码本向量（`[c]₁=cosθ₁`，中间项为连乘 sin 与 cos，`[c]₈=∏sinθ_j`），并通过 `θ_j = ε + (π/2 − 2ε)·σ(φ_j)` 由无约束的角 logits `φ` 映射，**构造上即保证**落在 `S⁷₊`。
- **层间重构优化**：维护两条激活流（全精度 teacher `x_fp` 与已量化层产生的 student `x_q`），目标为
  `min_{ρ,φ} E[ ||F_l^SPH(x_q; ρ, φ) − F_l^FP(x_fp)||₂² ]`；
  半径用 `r = softplus(ρ)` 保证正值，配合 V-bit 组量化与 STE。码本索引在初始化后固定，微调只移动角度与半径。
- **硬件友好 GEMV 内核**：
  - 每个 8D 向量打包为一个 **16-bit 基础字**：低 8 位符号、中间 6 位方向索引、高 2 位半径低位；
  - 每 128 权重组（16 个向量）**额外存一个 32-bit 字**，打包全部 16 个向量的额外 2 位半径 → 字对齐、合并访存；
  - 64 条目方向码本（1 KiB）预载入共享内存并以转置布局减少 bank 冲突；
  - **融合**半径反量化、方向查表、符号恢复、与 fp16 激活的乘加（fp32 累加），避免把反量化权重写回全局内存；
  - 线程映射：每 block 256 线程、计算 8 个输出通道，每线程处理 32 个 fp16 激活（4 个 8D 向量），用 half2 向量化 + warp shuffle/共享内存归约。

## 6. 主要结论与发现

- **核心结论**：在 2–3 bit 极低比特区间，**坐标系选择比量化算法本身更关键**。把权重从笛卡尔坐标搬到球面坐标后，离群幅度被隔离到半径标量上，方向分量统计规整且接近均匀分布，从而使"幅度用少量比特精确保留 + 方向用码本刻画"成为可行策略。
- **精度表现**：SPHQuant 在 2-bit / 3-bit 设置下于 MMMU_val、TextVQA、ScienceQA、RealWorldQA、MMStar 上普遍优于 RTN、AWQ、MBQ、ParoQuant、QTIP，且明显缩小与 BF16 上界的差距；在 Qwen3.5-9B 的 thinking 模式 MMMU-Pro 长推理评测中，精度保持优势更突出，说明该方法对**长链推理的误差累积**更具鲁棒性。附录中与 PVQ、PCDVQ 的对比同样支持这一结论。
- **比特分配有效性**：匹配平均比特的控制实验（图 4）显示，把额外比特倾斜给半径所带来的重构损失下降，来自"给对了位置"而非"总比特更多"；表 4 的径向/方向消融进一步验证方向码本在达到一定规模后收益饱和，而半径精度是瓶颈。
- **微调策略**：角度参数化微调（表 6、图 5）优于直接对 8D 单位向量做欧氏梯度更新、也优于只微调半径或不微调，原因在于角度参数化天然满足单位球约束，避免了投影/重归一化造成的有效更新损失。
- **维度选择**：4D/8D/16D 对比（表 7）显示 8D 是精度与码本存储（1 KiB、可驻留共享内存）之间的较优折中。
- **效率表现**：16-bit 基础字 + 每 128 权重一个 32-bit 附加字的打包格式实现了字对齐访存；融合式 GEMV 内核避免反量化权重回写全局内存。表 10/11 显示在 RTX 4090 24GB 上显存占用大幅下降、吞吐相对 fp16 基线具备竞争力，说明球面表示并未以显著的推理开销换取精度。
- **成本可控**：在与 QTIP、ParoQuant 对齐的量化成本下（6 小时、单卡 RTX PRO 6000），SPHQuant 取得更好精度，表明其收益并非靠更大算力预算堆出来。

## 7. 局限性与未来方向

- **分组与码本的耦合**：方法固定以 8 维为一组、每组 128 标量权重，码本共享粒度（每层/每组）与组大小的敏感性探讨有限，换到其他硬件位宽或更细粒度分组时是否仍最优尚不清楚。
- **未触及激活量化**：论文聚焦仅权重 PTQ（W2A16/W3A16），激活仍为 fp16，因此对激活主导的显存与带宽瓶颈无直接帮助；W4A4 或 W2A8 等联合量化场景下的表现未知。
- **端侧落地缺口**：吞吐与显存实验基于桌面 GPU，缺少移动 NPU、ARM CPU 或专用加速器上的实测，球面解码（查表 + 符号恢复）在弱 SIMD/NPU 上的适配性需要进一步验证。
- **极低比特与超大规模**：未报告 1.5-bit 及以下的结果，也未验证 30B 以上稠密模型或更大 MoE 上的可扩展性；Gemma4-26B-A4B 上对比基线不完整，跨架构结论仍需补强。
- **潜在方向**：将球面分解与激活量化、KV cache 量化结合；探索自适应分组/自适应码本规模；把码本学习与半径比特分配联合优化；以及在真实端侧设备上实现并评测该 GEMV 内核。
