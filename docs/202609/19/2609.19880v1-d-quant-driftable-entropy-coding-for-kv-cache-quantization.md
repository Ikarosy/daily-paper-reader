## 摘要
KV 缓存已成为部署 LLM 的主要瓶颈，因为其内存占用随序列长度和批大小线性增长，给内存容量和带宽带来巨大压力。在各种 KV 缓存压缩技术中，量化因其有效性和易于部署而尤其具有吸引力。然而，大多数现有方法依赖固定位宽量化，其中 $b$ 比特表示本质上只能提供 $2^b$ 个量化级别。随着位宽降低，可用级别数量呈指数级减少，导致严重的信息丢失和性能迅速下降。我们进一步观察到，固定位宽量化未能利用 KV 缓存高度非均匀的分布。经过旋转和归一化后，KV 值近似服从正态分布，大多数值集中在中心附近，只有一小部分出现在尾部。然而，固定位宽编码对频繁出现的符号和稀有符号分配相同数量的比特。熵编码通过为频繁符号分配较短的码字、为稀有符号分配较长的码字，自然地利用这种非均匀性，从而显著减少表示所需的平均比特数。然而，其变长输出不适合高度并行的注意力内核，因为高效的解量化和计算依赖规则的内存布局和固定步长访问。为弥合这一差距，我们提出 \textbf{D-Quant}，一种灵活的 KV 缓存量化框架，它引入 \textbf{漂移} 机制，将每个 token 的熵编码表示转换为固定大小的比特流，从而在注意力内核中实现规则的内存访问和并行解量化。

## Abstract
The KV cache has become a major bottleneck in deploying LLMs, as its memory footprint grows linearly with sequence length and batch size, imposing substantial pressure on both memory capacity and bandwidth. Among various KV cache compression techniques, quantization is particularly attractive due to its effectiveness and ease of deployment. However, most existing methods rely on fixed-width quantization, where a $b$ bit representation is inherently limited to $2^b$ quantization levels. As the bit width decreases, the number of available levels shrinks exponentially, leading to severe information loss and rapid performance degradation. We further observe that fixed-width quantization fails to exploit the highly non-uniform distribution of KV cache. After rotation and normalization, KV values approximately follow a normal distribution, with most values concentrated near the center and only a small fraction appearing in the tails. Nevertheless, fixed-width coding allocates the same number of bits to frequent and rare symbols. Entropy coding naturally exploits such non-uniformity by assigning shorter codewords to frequent symbols and longer ones to rare symbols, substantially reducing the average number of bits required for representation. However, its variable-length output is not suited to highly parallel attention kernels, where efficient dequantization and computation rely on regular memory layouts and fixed-stride accesses. To bridge this gap, we propose \textbf{D-Quant}, a flexible KV cache quantization framework that introduces a \textbf{drift} mechanism to convert entropy-coded representations of each token into fixed-size bitstreams, enabling regular memory access and parallel dequantization within attention kernels.

# D-Quant 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景瓶颈**：KV cache 的显存占用随序列长度和批量大小线性增长，与模型权重的固定尺寸不同，已成为长上下文 LLM 部署在显存容量与带宽上的主要瓶颈。
- **现有方案**：量化因有效且易于部署而成为主流压缩手段（KIVI、KVQuant、QuaRot、OScaR 等），但它们普遍采用**固定位宽量化**，即每个值用 $b$ 比特表示，天然只能提供 $2^b$ 个重建级别。
- **两大缺陷**：
  - 位宽降低时可用量化级数呈指数级收缩，信息损失严重、性能快速退化；
  - 固定位宽编码对"高频符号"和"稀有符号"分配同样的比特数，**无法利用 KV 分布的非均匀性**。作者观察到经过旋转（Hadamard）与去均值等预处理后，KV 值近似服从正态分布，绝大多数值集中在中心，只有极少数落在尾部。
- **熵编码的机遇与障碍**：熵编码（如 rANS）通过给高频符号短码、低频符号长码可显著降低平均码长，但**输出是变长的**，与注意力核所依赖的规则内存布局、固定步长访问、高并行反量化不兼容。
- **整体含义**：论文提出 D-Quant，用"漂移（drift）"机制把每个 token 的变长熵编码表示压成**固定字节长度的容器**，从而在保留熵编码压缩收益的同时恢复规则访存，使低比特 KV cache 量化在"压缩率—可部署性"之间取得更好的折中。

## 2. 方法论

### 2.1 核心思想
- 将量化从"固定比特宽度 + 固定分组"范式，转变为"**固定存储预算 + 可变量化级数 + 熵编码**"范式：存储预算约束的是**总编码速率**，而不再约束量化级数。
- 每条 stream（一个 token 的 Key 或 Value，共 $n$ 个值）编码进一个固定 $C$ 字节的容器，使 KV cache 保持定长记录的规则数组，地址可由 token 索引直接算出，无需偏移表或动态分配器。

### 2.2 关键技术细节

- **预处理**：
  - 对每个注意力头施加 Hadamard 旋转（Value 侧可离线折叠进投影权重；Key 侧因与 RoPE 不可交换需在线执行）；
  - Key 额外去除**窗口化通道均值**（token 级标量 offset 无法捕捉通道均值），使分布更接近标准正态；
  - 采用 token 级仿射量化 $\hat{x}_i = o + s\,m_i$，$s=(\max(x)-\min(x))/(M-1)$，$o=\min(x)$。
- **熵编码（rANS）**：给定精度 $p=8$，符号 $m$ 的频率 $f_m$、累积频率 $c_m$，编解码通过整数状态更新完成；解码时 $z=x \bmod 2^p$ 索引一个 256 项查找表，表项同时存重建值与状态更新信息，**熵解码与反量化共用一次查表**。由于 rANS 逆序解码，stream 需反向编码以恢复原始顺序。
- **免校准概率模型**：由于旋转+去均值后 KV 近似标准正态，概率模型**直接由标准正态分布（结合高斯次序统计量）解析导出**，不需要任何校准数据；又因仿射归一化位置的不变性，同一概率表可跨 token、跨层共享。
- **漂移机制（Drift）**：变长编码可能超出预算，作者不降低量化级数，而是求解长度约束下的分配问题：
  - 目标：$\min \sum_i (x_i-(o+sm_i))^2$，约束 $\sum_i r(m_i) \le B$，其中 $B=8C-\sigma$（$\sigma$ 为熵编码器终止状态开销）；
  - 用拉格朗日形式 $\min \sum_i [D_i(m_i)+\lambda r(m_i)]$，对固定 $\lambda$ 各值可独立优化（可分离），再用**二分法**搜索满足码长约束的乘子；实际二分的是 $\log_2\lambda$（约 12 次迭代）以保证动态范围下收敛稳定；
  - 直觉：只有少数落在高代价符号上的值"漂移"到邻近的低代价符号，而非全局统一降精度。
- **实用精化**：
  - K/V 独立配置容器与级数（Key 对量化更敏感，因为误差经 softmax 指数放大；Value 误差在 softmax 之后被注意力权重聚合）；
  - **分布锐化**：漂移使最终编码分布比解析模型更集中，故用 $p'_m \propto p_m^{\alpha}$（$\alpha=1.4$，全局统一）构建熵表。
- **核实现（Kernels）**：
  - **编码**：每个 stream 分配一个 warp，值常驻片上，避免物化 $n\times M$ 失真矩阵；失真在线重算，码长用 warp 级规约；仿射重拟合与 rANS 编码在同一 warp 内完成。
  - **解码**：以 **token 为中心**组织（一个线程块拥有一批 token，每条 stream 只解一次），warp 按通道而非按 query head 切分累加器；仿射变换折叠进注意力收缩运算，解码级别可直接参与计算而无需显式反量化或物化 BF16 KV cache。

### 2.3 算法流程（文字版）
编码一条 stream：计算预算 $B$ → 拟合 min-max 尺度 → 漂移求解符号分配 → 最小二乘重拟合 scale/offset → 舍入到 FP16 → 在 FP16 网格上再漂移一次（保证编码器与解码器优化的是同一重建网格）→ rANS 编码并返回。解码：读入终止状态 → 每次用状态低 8 位查表得到重建级别与状态更新参数 → 状态不足时补充字节 → 将级别直接喂给注意力计算。

## 6. 主要结论与发现

- **精度**：2.26 BPV 下 D-Quant 在 RULER 上取得 86.50（Qwen3-8B）与 88.94（Llama-3.1-8B），接近 BF16 的 87.31 / 89.69，显著优于所有低比特基线；长上下文优势更明显，128K 时为 70.92 / 74.65，而最强基线仅 57.14 / 66.15。
- **更低预算仍可用**：1.96 BPV 时 RULER 平均仍达 85.21 / 87.26，超过所有使用更多存储的基线，说明比特预算与量化级数解耦带来了更灵活的存储—精度权衡。
- **效率**：8K 提示下 BF16 在批量 64 即 OOM，D-Quant 可扩展到批量 128、峰值仅 49.4 GiB；64K 解码时 KV cache 显存降低约 **7×**；最大可行批量下吞吐 563.6 vs 159.5 tokens/s，提升至多 **3.5×**。
- **机制性发现**：
  - 8 级 Key / 6 级 Value 是较优工作点，级数再增大将迫使漂移频繁发生反而损害性能；
  - 存储预算增大持续逼近 BF16，收益逐渐饱和；
  - Key 适度多分配预算更优（但过度倾斜会伤害 Value 表示）；
  - 漂移是**稀疏且局部**的：仅 0.75% 的 Key 符号和 5.00% 的 Value 符号被改动，且**没有任何符号移动超过一个重建级别**；
  - 免校准解析模型仅带来 0.0045 / 0.0039 bit/value 的额外开销；
  - 等存储下 D-Quant 的 KL 散度约为固定位宽的一半（2.26× / 2.00×），固定位宽要追平需多花 0.234 / 0.267 bit/value。

## 7. 优点

- **问题洞察精准**：明确指出固定位宽量化"量化级数被位宽绑定"这一根本限制，并用实验（表 1、表 2）量化了旋转/去均值后的分布规律、编码增益与免校准可行性。
- **方法设计巧妙**：以"固定字节容器 + 长度约束下的拉格朗日/二分漂移"同时满足压缩率与规则访存，且漂移是稀疏局部调整而非全局降精度，避免了大字母表的优势被浪费。
- **免校准**：概率模型直接由标准正态解析导出，不需要校准数据集，部署友好；概率表可跨 token/层共享。
- **软硬件协同**：warp-per-stream 的编码实现避免物化失真矩阵；token 中心的解码组织避免多头重复解码；仿射折叠进注意力收缩，省去显式反量化与 BF16 KV 物化；查表同时服务熵解码与重建。
- **实验说服力**：等存储受控对比 + 配对 bootstrap 置信区间，有效排除了"增益来自预处理或额外存储"的替代解释；配置全程统一，避免逐设置调参带来的不公平。
- **工程价值明确**：显存降低直接转化为更高服务容量与吞吐，对长上下文在线服务有实际意义。

## 8. 不足与局限

- **小批量下反而更慢**：熵解码引入额外计算，批量小时 D-Quant 吞吐低于 BF16，其收益依赖"显存受限"的部署场景（高批量或超长上下文），在算力受限而显存充裕的场景可能得不偿失。
- **编码端开销未量化**：漂移求解需多次二分与重算失真，论文只给了算法复杂度直觉与 warp 实现思路，未报告编码延迟/吞吐或相对基线编码成本，对预填充（prefill）阶段的影响未知。
- **依赖定制核**：固定容器、rANS 表、仿射折叠都需要专门 kernel 支持，未讨论与现有推理框架（如 vLLM/FlashAttention 生态）的集成成本与可移植性。
- **超参固定但可能非最优**：容器大小（331/231 字节）、级数（8/6）、锐化因子 $\alpha=1.4$、残差窗口 128 token 均为手工设定，跨模型/层/任务复用，缺少自动选择机制；论文也承认过度增大字母表会因漂移变频繁
