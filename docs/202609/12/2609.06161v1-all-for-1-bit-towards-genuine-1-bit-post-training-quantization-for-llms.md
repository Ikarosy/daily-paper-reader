## 摘要
大语言模型（LLMs）已取得显著进展，但其庞大的存储和内存带宽需求仍然阻碍高效部署。权值二值化是一种有前景的解决方案，但现有的基于二值化的训练后量化（PTQ）方法通常由于隐藏开销而远超名义上的 1 比特存储目标。为弥补这一差距，我们提出 All for 1-Bit（AF1），一个面向 LLMs 的真正 1 比特 PTQ 框架。AF1 包含两个互补组件：（1）零空间感知二值分解（NABF），通过 Hessian 感知的代理重参数化、零空间感知二值分解和仅尺度全局重建来改进二值重建；（2）分层 Shapley 分配（HiSA），利用分层 Shapley 敏感性分配结构容量。二者共同在 PTQ 设置下于严格的 1.0-BPW 预算内保持模型精度。在 LLaMA、Qwen 和 Gemma 系列上的实验表明，AF1 在困惑度和零样本准确率方面始终优于现有的基于二值化的 PTQ 方法。与 BF16 相比，AF1 在评估模型上平均实现 2.5 倍推理加速和超过 90% 的内存降低，为 LLMs 实现可部署的真正 1 比特压缩提供了切实可行的路径。可复现的代码见 https://github.com/Kishon-zzx/AF1。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

- **背景**：LLM 规模持续膨胀（如 LLaMA-3.1-405B、Qwen3.5-397B-A17B），BF16 精度下仅权重就需约 800GB 内存，加上 KV cache 与中间激活，部署成本极高。
- **核心矛盾**：权值二值化（1-bit）是降低存储与内存带宽的理想方案，但存在两条技术路线的困境：
  - **二值化 PTQ 方法**（BiLLM、ARB-LLM、STBLLM、HBLLM）：依赖显著权重掩码、分组缩放因子、位图、稀疏索引等辅助元数据，实际有效 BPW 常达 2–4 bit，远超名义 1-bit 目标。
  - **QAT 方法**（OneBit、LittleBit）：可实现真正 1-bit，但需大规模训练数据、长优化周期与大量算力。
- **两大技术瓶颈**：
  1. **单矩阵二值化范式**（W ≈ αB）表征能力有限，难以刻画 LLM 权重的复杂幅度分布与结构相关性；PTQ 仅有少量校准数据，离散重建的误差控制要求更严苛。
  2. **结构单元敏感度高度异质**：统一量化配置或固定结构预算无法匹配层与子模块的非均匀重要性，导致容量分配次优。
- **论文目标**：在 PTQ 设定下实现**真正的 1.0 有效 BPW**（针对目标线性权重），无需沉重元数据或昂贵重训练。

## 2. 论文提出的方法论

### 2.1 核心思想
AF1 由两个互补组件构成：
- **NABF（Null-space-Aware Binary Factorization）**：提升二值重建精度，吸收离散投影误差。
- **HiSA（Hierarchical Shapley Allocation）**：从全局交互视角分配严格受限的结构容量。

### 2.2 NABF 关键技术细节

**(1) Hessian 感知代理重参数化**
- 采用 K-FAC 启发的对角近似，定义输入重要性向量 `i_j = sqrt(E[x_j²])` 与输出重要性向量 `o_u = sqrt(E[g_u²])`（x 为输入激活，g 为输出梯度）。
- 重参数化：`W' = o ⊙ W ⊙ i^T`，将 Hessian 加权重建转化为代理空间中的 Frobenius 目标，使后续二值分解关注任务敏感通道。

**(2) 双因子二值分解**
- 将 W' 分解为两个二值符号矩阵与连续缩放向量的乘积：
  `W' ≈ (a ⊙ A±1 ⊙ m1^T)(m2 ⊙ B±1 ⊙ b^T)`
- 相比单矩阵二值化，双因子结构引入中间维度 r 条二值路径，可表达非秩一的幅度模式（附录 A.2.1 给出 2×2 反例证明其表征能力严格更强）。

**(3) 零空间感知二值 ADMM 分解**
- 沿用 DBF 的 ADMM-SVID 框架：固定一个因子，用 ADMM 求解连续代理，再经 SVID 投影回二值-缩放域。
- **核心创新**：SVID 投影产生残差 `E_A = Â - A_q`，实际扰动为 `E_A B`。若 E_A 落在固定因子 B 的近似左零空间中，则 `E_A B ≈ 0`。
- 构造近似零空间投影：对协方差矩阵 `C_B = BB^T` 做 SVD，按自适应残差能量截断（阈值 η=0.01）取尾部奇异向量 `Û`，得投影 `P_B = ÛÛ^T`，满足 `P_B B ≈ 0`。
- 定义零空间补偿目标 `A_target = Â - E_A P_B`，并通过列方向最小二乘闭式解将补偿吸收进中间缩放向量：
  `γ* = diag(A_q^T A_target) / diag(A_q^T A_q)`，更新 `m1 ← m1 ⊙ γ*`。
- 该操作不改变二值符号矩阵与推理计算图，零额外推理开销。

**(4) 仅尺度全局重建**
- 冻结所有二值符号矩阵，仅优化可学习缩放参数 `S = {a^(l), m^(l), b^(l)}`。
- 以全精度模型为教师，用 KL 散度对齐 logits 分布：
  `min_S E_X~D_cal [D_KL(softmax(z_T(X)) || softmax(z_Q(X;S)))]`
- 每层可训练参数量从 `O(d_out·r + r·d_in)` 降至 `O(d_out + r + d_in)`。

### 2.3 HiSA 关键技术细节

**(1) 层级粗粒度预算分配（Progressive Shapley）**
- 将层维度分配建模为结构容量博弈，参与者为各 Transformer 层，价值函数为端到端 NLL：
  `v_NLL(S) = E_{(x,t)~D}[-log p(x_{t+1} | x≤t; S)]`
- 沿随机排列 π 逐步将层从原始维度 `r_orig` 退化为代理维度 `r_proxy`，计算 NLL 增量作为边际贡献，蒙特卡洛平均得 `Φ_l`。
- 经温度控制 softmax 转为层预算：`B_l = B_total · exp(Φ_l/τ) / Σ_j exp(Φ_j/τ)`。

**(2) 块级细粒度分配（Dual-Sensitivity Shapley）**
- 区分两种互补失真：方向失真 `r_dir`（角度漂移，影响注意力匹配）与幅度失真 `r_mag`（相对激活能量偏移，影响残差流注入）。
- 使用单调累积误差 `Ê_c(S_t) = max(E_c(S_t), Ê_c(S_{t-1}))` 减少负边际，分别估计两类 Shapley 分数。
- MAD 稳健 Z-score 归一化后经 Sigmoid 映射，用 **Soft-OR** 融合：`v_base = 1 - (1-P_dir)(1-P_mag)`，避免任一失效模式被平均抑制。
- 尺寸感知敏感度密度分配：`b_i = B_l · (Σ|W_k|)(v_base/|W_i|+ε)^α / Σ_j|W_j|(v_base/|W_j|+ε)^α`，α 控制尺寸比例与敏感度密度的权衡。
- 最终预算经 `r_i = Round(b_i·d_out·d_in / (d_out+d_in))` 转为 NABF 的中间维度。

### 2.4 整体算法流程
1. 收集校准统计 → 2. HiSA 分配层/模块预算 → 3. 对每个目标线性算子执行 NABF → 4. 冻结二值符号矩阵 → 5. 仅尺度全局重建 → 6. 组装压缩模型。

## 6. 论文的主要结论与发现

- **性能优势**：在 2.5-bit 设置下，AF1 在全部模型上取得最优量化结果，相比最强基线 HBLLM 平均零样本准确率提升超 20%，WikiText2 PPL 降低超 90%。
- **真正 1-bit 可行性**：在严格 1.0 BPW 下，LLaMA-3-70B 达到 61.80 零样本准确率与 8.91 PPL，超越部分更高比特基线；Qwen3-14B-Instruct 以 39.3% 的 HBLLM 模型大小实现仅约 9% 的平均分差距。
- **效率收益**：相比 BF16 内存降低约 90%，相比 GPTQ-W4 降低约 68%；解码吞吐相比 BF16 提升约 2.5 倍。
- **PTQ 与 QAT 的桥接**：AF1 以 PTQ 级效率（5.9 GPU 小时）达到接近 QAT 的 PPL（11.20 vs OneBit 9.08、LittleBit 9.73），远优于 ARB-LLM 的 16.44。
- **组件互补性**：NABF 提供高保真二值重建，HiSA 将稀缺容量分配给敏感层与子模块，二者缺一不可。
- **失真模式互补**：方向与幅度失真捕获不同失效模式，Soft-OR 融合优于任一单失真（LLaMA-3-8B：22.18 vs 24.59/23.33）。
