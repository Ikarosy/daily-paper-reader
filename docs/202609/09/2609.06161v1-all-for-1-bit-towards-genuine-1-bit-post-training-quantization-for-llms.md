## 摘要
大语言模型（LLMs）取得了显著进展，但其巨大的存储和内存带宽需求仍阻碍着高效部署。权重二值化是一种有前景的解决方案，但现有的基于二值化的训练后量化（PTQ）方法由于隐藏开销，通常远超名义上的1比特存储目标。为解决这一差距，我们提出了All for 1-Bit（AF1），一个用于LLMs的真正1比特PTQ框架。AF1包含两个互补组件：（1）零空间感知二值分解（NABF），通过Hessian感知的替代重参数化、零空间感知的二值分解和仅缩放全局重构来改进二值重构；（2）层次Shapley分配（HiSA），利用层次Shapley敏感性分配结构容量。两者结合，在PTQ设置下严格1.0-BPW预算内保持了模型精度。在LLaMA、Qwen和Gemma系列上的实验表明，AF1在困惑度和零样本准确率上始终优于现有基于二值化的PTQ方法。与BF16相比，AF1在所评估模型上实现了平均2.5倍的推理加速和超过90%的内存缩减，为LLMs的可部署真正1比特压缩提供了一条实用路径。用于复现的代码可在https://github.com/Kishon-zzx/AF1获取。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

### 1. 核心问题与整体含义

- **研究动机与背景**：大语言模型（LLMs）在实际部署中面临巨大的存储和内存带宽压力，权重二值化（weight binarization）被认为是极具潜力的压缩方案。然而，现有的基于二值化的训练后量化（PTQ）方法存在一个根本性缺陷——它们的**有效存储位宽（effective BPW）远超名义上的1比特**。由于需要存储残差二值分量、尺度因子、群组位图、离群值索引等辅助元数据，实践中这些方法的端到端位宽往往落入2-4比特区间。
- **核心问题**：如何在PTQ设置下，真正达成严格1.0有效BPW的权重压缩，同时保持可接受的模型精度？文中指出现有方法失败的关键有二：
  - 单矩阵二值化范式表达能力不足，难以刻画LLM权重中复杂的数值分布与结构关联；
  - 模型不同层与子模块对二值化误差的敏感性高度不均，均匀或固定的结构预算分配无法匹配这种异质性。
- **本文回应**：提出AF1框架，通过消除隐藏开销、改进二值重构表达能力和引入交互感知的结构预算分配，在真实1.0 BPW预算下实现高精度LLM压缩，为可部署的真1比特推理提供了可行路径。

### 2. 方法论

AF1集成了两个互补的核心组件，整体架构如论文图2所示。

- **组件一：零空间感知二值分解（NABF）**，包含三个关键技术环节：
  - **Hessian感知的替代重参数化**：为避免对所有权重扰动等权对待，利用输入激活和输出梯度的二阶统计信息（K-FAC启发式对角近似），分别生成输入重要性向量与输出重要性向量，将原权重矩阵替换为Hessian加权后的替代空间，使分解重点聚焦在任务敏感通道上，从而将Hessian加权重构转换为替代空间上的Frobenius范数目标。
  - **零空间感知二值ADMM分解**：借鉴DBF的双因子二进制参数化结构，将替代权重分解为两个二值符号矩阵与多个连续缩放向量的乘积。在ADMM-SVID交替优化过程中，核心创新在于对离散投影残差进行零空间补偿：通过对固定因子的协方差矩阵进行SVD分解来构造近似零空间投影器，将残差中可补偿的分量引导至零空间方向，使残差经固定因子传播后近乎消失——该补偿可通过最小二乘的闭式解耦合进既有缩放向量，既不改变二值符号矩阵，也不增加任何推理时开销。
  - **仅缩放全局重构**：冻结全部二值符号矩阵后，只对连续缩放参数进行优化，以最小化压缩模型与原始全精度教师模型在校准集上的KL散度，实现全模型logits分布的对齐。
- **组件二：层次Shapley分配（HiSA）**，用于解决结构预算分配问题：
  - **层极粗粒度预算分配**：将各层视为合作博弈参与者，通过Monte Carlo排列采样，以端到端NLL变化为价值函数，用逐步降级方式估算每层的Shapley值，再通过温度控制的Softmax将总预算转换为各层预算。该方法天然具备交互感知特性，能够捕捉层间误差传播与累积效应。
  - **模块级细粒度分配**：在每个层内，对QKV等子模块进行逐步压缩，分别测量其输出相对参考输出的**方向失真**（余弦夹角漂移）与**量值失真**（相对能量偏移），分别估算两种失真下的Shapley边际贡献，经MAD稳健Z-score归一化后用Soft-OR规则融合两个失真模式，最终以尺寸感知的敏感性密度完成模块内分配，并将预算转换为NABF使用的中间维度。
- **公式/算法流程**（文字说明）：算法整体流程为：先在校准集上收集统计信息→执行HiSA分配并得到各子模块预算→将其转换为NABF所需中间秩→对每个目标算子执行NABF双因子二值分解→冻结二值矩阵→仅对缩放向量做全局KL对齐优化。

### 6. 主要结论与发现

- **结论一**：在2.5比特设置下（接近现有二值化PTQ基线的等价位宽），AF1在所有评测模型上零样本准确率与PPL均显著优于现有方法，相比最强基线HBLLM平均零样本准确率提升超过20%，WikiText2 PPL平均降低超过90%。

- 总体而言，NABF与HiSA互为补充：前者提供高保真的1比特分解结构，后者将稀缺的容量预算按交互敏感度精准配置到各层与各模块，最终实现真正1.0 BPW预算下可部署的LLM压缩方案。

### 7. 优点与亮点

- **解决真伪1比特偏差问题**：许多已有二值化方法的名义位宽与实际存储脱节，而AF1在方法论设计上就具备内建的有效BPW控制能力，能够做到论题“genuine 1-bit”的要求；它不做多余的存储假设，只保留两个二值矩阵与极少的轻量缩放向量，这是工程实践上的重要亮点。
- **零空间补偿理论严谨**：对近似零空间投影性质、缩放补偿的闭式解、双因子二值参数化表达容量等关键环节给出严格数学推导（附录A.2），论述过程可信度高。
- **层次化博弈视角的独特性**：将Shapley值从单纯敏感性排序升级为层级化容量分配策略，兼顾层间交互与模块内方向/量值双失真，同时通过温度系数、MAD稳健归一化、尺寸感知密度平滑等手段显著提升了实际可用性。
- **仅缩放重构的资源利用率高**：将全部连续可训练参数限制在尺度空间内，无需更新任何二值矩阵，迭代优化代价低，适合有限校准数据的PTQ环境。
- **充分关注已有方法的隐藏存储开销**：对BiLLM、ARB-LLM、STBLLM、HBLLM等方法逐个进行有效BPW数学推导，在公平统一的存储口径下进行比较，增强了实验结果的说服力。
- **实验设计覆盖面较全**：包含不同模型家族、多尺度（3B-70B）、基础与指令微调模型、多个任务基准以及细致的效能分析。

### 8. 不足与局限

- **仅权重压缩，不处理激活和KV Cache**：AF1聚焦于权重的纯1比特训练后压缩，并未直接压缩激活值或KV cache。在长上下文或大批次服务场景下，激活和KV cache的开销可能成为瓶颈。
- **缺少真实的端到端部署集成测试**：推理效率实验仅在具备优化的二值矩阵乘法的代表性GPU实现（GemLite）上验证。更多真实推理栈（如服务框架、不同硬件平台、批处理策略）中的系统级集成效果尚未评估。
- **评估基线与架构覆盖有限**：实验模型集中在LLaMA、Qwen和Gemma上，指令微调变体的评估也仅覆盖2个代表性模型。更多架构（如MoE模型）、更多指令调优变体以及真实在线负载场景的实验仍待补充。
- **长文本、大语料及首词延迟指标缺失**：论文在推理效率部分只处理了1024-token预填充与4096-token解码的设置，吞吐性能表现尚待覆盖更长的多轮对话、长文本生成等应用模式。
- **校准集选择的实用性考虑**：校准集默认从RedPajama中采样128条，虽然额外的C4样本消融证明了其鲁棒性，但实际部署中训练数据分布不可知，依然存在校准集与待处理任务分布偏移的风险。
- **定性评估工具的使用存在信息重叠风险**：定性生成样例用GPT-5.5做了标注，但其并未完全替代标准基准评测（作者在该问题上用法受到一定的主观锚定影响）。
- **量化时间优化空间仍然存在**：5.9小时虽较QAT快，但整体量化流程相比超低开销的启发式二值化方法仍有更长的离线处理周期。
