## 摘要
离散视觉分词主要由向量量化、标量量化和乘积量化驱动，但缺乏一个统一的概念框架来理解量化权衡。本文提出一个关于现代离散视觉分词的统一率失真视角。通过将量化视为有损压缩，我们以词元数量和码本大小来表征标称定长编码速率，并将量化误差作为失真。在此框架内，我们解决了三个核心问题。首先，我们从理论和实证上表明，最小化失真（而非最大化码本利用率）是重建保真度的主要内在目标，这直接与STE引起的梯度差异相关。其次，我们为内在量化比较确立了两个关键公平条件：控制潜在特征统计量和强制相同的编码速率。第三，在这些条件下，我们恢复了现代视觉分词中的VQ-PQ-SQ失真层级，并从实证上表明现代VQ方法实现了最低失真。这项工作为现代离散视觉分词提供了一个基础性的率失真重构框架，解决了量化器评估中的歧义，并为在固定速率约束下隔离内在量化有效性提供了一个受控框架。

## Abstract
Discrete visual tokenization, predominantly driven by vector, scalar, and product quantization, lacks a unified conceptual framework for understanding quantization tradeoffs. In this paper, we propose a unified rate--distortion perspective on modern discrete visual tokenization. By viewing quantization as lossy compression, we characterize the nominal fixed-length coding rate through token count and codebook size, and quantization error as the distortion. Within this framework, we resolve three central questions. First, we theoretically and empirically show that minimizing distortion, rather than maximizing codebook utilization, is the primary intrinsic objective for reconstruction fidelity, with a direct connection to the STE-induced gradient discrepancy. Second, we establish two critical fairness conditions for intrinsic quantization comparison: controlling latent feature statistics and enforcing identical coding rates. Third, under these conditions, we recover the VQ--PQ--SQ distortion hierarchy in modern visual tokenization and show empirically that modern VQ methods achieve the lowest distortion. This work provides a foundational rate--distortion reframing of modern discrete visual tokenization, resolves ambiguities in quantizer evaluation, and provides a controlled framework for isolating intrinsic quantization effectiveness under fixed-rate constraints.

## 2. 方法论

### 核心思想

- 将离散量化抽象为**有损压缩**：给定输入分布 X，量化器 Q_phi 产生码率 R 与失真 E，研究者据此比较算法。
- 定义**标称固定长度编码率**（nominal fixed-length coding rate）为：

  R = T log₂K

  其中 T 为 token 数，K 为码本空间基数（对 VQ 是指码向量数量；对 PQ/SQ 是指所有子码本笛卡尔积后形成的**复合码空间**基数）。

- 定义**量化失真**为均方误差：

  E(P, Q_phi) = E_X[ ‖X - Q_phi(X)‖₂² ]

### 三个中心命题与理论推理

**（1）失真最小化应被视为主导优化目标**

- 失真与 STE（Straight-Through Estimator）梯度差异：在局部光滑假设下，梯度差异 G 与量化误差的关系满足：

  G = O(‖z_e - z_q‖²)

  因此降低失真会二阶地改善 STE 梯度保真度。

- 定理形式：在每个全局失真最小化器下，只要分布满足“非退化可分割性”（Assumption 1），且不存在可由 K 个码字实现零失真的平凡情况，那么**失真最小化必然导致 100% 码本利用率**；然而利用率 100% 并不等于失真最优（Proposition 2 给出了反例）。

**（2）公平比较的两个条件**

- 条件 1（匹配潜在分布）：比较对象应在相同潜在特征分布 P 上进行；在全局缩放 X′=aX 时，有 E⋆(aX, K)=a²E⋆(X, K)（Proposition 5）。因此潜在尺度会混淆比较结果。
- 条件 2（匹配标称码率）：各算法必须运行在相同 R=T log₂K 下。更强的设计为同时匹配 T 与 K，而不仅匹配 T log₂K。

**（3）VQ、PQ、SQ 的失真层次**

- 结构包含关系：SQ 是 PQ 的特例（M=d，每个子向量 1 维）；PQ 是 VQ 的特例（码本为笛卡尔积结构），故

  E*_{VQ} ≤ E*_{PQ} ≤ E*_{SQ}

- 最坏情形下（Proposition 3，分布定义在 [−1,1]^d）：三者的最优失真都在 Θ(d/K^{2/d}) 量级（常数因子不同）。
- 更有意义的分离（Proposition 4）：当数据内部存在 d_eff 维低维结构（d_eff < d）时，VQ 的失真可低至 O(d d_eff / K^{2/d_eff})，而固定的坐标分解结构的 PQ/SQ 在简单 1 维斜线分布上仍可能具有 Ω(K^{-2/M}) 或 Ω(K^{-2/d}) 的失真率。这使得 VQ 的优势不仅来自结构包含关系，还来自其能**利用低维内在结构**的能力。

### 实验对比框架

- 采用 **VQ-Transplant 框架**：沿用预训练 VAR tokenizer 的编码器与解码器，仅替换量化模块，实现“同一潜在空间”的受控比较。
- 两阶段流程：
  1. **Substitution**：冻结编码器与解码器，仅训练新量化器；
  2. **Adaptation**：再冻结量化器与编码器，令解码器适配新量化表示。

## 6. 主要结论与发现

1. **失真最小化是更本源的优化目标**
   - 失真最小化在温和条件下自然导致 100% 利用率，而 100% 利用率不蕴含满意重建；
   - 失真同 STE 梯度差异有直接联系：失真减小→STE 梯度近似质量提升→训练更稳定；
   - 在多个数据集中，失真与 r-FID 的 Spearman 相关性（ρ≈0.94–0.996）远强于码本利用率与 r-FID 的相关性（ρ 约 −0.4 至 −0.56，且部分不显著），证明高利用率并非重建保真度的充分代理。

2. **公平比较必须控制两组因素**
   - 必须匹配潜在源分布，特别要避免潜在尺度差异（失真随方差线性增长）；
   - 必须匹配码率（理想为同时匹配 token 数与复合码本基数），而不是只对比网络整体重建质量。

3. **理论失真层级是 VQ ≤ PQ ≤ SQ**
   - 在匹配潜在分布与码率后，最优失真确实满足 E*_VQ ≤ E*_PQ ≤ E*_SQ；
   - 在低维结构的源上，VQ 可进一步获得明显更优的失真阶（O(K^{−2/d_eff}) vs. PQ/SQ 在高维坐标分解下的较慢衰减）。

4. **现代 VQ 的实际表现优于 PQ 与 SQ**
   - 在 ImageNet-1K 受控比较中，最佳 VQ（MMD VQ）在替换阶段 E=0.201，优于最佳 PQ（0.209）与最佳 SQ（0.231）；
   - 在解码器适配后同样取得最优 r-FID=0.86，优于 PQ（0.93）和 SQ（1.07）；
   - 上述相对优势在 FFHQ、CelebA-HQ 以及像素空间 CelebA-HQ 场景中均保持一致。

## 7. 优点

- **视角统一**：把现代深度离散视觉 tokenization 中看似异质的 VQ、PQ、SQ 算法拉到同一率失真脚手架下，概念上更简洁、更具理论导向。
- **关注“公平比较”问题**：点出跨文献比较普遍存在的重坐标系统混淆问题，并提出可执行的两条控制条件，比多数只做端到端 scoreboard 比较的工作更严格。
- **理论分析切入有实质贡献**：
  - Proposition 2 澄清“失真最小化→基本可推出完全利用率；完全利用率↛失真最优”；
  - Proposition 4 给出了非渐近、显式地依赖块数 M 的 VQ–PQ 分离下界，并解释其与经典 Zador 量化理论的不同；
  - STE 梯度差异与失真之间的二阶联系为“为什么低失真利于优化”提供了新支撑。
- **实验设计较严谨**：
  - 引入 VQ-Transplant 使得所有算法共享编码器、解码器与潜在空间；
  - 明确匹配 T 与 K（而不是 R 单独匹配），给出比较更细粒度；
  - 针对歪曲因素做了 latent-scale 理论推导，并对 K、T、不同(T,K)分配、多个数据集和像素空间均做了测试；
  - 还进行了与经典“高利用率成功叙事”相悖的统计证据（Spearman 相关）。

## 8. 不足与局限

- **范围边界一：码率模型有限**
  - 论文只刻画了固定长度码率 R=T log₂K；
  - 没有描述熵编码/变长编码/熵约束下的率失真行为，因此不能直接回答“若同时考虑 token 分布概率则应如何选择/比较量化方法”的问题。

- **范围边界二：失真度量单一**
  - 全程使用平方欧氏距离作为信息损失度量，无法捕捉感知质量、语义任务或下游

- 感知质量与下游任务：论文自始至终使用均方误差作为失真度量，理论上可以给出干净的率失真分析，但均方误差不能直接代表人类感知或语义保真度。对于以图像生成为目标的 tokenizer，重建 PSNR/SSIM/LPIPS/r-FID 虽然提供了补充视角，但论文几乎没有涉及“不同量化器对条件生成、分类、分割等下游任务的影响”。因此，若读者希望了解“在生成质量或语义理解意义上 VQ 是否仍然优于 PQ/SQ”，论文只能给出间接证据，而非直接结论。

- **范围边界三：码本/量化器参数空间的对称性假设较强**：理论部分依赖“相同码本基数 K”“相同 token 数 T”和“同一潜在分布 P”下的比较；真实系统中，tokenizer 常与 Transformer 联合训练，码本大小和 token 序列长度往往同时影响后续模型容量与注意力复杂度，并非纯率失真问题。论文对这些联合优化情形保持有意回避，因此其实验结论更适合被理解为“量化模块单独比较”的结论，而不是端到端 tokenizer 设计指南。

- **实验设计的边界：编码器-解码器来自预训练 VAR tokenizer**。虽然这保证了公平性，但也意味着全部算法共享一个经过特定 VQ 预训练的潜在空间。潜在空间本身可能已经“偏向”某一类量化特性（例如球面分布或低维子空间），从而使 SQ/PQ 在源分布匹配上处于不利地位。论文对潜在空间做了归一化或固定处理，但很难完全消除这种已训练潜在空间带来的选择偏误；理想情形应在多种预训练潜在空间上做交叉验证，而论文只在部分额外实验（像素空间、FFHQ、CelebA-HQ）中部分缓解了这一问题。

- **PQ 的块数与结构设定单一**：论文仅尝试了 M=2 的 PQ（每个 16 维 token 切为两个 8 维子向量）。而在现实 PQ 应用中可以变化 M 与子码本大小，这直接影响 PQ 的码本分布特性与失真表现。理论分析虽然对一般 M 给了下界，但实验上未作扫描，故“VQ 优于 PQ”的实际结论严格来说只在 M=2 的 PQ 变体上得到验证，无法排除“某些 M 的选择可使 PQ 更接近甚至达到 VQ 性能”的可能性。

- **码率匹配的表层化**：论文强调同时匹配 T 与 K，这在比较上非常公平；但代价是忽略了同一固定码率下不同(T,K)分配方式带来的解码器复杂度差异。虽然表 5 尝试了相同 R 下不同 (T,K) 的组合，但实验仅仅是沿着“固定 R 的不同分配”延长线展开，未在完整语义生成或端到端生成任务上进行验证，因此对实际设计者的启发有限。

- **训练开销未透明化，可复现成本受限**：论文没有报告分阶段训练的总 GPU 时长、内存峰值或能耗；仅提供批大小与训练轮次。这在对比多种方法时显得可以理解（各方法开销接近），但对于想将该框架扩展到更大型预训练模型的读者，缺少成本上的预判依据。

- **与实际生成模型端的跨方法验证缺失**：论文对重建质量做了充分验证，却没有进一步在同一自回归生成器下对 VQ/PQ/SQ tokenizer 的输出做生成实验。这样无法确认“失真更优”是否能够转换为“采样质量更优”或“自回归任务上更易学”的最终收益。对视觉 tokenization 领域而言，重建与生成之间并非完全一致的目标，因此这也是一个实质性的证据缺口。

## 9. 总结与启示

### 对研究社区的启示

- **从“码本利用率叙事”转向“率失真叙事”**：本文最重要的启示是：对于离散视觉 tokenizer，与其把码本利用率当作核心指标，不如回到信息论源头，把“码率-失真”视为第一性的标尺。这一框架迁移可以解释很多零散的工程经验：例如 EMA/Online/Wasserstein/MMD 等对 VQ 变体的改进，其成功的共同原因可能不是码本使用率上升，而是实际失真下降。

- **为未来方法比较提供了契约式协议**：作者给出的两条公平比较条件（匹配潜在分布与匹配码率）可以作为可操作模板，供以后各 tokenizer 论文在比较时直接采纳。更具体地，“用同一预训练编码器/解码器 + 只替换量化模块”的 VQ-Transplant 方法，成本低且证据清晰，值得被领域采纳为基准评估策略。

- **理论层级关系可用于方法选择和预期管理**：E*_VQ ≤ E*_PQ ≤ E*_SQ 这一结构关系虽从定义看近乎显然，但被实验验证后就有了实际价值。研究者可以选择计算更简单的 SQ/PQ（如 FSQ/LFQ）换取接近的失真；只有需要严格逼近低维结构时，才需要更复杂的 VQ。

### 站在论文角度略过的深层问题

- 对“量化作为压缩”而言，任何率失真分析都离不开失真度量实际近似任务损失的问题；本文止步于 MSE 与重建指标，未来工作可延伸至感知率失真、扩散/AR 生成损失下的率失真行为。
- 从实践角度，量化器的梯度近似方式、码本更新频率、EMA 衰减等工程设计也会改变实际表现，而本文将这些因素统一视为“在给定优化器与训练配置下实现近似率失真极限的途径”，并没有对每种变体的内部机制给出定量的归因——这为后续“量化器内在机制 vs. 工程技巧”的拆解留下了空间。

---

## 10. 总体评价

这篇论文在内容上兼具理论严谨性与工程实用性，是一篇少有地直接回应“VQ/PQ/SQ 到底在何种条件下可比、谁更优”这一领域基本问题的工作。它的主要贡献可概括为：

1. 提出了基于率失真理论的统一视角；
2. 给出了失真最小化、码率匹配与结构包含关系的清晰理论；
3. 设计了可执行的 VQ-Transplant 受控实验框架；
4. 在潜在空间与像素空间、多个数据集上给出系统证据，证明现代 VQ 在公平条件下仍优于 PQ 与 SQ；
5. 质疑了“利用率最大化”的传统信仰，并提供理论反例与统计证据。

就其不足而言，最显著的缺口集中在三方面：一是失真度量只覆盖 MSE，未延伸到感知或下游任务；二是全部受控实验建立在特定预训练编码器潜在空间上，“公平”仍是有边界条件的公平；三是缺少端到端生成实验，因此“量化失真=生成质量改善”的关键桥梁尚属推断而非证明。但整体而言，论文为视觉 tokenizer 的设计与比较建立了坚实的概念与实验底座，对该领域未来研究具有较高的参考价值与规范意义。
