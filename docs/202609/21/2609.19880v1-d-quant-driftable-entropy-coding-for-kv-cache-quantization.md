## 摘要
KV 缓存已成为部署 LLM 的主要瓶颈，因为其内存占用随序列长度和批大小线性增长，给内存容量和带宽都带来了巨大压力。在各种 KV 缓存压缩技术中，量化因其有效性和易于部署而尤其具有吸引力。然而，大多数现有方法依赖固定位宽量化，其中一个 $b$ 比特表示本质上只能提供 $2^b$ 个量化级别。随着位宽降低，可用级别数呈指数级减少，导致严重的信息损失和性能迅速下降。我们进一步观察到，固定位宽量化未能利用 KV 缓存的高度非均匀分布。经过旋转和归一化后，KV 值近似服从正态分布，大多数值集中在中心附近，只有一小部分出现在尾部。然而，固定位宽编码为频繁符号和稀有符号分配相同的比特数。熵编码通过为频繁符号分配较短码字、为稀有符号分配较长码字，自然地利用这种非均匀性，从而显著减少表示所需的平均比特数。然而，其变长输出不适合高度并行的注意力内核，因为高效的反量化和计算依赖于规整的内存布局和固定步长访问。为弥合这一差距，我们提出 D-Quant，一种灵活的 KV 缓存量化框架，它引入漂移机制，将每个 token 的熵编码表示转换为固定大小的比特流，从而在注意力内核中实现规整的内存访问和并行反量化。

## Abstract
The KV cache has become a major bottleneck in deploying LLMs, as its memory footprint grows linearly with sequence length and batch size, imposing substantial pressure on both memory capacity and bandwidth. Among various KV cache compression techniques, quantization is particularly attractive due to its effectiveness and ease of deployment. However, most existing methods rely on fixed-width quantization, where a $b$ bit representation is inherently limited to $2^b$ quantization levels. As the bit width decreases, the number of available levels shrinks exponentially, leading to severe information loss and rapid performance degradation. We further observe that fixed-width quantization fails to exploit the highly non-uniform distribution of KV cache. After rotation and normalization, KV values approximately follow a normal distribution, with most values concentrated near the center and only a small fraction appearing in the tails. Nevertheless, fixed-width coding allocates the same number of bits to frequent and rare symbols. Entropy coding naturally exploits such non-uniformity by assigning shorter codewords to frequent symbols and longer ones to rare symbols, substantially reducing the average number of bits required for representation. However, its variable-length output is not suited to highly parallel attention kernels, where efficient dequantization and computation rely on regular memory layouts and fixed-stride accesses. To bridge this gap, we propose \textbf{D-Quant}, a flexible KV cache quantization framework that introduces a \textbf{drift} mechanism to convert entropy-coded representations of each token into fixed-size bitstreams, enabling regular memory access and parallel dequantization within attention kernels.

- **背景**：自回归推理中，KV cache 随序列长度与 batch size 线性增长（模型权重固定，KV cache 不固定），成为长上下文 LLM 部署在**显存容量**与**带宽**上的主要瓶颈。
- **现有主流方案**：KV cache 量化（KIVI、KVQuant、QuaRot、OScaR 等）通过改进量化粒度与预处理降低开销，但几乎都使用**固定位宽编码**。
- **两个根本缺陷**：
  - **级数被位宽锁死**：$b$ bit 只能提供 $2^b$ 个重建级，位宽下降时可用级数指数级减少，低位宽下信息损失严重、性能迅速退化。
  - **不匹配分布**：经旋转 + 归一化后，KV 值近似正态分布（绝大多数值集中在中心，少量落在尾部），但固定位宽对高频与稀有符号分配相同比特，浪费严重。
- **熵编码的机遇与障碍**：熵编码天然适配非均匀分布（高频短码、稀有长码），但输出为**变长比特流**，与高并行注意力核所需的规整内存布局、固定步长访问不兼容。
- **整体含义**：论文试图把熵编码的压缩效率带入 KV cache 量化，同时保持注意力核的并行友好性，从而在极低位宽下逼近 BF16 质量。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- 用**固定字节大小的容器（container）**承载每个 stream（一个 token 的 K 或 V 向量）的熵编码结果，使 KV cache 仍是固定步长的规则数组。
- 引入 **drift（漂移）机制**：当编码长度超出预算时，不做全局降精度，而是把**少量高代价符号局部漂移到邻近低成本符号**，直到满足长度约束。
- 熵编码概率模型**由标准正态分布解析推导**，无需校准数据。

### 2.2 编码流程（图 1）

1. **预处理**：对每个 attention head 做 Hadamard 旋转（V 可离线折叠进投影权重，K 因与 RoPE 不可交换需在线做）；K 额外做**窗口化通道均值移除**。
2. **逐 token 仿射量化**：$\hat{x}_i = o + s\,m_i$，$m_i \in \{0,\dots,M-1\}$，$s=(\max x-\min x)/(M-1)$，$o=\min x$；scale/offset 舍入到 FP16。
3. **熵编码（rANS）**：精度 $p=8$，256 项查找表同时存重建级与状态更新信息，解码与反量化共用一次查表；流按逆序编码以保证顺序解码。
4. **固定容器约束**：$\sum_{i=1}^{n} r(m_i) \le B,\; B = 8C - \sigma$（$\sigma$ 为 coder 末态开销）。
5. **两轮 drift**：先用 min–max 拟合 scale/offset 求初始 assignment → drift → 重新拟合 scale/offset 并舍入 FP16 → 再次 drift，保证编码器优化的网格与解码器一致。

### 2.3 Drift：长度约束下的符号分配

- 优化目标（式 5）：在码长约束下最小化重建误差
  $$\min_{m\in\{0,\dots,M-1\}^n}\ \sum_{i=1}^{n}\bigl(x_i-(o+s m_i)\bigr)^2 \quad \text{s.t.}\ \sum_i r(m_i)\le B$$
- 转为 **Lagrangian 可分离形式**（式 6）：$\min_m \sum_i [D_i(m_i)+\lambda r(m_i)]$，固定 $\lambda$ 时每个值独立求解。
- 用 **bisection** 搜索满足码长约束的 $\lambda$：对 $\log_2\lambda$ 二分（$T=12$ 次），区间 $hi=\log_2(8(\max D-\min D))$，$lo=hi-40$，对数值范围更稳定。

### 2.4 实用改进

- **K/V 独立配置**：K 更敏感（误差直接影响 softmax 前的 logits 并被指数放大），分配更大容器预算；级数也可独立设置（默认 K 用 8 级、V 用 6 级）。
- **分布锐化**：drift 会把符号推向更可能的中心级，故把解析概率锐化为 $p'_m \propto p_m^{\alpha}$，全局统一 $\alpha=1.4$。
- **内核设计**：
  - 编码：一个 warp 处理一个 stream，值常驻片上，逐次二分时在线重算失真，warp 级规约码长，避免物化 $n\times M$ 失真矩阵。
  - 解码：**以 token 为中心**组织（而非 head 为中心），每个 thread block 负责一组 token，每个 stream 只解码一次，warp 按 channel 划分累加器；仿射变换折叠进注意力收缩，无需显式逐元素反量化。

## 6. 主要结论与发现

- **精度**：2.26 BPV 下 RULER 平均分 86.50（Qwen3-8B）/ 88.94（Llama-3.1-8B），逼近 BF16 的 87.31 / 89.69，显著优于所有基线；128K 时 D-Quant 达 70.92 / 74.65，最强基线仅 57.14 / 66.15。
- **低预算仍强**：1.96 BPV 时 RULER 平均 85.21 / 87.26，仍超过所有基线（其存储更低）。
- **长上下文更稳**：基线随长度增加退化更快，D-Quant 全程贴合 BF16 曲线。
- **系统收益**：64K 解码时 KV cache 显存降低约 **7×**；BF16 在 8K prompt 下 batch=64 即 OOM，D-Quant 可扩展到 batch=128（峰值 49.4 GiB）；最大可行 batch 下吞吐 **563.6 vs 159.5 tokens/s（约 3.5×）**。
- **设计规律**：
  - 熵编码使级数脱离位宽，同级预算下可用更大 alphabet（8/6 为较优点，继续增大导致 drift 频繁反而掉点）。
  - 存储预算增加可平滑逼近 BF16。
  - K 分配略多于 V 更优，但过度倾斜会损害 V 的表示。
- **机制发现**：
  - 旋转使分布接近高斯，K 的通道均值移除把 Normal Gap 降到 $5\times10^{-4}$ bit/value，故解析模型无需校准（实测仅多 0.0045 / 0.0039 bit/value）。
  - drift 非常稀疏：仅 **0.75% 的 K 符号、5.00% 的 V 符号**被改动，且**移动不超过一个重建级**。
  - 匹配存储下 D-Quant 的 KL 散度约为固定位宽的一半（2.26× / 2.00×），固定位宽需多花 0.234 / 0.267 bit/value 才能追平。

## 7. 优点

- **问题切中要害**：明确指出现有 KV 量化的"固定位宽 = 2^b 级"这一被忽视的编码格式限制，并给出解耦级数与存储预算的可行路径。
- **方法组合巧妙**：用固定容器把熵编码的变长输出"规整化"，drift 只做稀疏局部修正而非全局降精度，兼顾压缩率与访存规整性。
- **免校准**：概率模型由标准正态分布解析导出，无需校准集，部署成本低、泛化风险小，且全模型/层/任务共用一套超参。
- **软硬件协同**：warp-per-stream 编码、token-centric 解码、rANS 表项同时携带重建级与状态更新、仿射折叠进注意力收缩，避免了显式反量化与 BF16 KV 物化。
- **灵活性**：存储预算不再绑定整数位宽或固定 group size，K/V 预算与级数可独立调节，能按敏感度分配。
- **实验说服力**：匹配存储对照实验把"编码增益"从"预处理增益"中剥离，结论归因清晰。

- **可复现性与开源**：论文未明确提供代码、内核实现或完整超参表，复现自定义 rANS 内核与容器布局的门槛较高。

## 9. 总体评价与适用场景

- **核心贡献**：D-Quant 把“熵编码的高压缩率”与“KV cache 的规整访存”调和起来，用固定字节容器承载变长码流，并用稀疏 drift 替代全局降精度，从而将**重建级数从位宽中解耦**。这是对现有 KV 量化范式的有意义的补充。
- **最强证据**：2.26 BPV 下逼近 BF16 的 RULER 平均分、128K 长上下文优势、约 7× KV cache 显存节省、大 batch 下约 3.5× 吞吐，以及附录 B 在匹配存储下将编码增益从预处理增益中剥离的 KL 对照。
- **适用场景**：长上下文、大 batch、显存/带宽受限的在线推理服务；对延迟极度敏感的小 batch 场景收益有限甚至更慢。
- **证据强度**：主实验、消融与机制分析较完整，匹配存储对照提升了归因可信度；但模型规模（仅 8B 级）、任务类型（英文长文本为主）、理论保证与框架集成验证仍有明显提升空间。
- **后续方向**：扩展到更大模型、MoE、多模态与推理/代码任务；与 PagedAttention/连续批处理集成；自适应容器预算与在线超参调整；给出 drift 的误差界或收敛性分析；开展端到端服务级延迟、吞吐与成本评测。
