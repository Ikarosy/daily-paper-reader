## 摘要
块量化（BQ）是高效部署大型语言模型（LLM）的一种有前景的方法，能够在控制精度损失的同时实现低精度计算。与标量仅权重量化（WoQ）相比，BQ同时量化权重和激活，提供更高的硬件效率和在统一数据路径上的端到端推理，但其设计空间（涵盖位宽、块大小、缩放和数值格式）仍未得到充分探索。我们通过设计空间探索（DSE）提供了硬件/基准测试结果。我们发现，增大块大小通过摊销反量化和累积成本提高了硬件效率，但会降低精度。这种权衡限制了传统的BQ方法。受此洞察启发，我们提出了分层块量化（HBQ）。与先前方法[1]、[2]使用小块和传统的2的幂（PoT）或基于整数的缩放不同，HBQ使用大块以最大化效率，并引入了低开销的有效数（SIG）缩放用于第二级量化。通过有效分配量化级别并考虑激活和权重的不同分布，SIG缩放比先前的PoT和INT方案更有效地补偿了大块误差。HBQ-A（高精度）仅使用W4A5即可达到W4A16级别的精度，同时所需硅面积小于NVFP4。HBQ-E（高效）进一步将硬件成本降低17%，同时保持比所有现有BQ方法更高的精度。我们实现了一款28nm ASIC加速器，将HBQ应用于权重、激活和KV缓存，并集成了一种新颖的部分和BQ方案以进一步降低EMA能耗。与最先进的WoQ相比，HBQ在相同精度水平下实现了$2.3\times$/$4.6\times$更高的面积/能源效率；与先前BQ方法相比，系统能耗降低$1.6$–$3.3\times$，速度提升$1.5$–$3.0\times$，同时提供了最佳精度。

## Abstract
Block Quantization (BQ) is a promising approach for efficient deployment of large language models (LLMs), enabling low-precision computation with controlled accuracy degradation. Compared to scalar weight-only quantization (WoQ), BQ quantizes both weight and activation, offering higher hardware efficiency and end-to-end inference on a unified datapath, but its design space, spanning bit-width, block size, scaling, and numeric formats, remains underexplored.   We provide hardware/benchmark results through design space exploration (DSE). We find that increasing block size improves hardware efficiency by amortizing dequantization and accumulation costs, but degrades accuracy. This trade-off limits conventional BQ methods.   Motivated by this insight, we propose Hierarchical Block Quantization (HBQ). Unlike prior methods [1], [2], which use small blocks and conventional Power-of-Two (PoT) or integer-based scaling, HBQ uses large blocks to maximize efficiency and introduces low-overhead significand (SIG) scaling for second-level quantization. By allocating quantization levels effectively and accounting for distinct activation and weight distributions, SIG scaling compensates for large-block errors more effectively than prior PoT and INT schemes. HBQ-A (accurate) achieves W4A16-level accuracy using only W4A5 while requiring less silicon area than NVFP4. HBQ-E (efficient) further reduces hardware cost by 17% while maintaining higher accuracy than all existing BQ methods.   We implemented a 28nm ASIC accelerator applying HBQ to weights, activations, and KV cache, and integrated a novel partial-sum BQ scheme to further reduce EMA energy.   Compared to state-of-the-art WoQ, HBQ delivers $2.3\times$/$4.6\times$ higher area/energy efficiency at the same accuracy level; $1.6$--$3.3\times$ system energy reduction and $1.5$--$3.0\times$ speedup over prior BQ methods while providing best accuracy.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### （1）方法总体框架

论文提出**分层块量化（Hierarchical Block Quantization, HBQ）**，其核心思路是**使用大的一级（L1）块以最大化硬件效率，再通过轻量、低开销的二级（L2）量化来补偿大块带来的精度损失**。L2 缩放引入新提出的**有效数缩放（Significand Scaling, SIG）**，用于更好地匹配权重和激活的不同分布特性。整体量化公式如下：

- 一级量化：块 \(B_b\) 共用一级缩放因子 \(s_b\)，其元素 \(x\) 的量化形式为 \(q^{(b)} = Q_F(x / s_b)\)；
- 二级量化：块 \(B_b\) 内再划分为微块 \(U_{b,u}\)，各微块独立享有二级缩放因子 \(\alpha_{b,u}\)，元素实际采用的有效缩放为 \(\tilde s_{b,u}=s_b \cdot \alpha_{b,u}\)；
- 反量化/解码过程：\(\hat{x} = q_{(b,u)} \cdot \alpha_{b,u} \cdot s_b\)。

### （2）核心创新：Significand Scaling（SIG）

其中二级缩放因子的编码方式为：

\[\alpha_{\mathrm{SIG}_x}(c) = 1 + \frac{c}{2^x}, \quad c \in \{0,1,\ldots,2^n-1\},\; x\in \mathbb{N}\]

- 论文取 \(\alpha\) 位宽 \(n=2\) 以压降硬件/位开销；
- SIG 策略可通过参数 \(x\) 控制有效数缩放的粒度：如激活与 KV cache 适合 \(\mathrm{SIG}_1\)，权重则适合更细粒度的 \(\mathrm{SIG}_3\)；
- 由于权重离线量化，HBQ 逐 L1 块比较 \(\mathrm{SIG}_2\) 与 \(\mathrm{SIG}_3\)，挑选量化 MSE 更小者，以 1 bit 的 select 信号存储标记供解码端使用；
- **关键效果**：相比 PoT 或 INT 缩放，SIG 在相同 L2 位开销下显著降低量化 MSE，真正“有效”地增加可表示量化电平，**可将 B=128 大块带来的误差恢复到小块 B=16 甚至更低的水平**。

### （3）与硬件结合的 HBQ 实现

- **PE 结构**：在原有 BQ 的 PE 设计（B 个乘法、B-to-1 定点加法树、去量化、FP 跨块累加）基础上，插入微块内加法树与 L2 去量化模块：先进行 micro-block 内定点累加，再执行 L2 去量化，再进行跨 micro-block 的 L1 去量化与浮点累加；
- **权重静止（Weight-Stationary）数据流 + 整体加速器实现**：28nm TSMC 工艺实现、32 个 PE（共 4096 MAC）、500 MHz 工作频率；
- **提出 partial-sum MXINT8 量化方案**：块大小为 32 的 8 位 MXINT8 psum 量化，在保持 FP16 精度累加的同时，将 psum 存储占用减半，扩大 tile 规模，有效降低外存访问（EMA）能耗；
- 论文进一步明确了 **HBQ-E（高效版，\(\mu B=32\)）** 与 **HBQ-A（高精度版，\(\mu B=8\)）** 两种配置，以适应不同部署场景。

4. **评测场景全面且贴近现实需求**：从困惑度到零样本任务、多步推理和长生成 CoT 环境，从短序列、长序列到推理场景，评测维度在 BQ 文献中相当完整；
5. **完整的 RTL-布局-功耗闭环验证**：实际做好布局布线，并有带切换活动标注的功耗、延迟、面积数据，而非停留在算法仿真层面；
6. **公平性意识较强**：在统一 PE/加速器配置下复现基线，匹配 buffer 容量与计算吞吐，最大程度减少硬件实现差异带来的误差。

## 8. 不足与局限

1. **只基于后训练量化（PTQ），未探索微调场景**：所有实验均基于无梯度/无重训策略；与可微调或联合训练的量化方案相比，泛化性未能验证；
2. **模型规模上限为 70B**：虽然覆盖 L3.1-70B，但尚未评估更大规模模型（如 100B+）的场景；
3. **GPU 和训练时长等算力信息缺失**：未报告耗电量、GPU 型号/数量、标定时间，复现成本难以估算；
4. **部分对比方法依赖原论文数据或按其论文描述重新实现**：如 MANT 直接引用原论文 28nm 数据，MicroScopiQ 使用原论文中未经精度损失充分评估的 bit-truncation PE，可能引入比较误差；一些方法缺少在不同模型上的完整测评结果（如 Amove 只在 Llama2-7B 上报告 PPL）；
5. **KV cache 对比范围有限**：尽管与常见格式（MXFP4/NVFP4）做了直接对比，但对于具有复杂动态/非均匀量化策略的高级 KV-cache 量化方案（如 KIVI、KVQuant、SageAttention），论文未做 PE 级及更细粒度的硬件对齐对比，仅做了文字层面的优劣论证；
6. **部分小细节可能限制泛化**：如 prefill/decode 两类负载只对 HBQ-E/A 做了粗略建议划分，未给出统一的端到端切换策略；
7. **对旋转量化 / 码本量化的对比较为粗略**：数理层面对比维度覆盖不足，主要指出其他方案需额外的 GPTQ/微调或者查询开销，但没有完整做硬件资源对比或端到端量化-推理周期对比。
