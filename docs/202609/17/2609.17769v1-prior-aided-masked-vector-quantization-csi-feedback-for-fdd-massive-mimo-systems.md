## 摘要
下行链路信道状态信息（CSI）反馈是频分双工（FDD）大规模MIMO系统中的一个关键瓶颈，因为用户设备（UE）必须在有限的上行链路（UL）预算下将其估计的信道传送给基站（BS）。为了在严格的反馈约束下提高CSI重建精度，我们提出了先验辅助掩码矢量量化（PM-VQ），这是一种基于学习的分离信源—信道编码（SSCC）反馈方案，其以平均角度—时延功率图为条件——该图是UE和BS处均可获得的信道二阶统计量的紧凑表示。在PM-VQ中，先验辅助编码器将CSI映射为潜在token，空间自适应掩码模块（SAMM）对信息量最大的token进行评分，并在反馈预算内选择它们。选中的token经过矢量量化后，与其位置一起被反馈；而自适应去掩码模块（ADM）在BS处进行先验条件解码之前补全潜在表示。为支持可变速率压缩，单个模型在一系列选定token数量上进行训练，从而无需重新训练即可在多个反馈维度上运行。我们在Sionna生成的3GPP TR 38.901 UMa数据集上，将PM-VQ与三个代表性基线进行比较，重点关注最具挑战性的弥散场景，其中信道能量分散在众多角度—时延系数上。仿真结果表明，在该场景下，PM-VQ在所有测试的SNR水平和反馈维度上均实现了最低的NMSE。此外，即使仅从少量信道实现中估计得到，角度—时延功率图先验仍然有益。

## Abstract
Downlink channel state information (CSI) feedback is a key bottleneck in frequency-division duplex (FDD) massive MIMO systems, as the user equipment (UE) must convey its estimated channel to the base station (BS) over a limited uplink (UL) budget. To improve CSI reconstruction accuracy under tight feedback constraints, we propose prior-aided masked vector quantization (PM-VQ), a learning-based separate source--channel coding (SSCC) feedback scheme conditioned on the average angle--delay power map---a compact representation of the channel second-order statistics available at both the UE and the BS. In PM-VQ, a prior-aided encoder maps the CSI to latent tokens, and a spatially-adaptive masking module (SAMM) scores and selects the most informative tokens within the feedback budget. The selected tokens are vector-quantized and fed back together with their positions, while an adaptive de-masking module (ADM) completes the latent representation at the BS before prior-conditioned decoding. To support variable-rate compression, a single model is trained over a range of selected-token counts, enabling operation across multiple feedback dimensions without retraining. We evaluate PM-VQ against three representative baselines on a Sionna-generated 3GPP TR~38.901 UMa dataset, focusing on the most challenging diffuse regime where channel energy is spread across many angle--delay coefficients. Simulation results show that PM-VQ achieves the lowest NMSE across all tested SNR levels and feedback dimensions in this regime. Moreover, the angle--delay power-map prior remains beneficial even when estimated from only a few channel realizations.

- **系统瓶颈**：在 FDD 大规模 MIMO 系统中，上下行不具互易性，UE 必须在有限的上行（UL）预算下把估计的下行（DL）CSI 反馈给 BS。反馈开销与重建精度之间存在根本性权衡，如何在受限比特预算下精确重建高维 CSI 是本文核心问题。
- **编码范式选择**：论文在 SSCC（分离信源—信道编码）框架下研究该问题，理由是 5G NR 的 CSI 报告本质为数字比特流，且 SSCC 可将信道编码与信源编码解耦，从而把问题归结为信源编码设计。文中采用容量可达的理想化信道编码模型，把 UL 链路抽象为可靠比特预算 `B ≤ βfb·Cul(psnr_ul)`。
- **理论指引**：远程率失真理论表明，率失真最优解沿信源协方差特征模态进行“反向注水”，应将有限比特优先分配给高方差分量。但率失真可达性是渐近的，而 CSI 反馈本质是**单次（one-shot）压缩**问题，无法积累大量实现做联合编码。
- **现有学习类方法的四点不足**：
  1. 隐表示纯数据驱动，未显式识别并优先传输信息量最大的隐分量；
  2. 多数方法未利用信道二阶统计量（如 CovNet 仅在解码端利用）；
  3. 多数方案只支持固定压缩率，变速率方法（嵌套隐表示）的特征排序对各信道实现固定；
  4. 评测多依赖单一固定信道剖面（CDL-C/D），缺乏几何多样性。
- **研究意义**：提出可训练、可变速率、利用二阶统计先验并能在单次体制下工作的信源编码器，是连接信息论指引与实际部署的关键一步。

## 2. 方法论：PM-VQ（先验辅助掩码矢量量化）

### 2.1 核心思想
以 **平均角度—时延功率图** 作为先验边信息（UE 与 BS 均可从各自历史 CSI 缓冲区估计，无需额外反馈负载），在编码器、token 评分与解码器多个语义层级注入先验；通过内容自适应的 token 选择与掩码补全，把有限比特集中到最具信息量的隐 token 上。

### 2.2 关键表示与先验
- 角度—时延域 CSI：对天线—频域信道做两侧酉 DFT（`H_ad = F^H H F`），能量守恒并暴露稀疏结构。
- 先验功率图：`P^(S) = (1/S) Σ_{s=1}^{S} |H_ad(s)|²`，是角度—时延功率谱的样本均值估计；小尺度衰落变化快于几何二阶统计，故可由多个实现平均得到。
- CSI 张量按实/虚部堆叠为二通道图像 `X ∈ R^{2×H×W}`，先验归一化为 `P ∈ R^{1×H×W}`。

### 2.3 网络结构（非对称先验辅助 U-Net）
- **先验辅助编码器**：U-Net 收缩路径（3×3 卷积 + 多级残差下采样 + 1×1 投影），在每一分辨率做门控融合：
  `Fuse_ℓ(f_ℓ,P) = f_ℓ + tanh(α_ℓ)·ρ_ℓ(P) + GN(f_ℓ)`
  其中恒等项保留幅度、GN 项稳定激活尺度、先验项注入长时结构，`tanh(α_ℓ)` 为可学习门控。
- **SAMM（空间自适应掩码模块）**：对每个隐 token 打分 `s = SAMM(z_e, P̃) ∈ (0,1)^K`，用 SPADE 调制注入先验：`SPADE(h,P̃) = (1+γ(P̃))⊙GN(h)+β(P̃)`。
- **Top-k 选择与分数缩放**：取分数最高的 k 个 token，`I = top-k(s)`；因 top-k 不可微，对选中 token 做 LayerNorm 后按分数缩放 `r z_{e,i} = LN(z_{e,i})·s_i`，使选择网络的梯度可经前向路径回传。
- **矢量量化**：学习码本 `{c_j}`，最近邻分配；用直通估计器 `p z_q = r z_e + sg(z_q − r z_e)` 传梯度，码本由 EMA 更新。

### 2.4 预算模型与可变速率
- 源编码开销建模为 `B(K,k,J) = K·h₂(k/K) + k·log₂J`（位置开销用二元熵上界，保证预算约束始终满足）。
- 在给定可靠预算 `βfb·Cul` 下取最大可行 token 数 `k* = max{k : B(K,k,J) ≤ βfb·Cul}`；因 K、J、βfb、Cul 双方已知，`k*` 无需信令。
- 训练时对 k 在 [3,200] 内随机采样，使**单一模型**覆盖多个反馈维度，无需重训。

### 2.5 ADM（自适应去掩码模块）
- 把收到的 k 个码字放回对应位置，缺失位置填同一个可学习掩码 token，得到稀疏网格 `r z_0`。
- 补全 = 基线投影 `b = P_0(r z_0)`（保留接收码字信息）+ Transformer 分支预测修正 `Δz`。
- **渐进式可靠性掩码**：`a^(0) = m + ε(1−m)`（接收位置权重 1、缺失位置权重 ε），每层取平方根 `a^(ℓ+1) = √(a^(ℓ))` 逐渐升至 1，形成由粗到细的补全。
- 输出 `p z = b + α_k·m⊙Δz + α_u·(1−m)⊙Δz`，接收位置几乎直通、缺失位置接受更强修正。
- ADM 设计上**不使用先验**，仅从可靠接收 token 推断缺失位置。

### 2.6 先验条件解码器
- U-Net 扩展路径：3×3 卷积 → 瓶颈自注意力 → 多级先验条件上采样块。
- 关键改动：UE 侧跳连特征无法免费传到 BS，故用 **BS 侧先验编码器** 生成多尺度跳连特征 `{p_ℓ^skip} = E_P(P)`，并用先验金字塔生成尺度匹配的 SPADE 调制图 `{p_ℓ^mod}`，即用先验合成 U-Net 跳连，额外反馈开销为零。

### 2.7 训练目标
`L = λ_rec·L_rec + λ_cm·L_cm + λ_lat·L_lat + λ_cu·L_cu`
- `L_rec`：重建 NMSE；
- `L_cm`：VQ 承诺损失；
- `L_lat`：ADM 隐补全监督，接收/掩码位置分开加权（`ω_m > ω_r`，更关注缺失位置）；
- `L_cu`：码字使用正则化，用软分配近似 + 与均匀分布的 KL 散度 `L_cu = log J − H(p̄)` 防止码本坍缩。
