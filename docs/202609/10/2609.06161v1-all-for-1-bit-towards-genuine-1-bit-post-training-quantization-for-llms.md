## 摘要
大语言模型（LLMs）已取得显著进展，但其庞大的存储与内存带宽需求仍阻碍高效部署。权值二值化是一种有前景的解决方案，但现有基于二值化的训练后量化（PTQ）方法通常由于隐藏开销而远超名义上的1比特存储目标。为弥补这一差距，我们提出 All for 1-Bit（AF1），一种面向 LLMs 的真正1比特 PTQ 框架。AF1 包含两个互补组件：（1）零空间感知二值分解（NABF），通过 Hessian 感知的代理重参数化、零空间感知二值分解以及仅尺度全局重构来改进二值重构；（2）层次化 Shapley 分配（HiSA），利用层次化 Shapley 敏感度分配结构容量。二者共同在 PTQ 设置下严格的 1.0-BPW 预算内保持模型精度。在 LLaMA、Qwen 和 Gemma 系列上的实验表明，AF1 在困惑度和零样本准确率方面始终优于现有基于二值化的 PTQ 方法。与 BF16 相比，AF1 在受评估模型上实现了平均 2.5 倍的推理加速和超过 90% 的内存降低，为 LLMs 实现可部署的真正1比特压缩提供了实用路径。用于复现的代码可在 https://github.com/Kishon-zzx/AF1 获取。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

- **核心问题**：权值二值化理论上可实现 1-bit 存储与位级计算，但现有基于二值化的 PTQ 方法（BiLLM、ARB-LLM、STBLLM、HBLLM 等）为补偿精度损失，通常引入缩放因子、分组统计、显著列掩码、残差二值张量、稀疏索引等辅助元数据，导致端到端有效 BPW 常达 2–4 bit，远高于名义 1-bit。

- **整体含义**：论文旨在实现“真正的 1-bit PTQ”，即在严格 1.0 effective-BPW 预算下，不依赖重型辅助元数据或昂贵重训练，仍能保持 LLM 精度与可用性。作者指出两大障碍：
  - 单矩阵二值化 `W ≈ αB` 表达能力有限，难以拟合 LLM 权重的复杂幅度分布与结构相关性。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架 AF1

- AF1 由两个互补组件构成：
  - **NABF（Null-space-Aware Binary Factorization）**：提升二值重构精度，抑制离散投影误差。
  - **HiSA（Hierarchical Shapley Allocation）**：在全局与层内子模块间分层分配结构容量。
- 目标：在 PTQ 设置下，对目标线性权重维持严格 1.0 effective-BPW 预算，同时尽量保持模型精度。

### 2.2 NABF：零空间感知二值分解

- **Hessian 感知代理重参数化**：
  - 使用 K-FAC 启发的对角近似，基于输入激活 `x` 与输出梯度 `g` 构造输入重要性 `i_j = sqrt(E[x_j^2])`、输出重要性 `o_u = sqrt(E[g_u^2])`。
  - 将原权重重参数化为代理空间权重：`W' = o ⊙ W ⊙ i^T`，把 Hessian 加权重构转化为代理空间中的 Frobenius 重构，使后续二值分解更关注任务敏感通道。
- **双因子二值分解**：
  - 将 `W'` 近似为两个二值符号矩阵与连续缩放向量的乘积：
    `W' ≈ (a ⊙ A±1 ⊙ m1^T)(m2 ⊙ B±1 ⊙ b^T)`。
  - 其中 `A±1`、`B±1` 为 `{−1,+1}` 二值矩阵，`a, m1, m2, b` 为全精度缩放向量。
  - 相比单矩阵二值化，双因子结构引入中间二值路径空间，可表达非可分幅度模式，提升 1-bit 预算下的表示能力，且主要参数仍为二值。
- **ADMM-SVID 优化与零空间补偿**：
  - 固定一个因子，用 ADMM 求解连续代理，再用 SVID 投影回二值缩放域。
  - SVID 投影产生离散残差 `E_A = Â − A_q`，实际扰动为 `E_A B`。
  - 若残差位于固定因子 `B` 的近似左零空间，则 `E_A B ≈ 0`，投影误差在传播中被抵消。
  - 通过 `C_B = BB^T` 的零/近零特征子空间构造近似零空间投影 `P_B`，满足 `P_B B ≈ 0`。
  - 定义补偿目标 `A_target = Â − E_A P_B`，再通过列尺度最小二乘拟合修正向量：
    `γ* = diag(A_q^T A_target) / diag(A_q^T A_q)`，并折叠进中间缩放向量 `m1 ← m1 ⊙ γ*`。
  - 该操作不改变二值符号矩阵，也不增加推理计算图；右因子更新对称处理。
- **仅尺度全局重构**：
  - 冻结所有二值符号矩阵，仅优化各层缩放向量 `S = {a, m, b}`。
  - 以全精度模型为教师，最小化压缩模型与教师 logits 的 KL 散度：
    `min_S E_X [D_KL(softmax(z_T(X)) || softmax(z_Q(X;S)))]`。
  - 可训练参数量从 `O(d_out r + r d_in)` 降至 `O(d_out + r + d_in)`，在保持 1-bit 参数化的同时缩小性能差距。

### 2.3 HiSA：分层 Shapley 分配

- **层级别粗粒度预算分配**：
  - 将层间维度分配建模为结构容量合作博弈。
  - 对层子集 `S`，保留原始中间维度 `r_orig`，其余层降级为代理维度 `r_proxy`，以端到端 token 级 NLL 作为价值函数 `v_NLL(S)`。
  - 通过 Monte Carlo 排列采样估计每层 Shapley 值 `Φ_l`，即逐步降级层时引起的 NLL 增量平均。
  - 用温度控制 softmax 将 Shapley 分数转为层预算：
    `B_l = B_total · exp(Φ_l/τ) / Σ_j exp(Φ_j/τ)`。
- **块级别细粒度分配与双敏感度 Shapley**：
  - 在每个层内，对子模块构造合作博弈，但分别测量两类失真：
    - 方向失真 `r_dir`：角度漂移，对 Q/K 等注意力匹配模式敏感。
    - 幅度失真 `r_mag`：相对激活能量变化，对 V/O、MLP 等残差注入分支敏感。
  - 使用单调累积误差 `Ê_c(S_t) = max(E_c(S_t), Ê_c(S_{t−1}))` 缓解偶然误差抵消导致的负边际。
  - 分别估计方向与幅度的模块级 Shapley 分数，用 MAD 稳健 Z-score 归一化，再经 sigmoid 映射。
  - 用 Soft-OR 融合两种失败模式：`v_base = 1 − (1 − P_dir)(1 − P_mag)`，避免任一脆弱模式被平均抑制。
  - 采用尺寸感知敏感度密度：`ω_i = (v_base / |W_i| + ε)^α`，再按层预算分配模块预算，缓解大模块主导预算的问题；最终将模块预算转为 NABF 使用的中间维度 `r_i`。

## 6. 主要结论与发现

- AF1 在严格 **1.0 effective-BPW** 目标线性权重预算下，实现了优于现有二值化 PTQ 方法的困惑度与零样本准确率。
