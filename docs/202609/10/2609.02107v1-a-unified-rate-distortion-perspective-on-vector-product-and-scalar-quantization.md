## 摘要
离散视觉标记化主要由向量、标量和乘积量化驱动，但缺乏理解量化权衡的统一概念框架。本文针对现代离散视觉标记化提出统一的率失真视角。通过将量化视为有损压缩，我们以标记数量和码本大小刻画名义固定长度编码速率，并将量化误差视为失真。在该框架内，我们解决了三个核心问题。首先，我们从理论和实证上表明，最小化失真而非最大化码本利用率，是重建保真度的首要内在目标，并且这与 STE 引起的梯度差异直接相关。其次，我们为内在量化比较建立了两个关键公平条件：控制潜在特征统计量并强制相同的编码率。第三，在这些条件下，我们恢复了现代视觉标记化中的 VQ--PQ--SQ 失真层级，并实证表明现代 VQ 方法实现了最低失真。这项工作为现代离散视觉标记化提供了基础性的率失真重构，解决了量化器评估中的歧义，并提供了一个在固定速率约束下隔离内在量化有效性的受控框架。

## Abstract
Discrete visual tokenization, predominantly driven by vector, scalar, and product quantization, lacks a unified conceptual framework for understanding quantization tradeoffs. In this paper, we propose a unified rate--distortion perspective on modern discrete visual tokenization. By viewing quantization as lossy compression, we characterize the nominal fixed-length coding rate through token count and codebook size, and quantization error as the distortion. Within this framework, we resolve three central questions. First, we theoretically and empirically show that minimizing distortion, rather than maximizing codebook utilization, is the primary intrinsic objective for reconstruction fidelity, with a direct connection to the STE-induced gradient discrepancy. Second, we establish two critical fairness conditions for intrinsic quantization comparison: controlling latent feature statistics and enforcing identical coding rates. Third, under these conditions, we recover the VQ--PQ--SQ distortion hierarchy in modern visual tokenization and show empirically that modern VQ methods achieve the lowest distortion. This work provides a foundational rate--distortion reframing of modern discrete visual tokenization, resolves ambiguities in quantizer evaluation, and provides a controlled framework for isolating intrinsic quantization effectiveness under fixed-rate constraints.

## 一、核心问题与整体含义

- **研究背景**：离散视觉分词（discrete visual tokenization）已成为视觉生成的核心技术，主流方法包括向量量化（VQ）、乘积量化（PQ）与标量量化（SQ）。近年来大量 VQ 工作聚焦于缓解"码本坍缩"、提升码本利用率（codebook utilization）。
- **核心问题**：该领域缺乏统一的概念框架来理解"利用率—失真—量化有效性"三者关系。**高码本利用率甚至 100% 利用率，并不必然意味着对输入的高保真表示**。此外，现有量化器比较往往在独立训练的、架构/数据/算力各异的 tokenizer 系统间进行，无法隔离量化算法本身的内在有效性。
- **整体含义**：作者提出将量化视为**有损压缩**，用率失真理论统一刻画离散视觉分词，回答三个核心问题：
  - **Q1**：量化算法本质上应优化什么？
  - **Q2**：公平的内在比较需要什么条件？
  - **Q3**：在受控条件下，VQ、PQ、SQ 的可达失真如何比较？
- **理论定位**：论文明确说明，Proposition 3 的 K^{-2/d} 缩放与 Zador 经典渐近量化定理指数一致，属于有限 K 的最坏情况结果；**主要理论创新在于 Proposition 4 给出的、依赖块数 M 的显式非渐近 VQ–PQ 分离下界**。

## 二、方法论

### 1. 率失真框架的基本定义
- **名义固定长度编码率**：$R = T \log_2 K$ 比特，其中 $T$ 为 token 数，$K$ 为离散码空间基数。
  - VQ 中 $K$ 为码向量数；PQ/SQ 中 $K = \prod_m n_m$ 为**复合码空间基数**，而非显式存储的码向量数。
- **量化失真**：$E(P, Q_\phi) = \mathbb{E}_{X \sim P}[\|X - Q_\phi(X)\|_2^2]$，即期望平方欧氏误差。
- **率分配的等价性**（Remark 1）：$2T \log_2 K = T \log_2 K^2$，即加倍 token 数与平方码本大小在名义预算上等价；但论文在实验中采用更强条件 $T_A = T_B$ 且 $K_A = K_B$。

### 2. 核心命题一：失真最小化是首要目标（Q1）
- **Proposition 2(a)**：在 Assumption 1（非退化可分裂性，标准连续分布满足）下，若不存在至多 K 个码字的零失真量化器，则**任意全局失真最小化器都必然满码本利用** $U(f^\star) = 1$。
- **Proposition 2(b)**：反之不成立——存在满利用率但非失真最优的量化器（文中以 $X \sim \text{Unif}[0,1]$、$K=2$ 构造反例：均匀切分 $E=1/48$，而 $9:1$ 切分虽满利用率但 $E=73/1200 > 1/48$）。
- **与 STE 梯度差异的联系**（附录 E）：在局部二阶可微假设下，STE 引起的梯度差距满足 $G = \|H(z_q)(z_e - z_q)\|_2^2 + o(\|\cdot\|^2) = O(\|z_e - z_q\|_2^2)$，即**梯度差距随失真平方衰减**，为"降低失真有利于优化稳定性"提供了机制解释。

### 3. 核心命题二：公平比较的两个条件（Q2）
- **Condition 1（匹配隐分布）**：由 Proposition 5，全局缩放 $X' = aX$ 使最优失真满足 $E^\star(aX, K) = a^2 E^\star(X, K)$；位置-尺度族下 $E^\star(\mu + \sigma Z, K) = \sigma^2 E^\star(Z, K)$。因此**隐特征统计量不同会直接混淆量化器比较**。
- **Condition 2（匹配名义率）**：必须固定 $R = T \log_2 K$；论文在实验中进一步采用 $T_A = T_B$ 且 $K_A = K_B$ 的更强控制。

### 4. 核心命题三：VQ–PQ–SQ 失真层级（Q3）
- **结构嵌套关系**：$\text{SQ} \subseteq \text{PQ} \subseteq \text{VQ}$（SQ 是 PQ 在 $M=d$ 的特例，PQ 是笛卡尔积结构的 VQ），因此最优失真满足
  $$E^\star_{VQ}(P,K) \le E^\star_{PQ}(P,K,M) \le E^\star_{SQ}(P,K)$$
- **Proposition 3（最坏情况）**：对 $P \in \mathcal{P}$（$[-1,1]^d$ 上所有分布），当 $K \ge 2^d$ 时
  $$\frac{d}{8}K^{-2/d} \le \sup_P E^\star_{VQ}(P,K) \le \sup_P E^\star_{SQ}(P,K) \le 4dK^{-2/d}$$
  即三种方法在最坏情况下失真均按 $\Theta(d/K^{2/d})$ 缩放，仅相差常数因子。
- **Proposition 4（低维结构分离）**：若 $P$ 支撑在 $d_{\text{eff}} < d$ 维子空间上，则
  $$E^\star_{VQ}(P,K) \le \frac{4d}{d_{\text{eff}}}K^{-2/d_{\text{eff}}}$$
  而对轴不对齐的一维线性子空间分布，有 $E^\star_{PQ}(P,K,M) \ge \frac{M}{4}K^{-2/M}$，$E^\star_{SQ}(P,K) \ge \frac{d}{4}K^{-2/d}$。
  **含义**：VQ 可利用内在低维结构获得严格更优的失真缩放，而固定坐标分解的 PQ/SQ 无法利用该结构。

## 六、主要结论与发现

1. **失真最小化优于利用率最大化**：
   - 理论上，失真最小化在温和条件下蕴含满码本利用，反之不成立。
   - 实证上，失真与 r-FID 的 Spearman 相关近乎完美（ImageNet：$\rho=0.996$，$p<10^{-8}$；FFHQ：$\rho=0.979$；CelebA-HQ：$\rho=0.944$；像素空间：$\rho=0.947$），而利用率相关性弱且部分不显著（ImageNet：$\rho=-0.540$，$p=0.057$）。
   - 多个 PQ/SQ 方法达到 100% 利用率但失真更高、重建更差。

2. **公平比较的两个条件成立且必要**：隐分布缩放会以 $a^2$ 比例改变最优失真；不同编码率下的比较无法隔离量化器本身。

3. **VQ–PQ–SQ 失真层级在受控条件下被恢复**：
   - ImageNet-1K：MMD VQ $E=0.201$ < 最佳 PQ $0.209$ < 最佳 SQ $0.231$；适配后 r-FID 分别为 0.86 / 0.93 / 1.07。
   - 跨数据集与像素空间一致复现该层级。
   - 率失真曲线显示 VQ 在**每一个率点**均保持最低失真。

4. **VQ 可利用低维源结构**获得严格优于 PQ/SQ 的失真缩放（Proposition 4），这解释了现代 VQ 方法在受控条件下反超早期研究中"VQ 因码本坍缩而劣于 SQ/PQ"的现象。

## 七、优点

- **统一框架**：首次系统地将离散视觉分词纳入率失真视角，给出清晰的名义率与失真定义，澄清了"利用率 ≠ 保真度"的长期混淆。
- **理论—实证闭环**：Proposition 2 建立失真与利用率的偏序关系，Proposition 4 给出显式、有限 K、依赖块数 $M$ 的 VQ–PQ 分离下界，实验又在受控条件下验证了理论层级。
- **公平比较方法论**：提出两个可操作的公平条件（匹配隐分布 + 匹配名义率），并通过 VQ-Transplant 冻结编解码器实现强控制，实验设计严谨。
- **多维度验证**：跨 3 个数据集 + 像素空间 + 多组率失真消融 + 相关性统计分析，结论稳健。
- **STE 梯度差距的局部理论联系**（$G = O(\|z_e - z_q\|_2^2)$）为"降低失真改善优化"提供了机制解释。
- **诚实的理论定位**：明确区分经典结果（Zador 定理）与自身贡献（Proposition 4），避免夸大创新性。

## 八、不足与局限

- **率类型限制**：仅考虑**名义固定长度率** $R = T \log_2 K$，未覆盖熵编码下的期望码率、变长编码与自适应比特分配，与经典率失真优化仍有距离。
- **失真度量单一**：仅用平方欧氏误差，未涉及感知、语义或任务相关失真；理论层级针对各族的**最优可达失真**，不保证有限数据/有限优化下所有实际 VQ 都优于 PQ/SQ。
- **理论命题的分布假设较强**：Proposition 3 的 worst-case 结果与 Proposition 4 的一维轴不对齐源，未在实验中直接构造对应分布进行数值验证。
- **实验覆盖有限**：
  - PQ 仅测试 $M=2$ 一种块划分，未探索不同 $M$ 的影响。
  - 像素空间实验缺少 Online VQ（OOM），方法覆盖不完全。
  - 未报告总 GPU 小时数，训练成本可比性不足。
- **下游生成性能未涉及**：结论仅限**重建保真度**，作者明确指出更好的重建不必然带来更好的生成质量，两者关系仍是开放问题。
