## 摘要
大语言模型（LLMs）已取得显著进展，但其庞大的存储和内存带宽需求仍然阻碍高效部署。权值二值化是一种有前景的解决方案，但现有的基于二值化的训练后量化（PTQ）方法通常由于隐藏开销而远超名义上的1比特存储目标。为弥补这一差距，我们提出 All for 1-Bit（AF1），一种面向LLMs的真正1比特PTQ框架。AF1包含两个互补组件：（1）零空间感知二值分解（NABF），通过Hessian感知的代理重参数化、零空间感知二值分解和仅尺度全局重构来改进二值重构；（2）分层Shapley分配（HiSA），利用分层Shapley敏感度分配结构容量。二者共同在PTQ设置下严格1.0-BPW预算内保持模型精度。在LLaMA、Qwen和Gemma系列上的实验表明，AF1在困惑度和零样本准确率上持续优于现有的基于二值化的PTQ方法。与BF16相比，AF1在评估模型上平均实现2.5倍推理加速和超过90%的内存降低，为LLMs可部署的真正1比特压缩提供了实用路径。可复现性代码见 https://github.com/Kishon-zzx/AF1。

## Abstract
Large language models (LLMs) have achieved remarkable progress, yet their massive storage and memory-bandwidth demands still hinder efficient deployment. Weight binarization is a promising solution, but existing binarization-based post-training quantization (PTQ) methods usually far exceed the nominal 1-bit storage target due to hidden overhead. To address this gap, we propose All for 1-Bit (AF1), a genuine 1-bit PTQ framework for LLMs. AF1 comprises two complementary components: (1) Null-space-Aware Binary Factorization (NABF) for improving binary reconstruction through Hessian-aware surrogate reparameterization, null-space-aware binary factorization, and scale-only global reconstruction; and (2) Hierarchical Shapley Allocation (HiSA) for assigning structural capacity using hierarchical Shapley sensitivity. Together, they preserve model accuracy under a strict 1.0-BPW budget in the PTQ setting. Experiments on LLaMA, Qwen, and Gemma families show that AF1 consistently outperforms existing binarization-based PTQ methods in perplexity and zero-shot accuracy. Compared with BF16, AF1 achieves an average 2.5 times inference speedup and over 90% memory reduction across evaluated models, providing a practical path toward deployable genuine 1-bit compression for LLMs. The code for reproducibility is available at https://github.com/Kishon-zzx/AF1.

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体框架
AF1 = **NABF**（零空间感知二值分解，提升二值重建精度）+ **HiSA**（分层 Shapley 分配，优化结构预算）。

### 2.2 NABF：Null-space-Aware Binary Factorization
- **Hessian 感知代理重参数化**：
  - 用 K-FAC 风格对角近似构造输入/输出重要性向量：$i_j = \sqrt{E[x_j^2]}$（输入激活）、$o_u = \sqrt{E[g_u^2]}$（输出梯度）。
  - 重参数化：$W' = o \odot W \odot i^\top$，把 Hessian 加权重建转化为代理空间的 Frobenius 目标，使后续二值分解侧重任务敏感通道。
- **双因子二值参数化**（提升表达力）：
  - $W' \approx (a \odot A_{\pm1} \odot m_1^\top)(m_2 \odot B_{\pm1} \odot b^\top)$，其中 $A_{\pm1}, B_{\pm1}$ 为二值符号矩阵，其余为全精度缩放向量。
  - 附录证明：单因子二值化的幅值矩阵秩为 1（须满足乘法一致性约束），而双因子形式可表示非可分离幅值模式（如 2×2 例中幅值矩阵行列式 = 2 ≠ 0），表达能力严格更强。
  - 使用 DBF 的 ADMM-SVID 框架优化：固定一因子，ADMM 求解连续代理，SVID 投影回二值缩放域。
- **零空间感知补偿（核心创新）**：
  - SVID 离散投影残差 $E_A = \hat{A} - A_q$，实际扰动是 $E_A B$ 而非 $E_A$ 本身；若 $E_A$ 落在 $B$ 的左零空间，则 $E_A B \approx 0$。
  - 用无中心协方差 $C_B = BB^\top$ 的零特征子空间等价于 $B$ 的左零空间；SVD 后按**自适应残差能量比 cutoff** $\eta = 0.01$ 选取尾部奇异向量，构造近似投影 $P_B = \hat{U}\hat{U}^\top$，满足 $P_B B \approx 0$。
  - 定义补偿目标：$A_{target} = \hat{A} - E_A P_B$，保持前向传播行为不变。
  - 通过**闭式最小二乘**将补偿吸收进中间缩放向量：$\gamma^* = \mathrm{diag}(A_q^\top A_{target}) / \mathrm{diag}(A_q^\top A_q)$，再令 $m_1 \leftarrow m_1 \odot \gamma^*$；右因子对称处理。
  - **不改变二值符号矩阵，也不增加推理计算图或稠密参数**。
- **仅尺度全局重建**：
  - 冻结全部二值符号矩阵，仅优化缩放参数 $S = \{a^{(l)}, m^{(l)}, b^{(l)}\}$。
  - 以全精度模型为教师，最小化 KL 散度：$\min_S \mathbb{E}_X[D_{KL}(\mathrm{softmax}(z_T) \| \mathrm{softmax}(z_Q; S))]$。
  - 可训练参数量从 $O(d_{out} r + r d_{in})$ 降至 $O(d_{out} + r + d_{in})$。

### 2.3 HiSA：Hierarchical Shapley Allocation
- **层级别粗粒度分配（Progressive Shapley）**：
  - 构造结构容量博弈：$v_{NLL}(S) = \mathbb{E}[-\log p(x_{t+1}|x_{\le t}; S)]$，集合 $S$ 中层保留原始维度、其余降级到 proxy 维度。
  - 用 Monte Carlo 排列估计 Shapley 值 $\Phi_l = \frac{1}{M}\sum_m \Delta v_l^{(m)}$，衡量全局交互（跨层误差传播/补偿）。
  - 温度软最大化转预算：$B_l = B_{total} \cdot \exp(\Phi_l/\tau) / \sum_j \exp(\Phi_j/\tau)$。
- **模块级别细粒度分配（Dual-Sensitivity Shapley）**：
  - 区分**方向畸变** $r_{dir}$（角度漂移，对 Q/K 注意力匹配关键）与**幅值畸变** $r_{mag}$（激活能量偏移，对 V/O 与 MLP 残差注入关键），分别估计 Shapley 边际贡献。
  - 用单调累积误差 $\hat{E}_c(S_t) = \max(E_c(S_t), \hat{E}_c(S_{t-1}))$ 抑制负边际（误差抵消）。
  - MAD 稳健 Z-score 归一化 → Sigmoid 映射 → **Soft-OR 融合** $v_{base} = 1 - (1-P_{dir})(1-P_{mag})$，避免任一失效模式被平均抑制。
  - **尺寸感知敏感度密度**：$\omega_i = (v_{base}/|W_i| + \epsilon)^\alpha$，防止大模块因参数多而主导预算；按层预算 $B_l$ 加权分配 $b_i$。
- **预算→秩转换**：$r_i = \mathrm{Round}(b_i d_{out} d_{in} / (d_{out} + d_{in}))$。
- **有效 BPW 定义**：仅计入二值符号因子与 BF16 缩放向量，**不含显著列掩码、分组位图、残差二值张量或稀疏索引**，从而严格控制在 1.0 BPW。
