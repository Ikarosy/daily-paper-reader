## 摘要
键值（KV）缓存已成为长上下文 LLM 推理中的主要内存瓶颈，给内存容量和带宽带来了巨大压力。为缓解这一瓶颈，向量量化（VQ）已成为一种有前景的激进 KV 缓存压缩方法。然而，现有 VQ 方法在 1 比特场景下性能显著下降。在如此极端的压缩下，每个码本必须以有限的一组质心表示更大的一组通道，使得有效利用其容量变得愈发困难。为解决这一问题，我们提出了 $\textbf{TaSQ}$，它通过结合查询引导的通道加权、跨头归一化和协方差感知的通道分组来定制 VQ 目标空间，从而更好地反映缓存激活的误差敏感性和统计结构。由于这些变换与 RoPE 兼容，并且可以轻松合并到投影权重和码本中，TaSQ 保留了传统 VQ 查找结构，并增加了可忽略的推理服务开销。在通用、长思维链推理和长上下文检索基准上，TaSQ 始终优于现有的低位 KV 缓存 VQ 基线，同时保持推理稳定性。在单个 RTX 6000 Ada GPU 上，其 SGLang 实现支持高达 $14\times$ 的更大批大小，并相比 BF16 基线实现了 $1.87\times$ 的更高峰值吞吐量。

## Abstract
The key-value (KV) cache becomes a major memory bottleneck in long-context LLM inference, placing substantial pressure on memory capacity and bandwidth. To mitigate this bottleneck, vector quantization (VQ) has emerged as a promising approach for aggressive KV cache compression. However, existing VQ methods degrade substantially in the 1-bit regime. At such extreme compression, each codebook must represent a larger group of channels with a limited set of centroids, making effective use of its capacity increasingly challenging. To address this, we introduce $\textbf{TaSQ}$, which tailors the VQ target space by combining query-guided channel weighting, cross-head normalization, and covariance-aware channel grouping to better reflect the error sensitivity and statistical structure of cached activations. Since these transforms are RoPE-compatible and can be easily merged into projection weights and codebooks, TaSQ preserves the conventional VQ lookup structure and adds negligible serving overhead. Across general, long-chain-of-thought reasoning, and long-context retrieval benchmarks, TaSQ consistently outperforms existing low-bit KV cache VQ baselines while preserving reasoning stability. On a single RTX 6000 Ada GPU, its SGLang implementation supports up to $14\times$ larger batch sizes and achieves $1.87\times$ higher peak throughput compared to the BF16 baseline.

- **研究背景**：长上下文 LLM 推理中，KV cache 随序列长度线性增长，并在自回归解码中被反复读取，成为显存容量与带宽的主要瓶颈。
- **核心问题**：向量量化（VQ）适合超低比特 KV cache 压缩，但在 **1-bit 每通道** 的极端压缩下，每个码本需用有限质心表示更多通道，现有 VQ 方法性能显著退化。
- **关键洞察**：
  - 不同 key 通道的重建误差对注意力 logits 的影响不同，误差敏感度不均。
  - VQ 只有将相互依赖的通道放入同一码本/分组，才能利用通道间相关性。
  - RoPE 会显著扩散 key 分布，pre-RoPE key 比 post-RoPE key 更紧凑，更适合 VQ。
- **整体含义**：论文提出 **TaSQ**，通过“定制 VQ 目标空间”而非简单压缩原始空间，在 1-bit 级别提升 KV cache 压缩质量，同时保持接近传统 VQ 的推理服务效率。

## 2. 方法论
### 2.1 核心思想
- 在 VQ 之前对 pre-RoPE key 做三类变换：**查询引导通道加权**、**跨头共享尺度归一化**、**协方差感知通道分组**，使量化空间更符合注意力误差敏感性与通道统计结构。
- 变换仅涉及通道缩放与置换，兼容 RoPE，并可离线合并进投影权重和码本；运行时保留传统 VQ 查表结构。

### 2.2 关键技术细节
- **查询引导通道加权**：
  - 将 post-RoPE query 的 QK 误差矩阵 \(A_{t,p,h}=R_p^\top \bar q_{t,h}\bar q_{t,h}^\top R_p\) 在校准集上平均，取对角近似 \(\tilde A_h\)。
  - 定义 \(W_h=\mathrm{diag}(\tilde A_h)\)，对 key 做 \(k^w_{p,h}=W_h^{1/2}k_{p,h}\)，使欧氏 VQ 重建目标隐式加权查询敏感通道。
- **跨头共享尺度归一化**：
  - 对加权 key 计算所有 KV 头共享的 token 级 RMS 尺度：
    \[
    s_p=\left(\frac{1}{Hd}\sum_{h=1}^H\|k^w_{p,h}\|_2^2\right)^{1/2},\quad
    k^{wn}_{p,h}=k^w_{p,h}/s_p
    \]
  - 相比逐头 scale，跨头共享 scale 将元数据成本从 \(b_s/d\) 降至 \(b_s/(Hd)\)，节省比特用于码本索引。
- **协方差感知通道分组**：
  - 在校准集上估计加权归一化 key 的协方差 \(\Sigma^{wn}_h\)。
  - 对候选通道组 \(G\) 定义成本：
    \[
    c_h(G)=\det(\Sigma^{wn}_h[G,G]+\epsilon I)^{1/|G|}
    \]
    该成本受高斯高码率 VQ 率失真理论启发，作为量化误差代理。
  - 约束 RoPE 成对通道必须同组，采用 **层次最小权完美匹配** 近似求解分组，直到每组含 \(g\) 个通道。
  - 分组后得到置换矩阵 \(P_h\)，使每组通道连续：
    \[
    k^{wnp}_{p,h}=P_hW_h^{1/2}k_{p,h}/s_p
    \]
- **定制空间中的 VQ**：
  - 对每个 layer、KV head、通道组分别训练 \(K\)-质心码本。
  - 使用 Fisher 加权 k-means，按校准 token 的语言建模损失敏感度加权。
- **运行时重建**：
  - 将 \(P_hW_h^{1/2}\) 吸收进 key 投影，将逆加权/逆变换吸收进码本；query 投影也置于置换坐标系，RoPE 频率按成对布局重排。
  - 推理时只需码本查表
