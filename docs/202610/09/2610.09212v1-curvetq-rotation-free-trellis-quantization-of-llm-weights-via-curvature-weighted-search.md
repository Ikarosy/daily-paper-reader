## 摘要
面向大语言模型的最佳二比特权重量化器（如 QTIP 和 Proteus）会先用随机正交变换旋转每个权重矩阵，而该变换在每一步解码时都必须撤销，然后在欧氏搜索下用网格码或格码对其进行编码；层 Hessian 仅通过编码块之间的误差反馈参与其中。我们表明，这样做会使 Hessian 的一部分信息未被利用。误差反馈将损失转化为逐坐标舍入误差的加权和，其权重是 Hessian 的 LDL 分解的对角线；现有量化器会计算这些权重，却从不读取它们。我们将这些权重放入 Viterbi 分支度量中，使搜索在每一个编码块内遵循曲率。这也解释了旋转的作用：它消除了这种块内变化，因此在原始基下加权与旋转是相互替代的。在三个模型上，加权后的原始基搜索与全维随机 Hadamard 变换在下游精度上相差约一个点以内，而在旋转后再加权几乎没有增益。围绕这一搜索，我们构建了 CurveTQ，一种无需旋转的网格编解码器；它通过因子化尺度场和闭式分位数表来处理权重的幅度与边缘分布形状，并为每个编码块存储一个起始状态，使网格能够适应误差反馈带入其中的残差。在二比特下，CurveTQ 在三个 4-8B Instruct 模型上的平均下游准确率比 QTIP 和 Proteus 高 1-3 个点，即使在二者都获得我们的起始状态后也是如此；而仅此起始状态就能将任一基线提升 1-3 个点。它在一个 35B 混合专家模型上也取得领先，据我们所知，这是此类模型上的首个网格编码结果。由于无需撤销旋转，我们的解码器在所有测试的批大小和比特宽度下都是三者中最快的。

## Abstract
The best two-bit weight quantizers for large language models, such as QTIP and Proteus, rotate each weight matrix by a random orthogonal transform, which must be undone at every decoding step, then encode it with a trellis or lattice code under a Euclidean search; the layer Hessian enters only through error feedback between coding blocks. We show that this leaves part of the Hessian unused. Error feedback turns the loss into a weighted sum of per-coordinate rounding errors whose weights, the diagonal of the Hessian's LDL factorization, existing quantizers compute but never read. We put these weights into the Viterbi branch metric, so the search follows the curvature within each coding block. This also explains the rotation: it removes this within-block variation, so weighting in the native basis and rotating are substitutes. On three models the weighted native search matches a full-dimension randomized Hadamard to within about one point of downstream accuracy, and weighting after the rotation gains little. Around this search we build CurveTQ, a trellis codec with no rotation, which handles the weights' amplitude and marginal shape with a factored scale field and a closed-form quantile table, and stores a start state per coding block so the trellis can adapt to the residual that error feedback carries into it. At two bits CurveTQ is 1-3 points higher in mean downstream accuracy than QTIP and Proteus on three 4-8B Instruct models, even after both are given our start state, which alone lifts either baseline by 1-3 points. It also leads on a 35B mixture of experts, to our knowledge the first trellis-coded result on such a model. With no rotation to undo, our decoder is the fastest of the three at all tested batch sizes and bit widths.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 逐 token 解码时，瓶颈是权重从显存读出的带宽，因此"每权重存多少比特"直接决定解码速度。4-bit PTQ 已成熟，2–3 bit 仍是开放前沿，此时**码（code）的设计**——如何把一组权重联合映射为少量索引——比标量网格更重要。
- **现有最强 2-bit 方案（QTIP、Proteus）共用同一套"transform-and-flatten"三步配方**：
  1. 对每个权重矩阵施加随机正交旋转，使元素近似独立高斯；
  2. 在欧氏搜索下用 trellis / lattice 码编码；
  3. 层 Hessian 只通过**编码块之间的误差反馈**（block LDLQ）参与。
- **代价**：旋转必须在每一步解码时撤销（作用于激活或权重解码路径），带来额外开销。
- **核心洞察（问题所在）**：误差反馈只把损失重排为"逐坐标舍入误差的加权和"，其权重正是 **Hessian 的 LDL 分解对角元 D**（GPTQ 用来归一化残差的同一量）。QTIP 会算出它的块形式却**从不读取**；块内搜索仍按无权重欧氏距离最小化，导致 Hessian 信息被浪费。
- **整体含义**：把 D 放进 Viterbi 分支度量后，搜索可在块内沿曲率走。而这同时解释了旋转的作用——旋转把块内曲率变化抹平了，因此**"原始基下加权"与"旋转"是替代品**，从而可以构建一个**无旋转的 trellis 编解码器**，同时拿到精度与解码速度收益。

## 2. 方法论

### 2.1 核心思想
- 用误差反馈恒等式：`eᵀHe = Σᵢ Dᵢηᵢ²`（对任意量化器、任意码成立）。其中 `η = (I+Ū)ᵀe`，`H = (I+Ū)D(I+Ū)ᵀ`。
- 把 `ωᵢ = 1/dᵢ² = Dᵢ`（dᵢ 为 H⁻¹ 的 Cholesky 因子对角元，即 GPTQ 的误差归一化常数）放进 Viterbi 分支度量：
  - `P* = argmin Σ_{i∈b} ωᵢ [z̃ᵢ − T(kᵢ(P))]²`
- **代价不变**：目标对坐标可加，Viterbi 精确最小化；打包格式与欧氏搜索（ω≡1）完全一致——权重只改变选哪条路径，不改变怎么存。

### 2.2 关键技术细节
- **块局部 trellis + 显式起始状态**：以 G=64 列为一块，每块 Viterbi 可从 2^L 个状态中任选起点，并把所选状态存为 L 比特 / (行, 块)。边界自适应率 `L/G = 14/64 = 0.219 bpw`，是所有报告速率中最大的一项。QTIP 用 tail-biting 把首尾绑定、不存状态；但误差反馈下**块边界恰是继承残差落点**，绑定首坐标是错误约束。
- **发射结构**：采用 14-bit 状态的**边发射（Mealy）形式**（从 (sₜ, aₜ) 发射），搜索 2¹⁴ 个存活路径（QTIP 为 2¹⁶），在 k=2 时窗口同为 16 bit，经验证代价与重建完全一致。
- **为何旋转变得不必要**：旋转同时抹平三样东西——局部幅度、边缘分布形状、块局部 LDL 对角。但它**并不真正抹平 D**，而是把它变成沿编码序的平滑斜坡，**在 64 列块内近乎平坦**。块内近似常数的权重不改变路径选择，故旋转后加权与欧氏搜索近乎重合。
- **理论刻画（Proposition 1）**：
  - (i) 损失恒等式；
  - (ii) 若残差二阶矩相等，`E[eᵀHe] = σ²tr(D) ≥ Cσ²GM(D) = Cσ²det(H)^{1/C}`，当且仅当所有 Dᵢ 相等取等；
  - (iii) 高分辨率率模型下该下界可达（步长 ∝ Dᵢ^{-1/2}）。
  - 由此定义各向异性 `Γ(H) = ½log₂(AM(D)/GM(D))` 比特，及块局部版 `Γ_b(H)`。**加权相对欧氏搜索的增益上限即 Γ_b**；旋转后 Γ'_b≈0，加权冗余。
  - 注意：**替代性不是定理**。Proposition 2 构造 HA/HB 两例证明两种排序对一般正定矩阵都不成立——这是关于**训练后 LLM Hessian 的经验假设**（其原生 D 被离群输入通道主导，块内各向异性大）。
- **CurveTQ 编解码器（无旋转）**：
  - **因子化尺度场**：把每 64 权重的尺度看作行 × 列组的二维场，存 fp16 行因子与列组因子（几何均值）+ 4-bit 线性网格残差（每 256 个残差一个 fp16 absmax），两级均向上取整保证 `ŝ ≥ s`。代价约 0.068 bpw（Qwen3-4B 0.068、Llama-3 0.067），远低于 fp16 尺度 0.25 bpw 或 int8 二级量化 0.125 bpw。
  - **闭式分位表**：每个编码层有自己的 128 项 int8 字母表（归一化权重样本的等概率分位点），由发射窗口的 7-bit 哈希索引，解码无插值；样本是层内 64 组的确定性跨步，构建对校准集完全确定。
  - **可选无表变体**：直接从发射窗口计算重建（类似 QTIP 的 1MAD），仅用一个全局尺度（九点线搜索定标）。
- **MoE**：编解码器原样适用，仅 Hessian 不同——每个专家用自己 token 的 `H⁽ᵉ⁾`（沿用 QMoE）。top-8/256 路由下每专家仅数千 token，H 常秩亏、被阻尼主导，故**加权度量在该场景接近欧氏**。

### 2.3 与向量量化路线的区别
- 格码/加性 VQ（AQLM、GPTVQ、VPTQ、SqueezeLLM 等）也优化输入加权误差，但解码需多次依赖式码本读取；本文是 **trellis 码，却优化向量量化的加权目标**，解码成本仍是 trellis 级（一次表读或无表读）。
