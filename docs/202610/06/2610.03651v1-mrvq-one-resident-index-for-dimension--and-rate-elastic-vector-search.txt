## Abstract 

Dense-retrieval services must switch among embedding-prefix dimensions and index bit rates as latency, quality, and memory budgets change. Tuning a quantizer separately for each rate gives the best quality, but the retrieval tier then holds several code streams and quantizer states at once. We introduce Matryoshka Residual Vector Quantization (MRVQ) , a post-hoc residual quantizer for frozen embed-dings. Its maximum-rate code can be truncated two ways: dropping residual stages lowers the rate, and dropping embedding coordinates lowers the dimension. One resident artifact therefore serves every (dimension, rate) pair we evaluate. Across FiQA and NFCorpus, four embedding families, and {4, 8, 16 }-byte codes, MRVQ is the lowest-RAM design we evaluate. It uses 17 .8–22 .0× less memory than three separately trained QINCo2 indices, and 1.89 –2.02 × less than a lean shared-model steelman. The saving is not free: per-rate QINCo2 is 0.026 –0.107 nDCG@10 better on FiQA. But MRVQ beats PQ, OPQ, and AdANNS-OPQ at matched code size. We also evaluate a low-build-cost PCA-scalar design that attains quality com-parable to RaBitQ and its extension while fitting 420 × faster at the median. Finally, we report two negative results: QINCo2 collapses when trained at high rates, and a ranking-bound hypothesis misses its pre-specified acceptance criteria. MRVQ is therefore a low-memory operating point for elastic retrieval, not a universal quality winner. 

## 1 Introduction 

Dense retrieval is a first-class component of retrieval-augmented generation and agentic systems. For large corpora, the document embeddings and index state—rather than the query encoder—often dominate resident memory: a 768 –1024 dimensional fp32 vector occupies 3–4 KB before indexing. That state must also support more than one operating point. Dimension elasticity uses prefixes of Matryoshka representations to trade retrieval quality for query compute and bandwidth [Kusupati et al., 2022, Rege et al., 2023]; rate elasticity changes the document code size to trade quality for storage. A high-quality deployment can tune a quantizer independently for each rate, but then the retrieval tier retains several code streams and model states at once. We ask whether a single resident document code can cover both axes. MRVQ fits a residual vector quantizer post-hoc on frozen embeddings, weighting reconstruction error across the served prefix dimensions. Residual stages provide nested rates, and coordinate prefixes provide nested dimensions, so the same stored code supports every (m, b ) ∈ M × B (Figure 1). This differs from AdANNS, which targets dimension-adaptive search, and from MatQuant, which nests model-weight precision rather than document-index codes [Nair et al., 2025]; Appendix E places MRVQ among quantizers for approximate search.

## 3 Evaluation 

We use FiQA ( 57 ,638 documents, 648 queries) and NFCorpus ( 3,633 documents, 323 queries) from BEIR [Thakur et al., 2021]. The four embedding families are MPNet [Reimers and Gurevych, 2019] (D = 768 ), Mxbai [Lee et al., 2024] ( D = 1024 ), Nomic [Nussbaum et al., 2024] ( D = 768 ), and BGE [Xiao et al., 2023] ( D = 768 ). Within each family, every method uses the same fixed, model-specific prefix menu M ⊆ { 128 , 256 , 384 , 512 , 768 , 1024 }, and a “menu mean” is the unweighted mean over that family’s evaluated prefix-rate cells. The prefix weights wm in Eq. (1) are uniform over 

M and all 16 residual stages are weighted equally; Appendix F lists the exact checkpoints, menus, and fitting budget. Rates are B = {4, 8, 16 } B/vector, or 192 –1024 × smaller than the corresponding fp32 vector before fixed quantizer overhead. The metric is nDCG@10. Learned baselines use matched fitting budgets, and their aggregated per-rate results reproduce the stored runs to floating-point tolerance (maximum absolute deviation 0

for MRVQ, 5 × 10 −17 for QINCo2). We use paired per-query bootstrap confidence intervals ( 5000 

resamples; 10 ,000 for the RaBitQ study). Decision thresholds for the negative-result tests were fixed before the final aggregate analyses. Reported RAM is analytical accounting from the byte formulas above—parameter and code bytes only, with no optimizer or runtime buffers—rather than measured process RSS. 

## 4 Results 

One artifact is the low-RAM corner. Table 1 prices the complete {4, 8, 16 } B/vector menu. MRVQ uses 12 .06 –16 .88 MiB and is the lowest-RAM configuration for all four families on both datasets. Relative to three separate QINCo2 models, the saving is 17 .8–22 .0×; relative to the leanest shared-model configuration (including reduced embedding width and fp16 variants), it is 1.89 –2.02 ×.The first ratio is largest at these on-device and per-tenant corpus scales because neural parameter state dominates the resident footprint (Appendix A). As n grows, the separate-model ratio approaches the 28 /16 = 1 .75 × code-stream ratio, while the shared-model gap becomes a fixed overhead and therefore less important; Figure 2(b) makes both limits explicit. 

Quality forms a two-corner Pareto. At matched code size, separately trained QINCo2 [Hui-jben et al., 2024, Vallaeys et al., 2025] beats MRVQ in every FiQA family-rate cell by 0.026 –

0.107 nDCG@10 (Appendix B). Conversely, even the shared-model QINCo2 steelman uses roughly 

1.9× MRVQ’s RAM at the evaluated corpus sizes. Figure 2(a) therefore shows two useful operating points rather than a single winner. The low-memory result repeats on NFCorpus for all four families. Against standard fixed-code ANN baselines, MRVQ is stronger at matched bytes. Across the aggressive 4–16 B/vector regime, paired-bootstrap intervals favor MRVQ over per-prefix OPQ by about 0.06 –0.07 nDCG@10, over PQ by 0.10 –0.12 , and over AdANNS-OPQ [Rege et al., 2023] in every evaluated cell. ## 5 Limitations and Conclusion 

Training reliability. On NFCorpus at 16 stages, per-rate QINCo2 suffers retrieval collapse— nDCG@10 below half the MRVQ value despite converged validation MSE—in 3/3 BGE seeds (best 

0.035 ) and 1/3 Nomic seeds. The best surviving Nomic seed is also non-monotone in rate: 0.294 at 

16 stages against 0.320 at 8. We retain these failures rather than silently dropping them. 

No ranking certificate. A parameter-free predictor based on residual energy is directionally useful but misses our pre-specified acceptance bar: pooled rank correlation is 0.825 against a required 0.85 ,and only 72% of cells yield a non-vacuous bound against a required 90% (Appendix D). 

Scope. The quality study covers two modest BEIR corpora and four embedding families. We measure resident memory and ranking quality, not end-to-end ANN latency, build energy, or recall– throughput curves; the RAM gains should not be read as speedups. At very large n the advantage over a shared-model baseline narrows as the accounting predicts. Within that scope, MRVQ converts a dimension-and-rate menu from several rate-specialized resident artifacts into one post-hoc code. It pays a measurable quality cost to QINCo2, but beats standard ANN quantizers at matched bytes and occupies a distinct low-memory Pareto point. That is the intended systems contribution: a simple deployment option for elastic retrieval when resident memory, rather than peak quality, is the binding resource. 4References

## E Related work 

PQ, OPQ, and additive quantization are standard fixed-rate compressors [Jégou et al., 2011, Ge et al., 2013, Babenko and Lempitsky, 2014]. QINCo/QINCo2 use implicit neural codebooks to improve rate–distortion performance [Huijben et al., 2024, Vallaeys et al., 2025]. RaBitQ and its extension provide scalar-quantization methods with error guarantees [Gao and Long, 2024, Gao et al., 2024]. Matryoshka representation learning and AdANNS expose dimension elasticity [Kusupati et al., 2022, Rege et al., 2023], while MatQuant nests model-weight bit widths [Nair et al., 2025]. MRVQ instead targets the resident document index: one post-hoc code is truncated along both the residual-stage and the embedding-coordinate axis. 7F Experimental configuration
