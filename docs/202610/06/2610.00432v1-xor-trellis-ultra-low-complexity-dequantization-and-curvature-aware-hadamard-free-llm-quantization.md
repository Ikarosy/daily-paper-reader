## 摘要
Trellis 编码量化使大语言模型（LLM）权重能够在超低位宽下进行高维压缩，而无需传统矢量量化所需的指数级大码本。然而，实际部署面临两个挑战：以足够的并行吞吐量重建压缩权重，以避免反量化成为推理瓶颈；以及在不进行昂贵的非相干变换的情况下保持量化精度。我们通过两项互补技术来应对这些挑战。首先，我们提出一种超低复杂度的 Trellis 反量化器，它采用结构化且硬件高效的状态到值映射，同时为 Trellis 搜索保留多样化的重建选择。其次，我们用曲率感知目标重新表述离散 Trellis 路径优化，该目标直接在原始坐标空间中反映模型敏感性。这些技术共同实现了高质量的超低位宽 Trellis 量化，其运行时重建成本低且高度并行，并且不依赖于基于 Hadamard 的非相干处理。

## Abstract
Trellis-coded quantization enables high-dimensional compression of large language model (LLM) weights at ultra-low bit widths without the exponentially large codebooks required by conventional vector quantization. Practical deployment, however, presents two challenges: reconstructing compressed weights at sufficient parallel throughput to avoid making dequantization an inference bottleneck, and maintaining quantization accuracy without costly incoherence transformations. We address these challenges with two complementary techniques. First, we introduce an ultra-low-complexity trellis dequantizer that uses a structured, hardware-efficient state-to-value mapping while preserving diverse reconstruction choices for trellis search. Second, we reformulate discrete trellis path optimization with a curvature-aware objective that reflects model sensitivity directly in the original coordinate space. Together, these techniques enable high-quality ultra-low-bit trellis quantization with inexpensive, highly parallel runtime reconstruction and without relying on Hadamard-based incoherence processing.

## 1. 核心问题与整体含义

- **背景**：LLM 推理受权重存储与内存带宽限制，权重-only 训练后量化（PTQ）在超低位宽下尤为关键。传统矢量量化（VQ）码本随维度指数增长；Trellis 编码量化（TCQ）通过有限状态路径耦合量化决策，仅存低位转移，可支持远超 VQ 的有效维度。
- **两大部署挑战**：
  - **反量化吞吐瓶颈**：压缩权重需在推理时并行重建；若每权重重建算术复杂，会抵消压缩带来的带宽收益。例如 QTIP 的 3INST 反量化器需大量算术、逻辑与数据操作。
  - **非相干变换依赖**：RHT/Hadamard 等旋转可分散离群值、使欧氏路径度量更接近模型敏感目标，但不可吸收的在线旋转会引入推理开销。
- **核心洞察**：Trellis 对 RHT 的敏感并非本质，部分源于**二阶 PTQ 的模型感知目标与离散 Trellis 路径搜索的各向同性欧氏目标之间的不匹配**。RHT 通过让敏感度更均匀来掩盖该不匹配。
- **整体含义**：提出 XOR-Trellis，一种硬件-算法协同设计，实现超低复杂度、高并行、免 Hadamard 的超低位宽 LLM 权重 Trellis 量化。

## 2. 方法论

### 2.1 XOR-Trellis FP4 反量化器

- **Trellis 设置**：K=2 bitshift trellis，每步 2 bit 分支（4 个分支），16-bit 状态 = 14-bit 历史 h + 2-bit 当前分支 b。
- **局部重建调色板**：为固定历史 h 提供 4 个数值不同的重建选择，避免名义分支浪费。FP4 实现使用四个调色板：
  - P0 = [−6, −1.5, 0, 2]
  - P1 = [−4, −1, 0.5, 3]
  - P2 = [−3, −0.5, 1, 4]
  - P3 = [−2, 0, 1.5, 6]
- **XOR 映射**：四个掩码奇偶函数从 14-bit 历史产生 p0,p1,q0,q1：
  - p = p0 | (p1 << 1) 选择调色板；
  - b′ = b ⊕ (q0 | (q1 << 1)) 对分支身份做历史相关置换；
  - ŵ = P_p[b′]。
  - 使用掩码 {0x1089, 0x2112, 0x0A24, 0x2441}。
- **理论性质**：
  - 在固定 16 个 FP4 标签、四个不相交四元调色板、标量平方误差下，按排序秩模 4 交错构造的调色板对任意标量 x 达到一步最近四标签的平均距离下界，即**逐点一步最优**。
  - 达到最大可能的最小调色板内间距 1.5；每个历史暴露 4 个数值不同、跨负/近零/正区域的选择。
  - 用 F2 线性秩条件检测调色板边际平衡、相邻调色板对均匀性及多步退化；满秩仅作拒绝准则，最终掩码由实际路径失真选择。
- **硬件实现**：约 14 个 XOR2 门 + 小型固定 4×4 FP4 查找表，无需乘法器或通用算术；适合宽并行重建。512 权重/周期实现用 N3P 标准单元合成面积仅 1,917 μm²。

### 2.2 曲率感知 Trellis 路径优化

- **目标不匹配**：二阶 PTQ 最小化模型感知二次代理 e^T H e；传统 Viterbi 最小化各向同性欧氏失真 Σ(zi−ẑi)²。
- **LDL 分解**：H = LDL^T，则 e^T H e = (L^T e)^T D (L^T e)。L 表示坐标间交互，D 表示残差各方向相对代价。
- **曲率感知 Viterbi 目标**：
  - π_D = arg min_π Σ_i D_ii (zi − ẑi(π))²。
  - 等价于用 √D_ii 缩放每个残差后再累积平方失真。
  - 仅改变分支标量代价，不增加状态数、分支数、幸存路径数或渐近复杂度，不改变压缩表示。
- **RHT 关系**：若 D=αI，则曲率感知与欧氏 Viterbi  minimizer 完全相同；各向异性 κ_D=Dmax/Dmin 越大，欧氏代理越不可靠。实验采用：无 RHT 时用 D 加权，有 RHT 时用普通欧氏度量。
- **能量排序**：按块能量 E_b = tr(H_Bb,Bb) = Σ_{i∈Bb} H_ii 降序处理 LDLQ 特征块，使高敏感方向更早进入递归，后续块可通过 L 的三角反馈补偿。完全离线，不改变运行时解码器。
