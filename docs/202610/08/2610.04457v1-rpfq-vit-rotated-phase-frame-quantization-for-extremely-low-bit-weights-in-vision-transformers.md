## 摘要
视觉Transformer（ViT）在图像识别和移动视觉应用中取得了强劲性能，但其高维线性投影与注意力计算仍带来显著的存储和推理开销。极低位宽量化是一种有前景的解决方案，然而ViT往往会出现严重的精度下降，因为传统实值标量码本与Transformer投影的方向几何特性匹配不佳。我们提出RPFQ-ViT，一种旋转相位框架量化方法，它在二维相位平面上量化成对通道，使低位码能够更好地保持投影方向，同时通过轻量级缩放恢复幅值。RPFQ-ViT可作为nn.Linear的即插即用QAT替代方案，且不修改标准实值注意力、归一化或激活计算图。在ImageNet-1K上，RPFQ-ViT-B/16在W2/A4下达到79.33% Top-1 / 94.48% Top-5，Swin-T在W2/A8下达到79.30% Top-1 / 94.79% Top-5，DeiT-S在W2/A8下达到77.41% Top-1 / 93.11% Top-5。消融实验、相位几何分析和方向保持指标表明，通道配对、可学习旋转、相位锚点学习和残差相位细化均能提升量化质量。我们进一步将RPFQ-ViT图像分类模型部署到原生iOS和Android运行时栈上；使用2位打包权重时，模型大小相对FP32缩小约5.4–7.1×，端到端设备端延迟降低1.4–1.6×。我们代码库中训练的所有ImageNet结果均采用匹配的300轮训练方案，并报告三次独立运行的平均准确率。这些结果表明，RPFQ-ViT在极低位宽ViT的精度、压缩和实际移动端部署之间提供了有利的权衡。

## Abstract
Vision Transformers (ViTs) achieve strong performance on image recognition and mobile vision applications, but their high-dimensional linear projections and attention computations still impose substantial storage and inference costs. Extremely low-bit quantization is a promising solution, yet ViTs often suffer severe accuracy degradation because conventional real-valued scalar codebooks are poorly matched to the directional geometry of Transformer projections. We present RPFQ-ViT, a Rotated Phase-Frame Quantization method that quantizes paired channels in two-dimensional phase planes, enabling low-bit codes to better preserve projection directions while recovering magnitude with lightweight scaling. RPFQ-ViT serves as a drop-in QAT replacement for nn.Linear and does not modify the standard real-valued attention, normalization, or activation computation graph. On ImageNet-1K, RPFQ-ViT-B/16 reaches 79.33% Top-1 / 94.48% Top-5 under W2/A4, Swin-T reaches 79.30% Top-1 / 94.79% Top-5 under W2/A8, and DeiT-S reaches 77.41% Top-1 / 93.11% Top-5 under W2/A8. Ablations, phase-geometry analysis, and direction-preservation metrics show that channel pairing, learnable rotation, phase-anchor learning, and residual phase refinement each improve quantization quality. We further deploy RPFQ-ViT image-classification models on native iOS and Android runtime stacks; with 2-bit packed weights, model size shrinks by roughly $5.4$-$7.1\times$ relative to FP32 and end-to-end on-device latency drops by $1.4$-$1.6\times$. All ImageNet results trained in our codebase use a matched 300-epoch recipe and are reported as mean accuracies over three independent runs. These results show that RPFQ-ViT provides a favorable trade-off among accuracy, compression, and practical mobile deployment for extremely low-bit ViTs.

## 1. 核心问题与整体含义

- **研究动机**：ViT（含 DeiT、Swin）在图像识别上表现优异，但其高维线性投影与注意力计算在资源受限设备上存储与推理代价高昂。极低位宽量化（尤其 2-bit）是重要压缩手段，但 ViT 在 4/3/2 bit 下精度骤降。
- **现有解释的不足**：既有工作多将退化归因于注意力失真与 QAT 训练不稳定（如 Q-ViT、OFQ、Variation-aware ViT Quantization）。本文提出**互补的几何视角**：标准二值/三值量化器逐标量独立处理，而 ViT 投影对**方向**高度敏感（注意力依赖 query-key 内积），极低精度下标量码本会严重扭曲方向。
- **关键观察**：多数 ViT 线性层通道维度为偶数，可做确定性的"半分割配对"，每个通道对定义二维相位平面；2-bit 码本可表示四个方向而非实轴上几个标量电平。
- **整体含义**：将极低位 ViT 量化重新表述为"**方向保持 + 轻量幅值恢复**"，提出 RPFQ-ViT，作为 `nn.Linear` 的即插即用 QAT 替换，不改动注意力、归一化、激活与部署工具链。

## 2. 方法论

### 核心思想
- 在偶数维线性层中，把成对通道（第 j 与 j+m 通道）写成复数，将量化目标从"逼近两个独立标量"转变为"保持方向 θ、恢复幅值 ρ"。
- 通过**精确配对复数重参数化**（不改变算子图）在复数域量化，再映射回标准实值权重，前向仍走 `F.linear`。

### 关键技术细节与流程
1. **确定性半分割配对**：对 din=2m、dout=2n 的层，定义 xc = x1:m + i·xm+1:2m，yc 同理；权重分为四块 R11, R12, R21, R22，等价改写为两个复数矩阵：
   - U = ½[(R11+R22) + i(R21−R12)]
   - W = ½[(R11−R22) + i(R12+R21)]
   - 逆映射：R11 = Re(U+W), R12 = Im(W−U), R21 = Im(U+W), R22 = Re(U−W)。配对规则对 qkv 等融合投影统一适用，无分支启发式。

2. **相位框架量化**：
   - 固定框架基线：码字 Cϕ = {±1, ±i}（每个复权重 1 个 2-bit 方向，等效每实权重 1 bit）。
   - 学习型：引入组级旋转角 θg 与相位锚点 Φ={ϕk}（默认 K=4），在旋转坐标 Z'g = Zg·e^(−iθg) 下按最大实部投影准则选码字。

3. **最小二乘幅值拟合**：对每组选定方向 Cg，闭式求解 αg = Σ Re(z·c(z)) / Σ|c(z)|²，得到一阶段近似 αgCg。

4. **残差相位细化**：以第二组尺度 βg 与相位方向算子 Sphase(r)=r/(|r|+ε) 细化残差，最终 Ẑg = [αgCg + βg·S(Z'g−αgCg)]·e^(iθg)。备选象限符号算子 Ssign 用于更低复杂度场景。更高比特位宽可递归应用残差阶段（T 阶段对应 T bit 有效位宽）。

5. **训练与元数据**：QAT 中保留全精度主权重，前向用 Ẑ，梯度经 STE 回传。默认 K=4、W2 时每组仅存 7 个元数据标量（1 个旋转角 + 4 个锚点 + 2 个尺度）。

## 3. 实验设计

- **Benchmark**：以"有效前向权重码位宽（Eff. weight bits）"分组比较，而非强行统一含元数据的名义比特数；主结果 W2/A4（ViT-B/16）与 W2/A8（DeiT-S、Swin-T）。
- **对比方法**：
  - QAT 基线：Q-ViT、OFQ、LSQ+、LSQ+KD、FP32（同配方复现或原文报告）。
  - 对 PTQ 方法（PTQ4ViT、FQ-ViT、RepQ-ViT、IGQ-ViT、FIMA-Q、APHQ-ViT、GPLQ）作为相邻背景讨论，不作为直接对比。
- **消融与专项分析**：
  - 组件消融（配对 / 残差 / 旋转 / 锚点 / 尺度拟合，6 个变体）。
  - 方向保持分析（权重 MSE、角度误差、注意力分数 MSE、特征余弦相似度，5 个量化器对比）。

- **部署实验**：iPhone 17 Pro Max（A19 Pro，MLX Swift）与 Android（Dimensity 9400，JNI/C++ arm64-v8a）上测模型大小、加载时间、p50/p90 端到端延迟。

## 4. 资源与算力

## 6. 主要结论与发现

- **精度**：W2 下 RPFQ 在三个骨干上均优于实值低位基线——ViT-B/16 达 79.33%/94.48%（W2/A4），DeiT-S 达 77.41%/93.11%（W2/A8），Swin-T 达 79.30%/94.79%（W2/A8）；ViT-B/16 甚至略超同配方 FP32（77.89%），作者谨慎解释为可能的正则化效应。
- **几何归因**：相对 Real LSQ W2/A4，RPFQ 将角度误差从 1.00 降至 0.43，注意力分数 MSE 从 1.00 降至 0.46，特征余弦从 0.931 升至 0.983，精度排序与方向保持指标一致。
- **消融贡献**：固定相位框架已带来 74.89%→76.56% 提升；残差细化贡献最大（→78.74%）；预对齐（78.79%）→学习旋转+可学习锚点（79.33%）逐步增益。
- **部署**：2-bit 打包权重使 ViT-B/16 从 338.6 MB 缩至 47.7 MB（7.1×），Swin-T 从 110.2 MB 缩至 20.4 MB（5.4×），两平台延迟加速 1.41–1.58×，加载时间同步下降。
- **训练效率**：单阶段、无教师分支、无蒸馏损失，训练成本远低于 Q-ViT/OFQ。

## 7. 优点

- **视角新颖**：从"标量逼近误差"转向"码本几何/方向保持"，为极低位 ViT 量化提供互补的归纳偏置。
- **即插即用兼容**：仅替换 `nn.Linear`，保持注意力、LayerNorm、GELU、Softmax 与部署工具链原样，工程落地成本低。
- **理论构造干净**：配对复数重参数化是精确等价变换，配对规则确定性、无需学习匹配或路由。
- **组件设计完整**：旋转 + 锚点 + 最小二乘幅值 + 残差细化层层递进，消融可解释性强。
- **实验维度全面**：精度、方向几何指标、训练动力学、训练效率、原生移动部署多角度验证；三次种子 + 置信区间增强可信度。
- **训练友好**：单阶段、无蒸馏、无教师分支，比 Q-ViT 快约 3.44×，内存开销极小。

## 8. 不足与局限

- **任务覆盖窄**：仅在 ImageNet-1K 分类上验证，未涉及检测、分割、视频等下游任务，泛化性未知。
- **激活量化受限**：A2 激活量化仍不稳定，主实验采用 A4/A8 伪量化（fake quantization），移动端也未导出原生 INT 激活路径。
- **部署依赖运行时**：端到端延迟受后端是否保持打包权重影响，未给出分阶段 kernel 分解，也未测能耗。
- **对比协议不完全统一**：跨方法元数据、蒸馏分支、侧信息开销不同，按"有效前向码位宽"分组只是近似公平；部分基线（OFQ 的 ViT-B/16）只有调度下界。
- **ViT-B/16 超 FP32 的解读保守**：作者自认不能宣称 2-bit 普遍超越全精度，可能存在配方/正则化混杂因素。
- **几何分析范围有限**：方向指标与定性注意力图仅在小样本可视化层面呈现，缺少更系统的层级/头级统计。
- **社会与安全评估缺失**：作者在讨论中承认需补充鲁棒性、公平性、隐私与下游部署风险评估，但未实际开展。
