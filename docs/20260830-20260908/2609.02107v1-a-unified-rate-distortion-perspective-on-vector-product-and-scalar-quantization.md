## 摘要
离散视觉标记化主要由向量量化、标量量化和乘积量化驱动，但缺乏一个统一的概念框架来理解量化权衡。在本文中，我们提出一个关于现代离散视觉标记化的统一率失真视角。通过将量化视为有损压缩，我们通过标记数量和码本大小来表征标称定长编码速率，并将量化误差作为失真。在此框架内，我们解决了三个核心问题。首先，我们从理论和实证上表明，最小化失真而非最大化码本利用率是重建保真度的主要内在目标，并且与STE引起的梯度差异有直接联系。其次，我们建立了内在量化比较的两个关键公平条件：控制潜在特征统计量并强制执行相同的编码速率。第三，在这些条件下，我们恢复了现代视觉标记化中的VQ-PQ-SQ失真层级，并从实证上表明现代VQ方法实现了最低失真。这项工作为现代离散视觉标记化提供了一个基础的率失真重构框架，解决了量化器评估中的模糊性，并提供了一个受控框架，用于在固定速率约束下分离内在量化有效性。

## Abstract
Discrete visual tokenization, predominantly driven by vector, scalar, and product quantization, lacks a unified conceptual framework for understanding quantization tradeoffs. In this paper, we propose a unified rate--distortion perspective on modern discrete visual tokenization. By viewing quantization as lossy compression, we characterize the nominal fixed-length coding rate through token count and codebook size, and quantization error as the distortion. Within this framework, we resolve three central questions. First, we theoretically and empirically show that minimizing distortion, rather than maximizing codebook utilization, is the primary intrinsic objective for reconstruction fidelity, with a direct connection to the STE-induced gradient discrepancy. Second, we establish two critical fairness conditions for intrinsic quantization comparison: controlling latent feature statistics and enforcing identical coding rates. Third, under these conditions, we recover the VQ--PQ--SQ distortion hierarchy in modern visual tokenization and show empirically that modern VQ methods achieve the lowest distortion. This work provides a foundational rate--distortion reframing of modern discrete visual tokenization, resolves ambiguities in quantizer evaluation, and provides a controlled framework for isolating intrinsic quantization effectiveness under fixed-rate constraints.

## 二、方法论与关键技术细节

### 2.1 核心建模思想

- **失真定义**：给定潜在特征 $X \sim P$，量化器 $Q_\phi$ 的失真为期望平方误差 $E(P, Q_\phi) = \mathbb{E}\|X - Q_\phi(X)\|_2^2$。
- **码率定义**：名义固定长度编码码率 $R = T \log_2 K$，其中 $T$ 为视觉 token 数量，$K$ 为离散码空间基数。该定义区别于熵编码下的期望码率。
- **统一比较框架**：VQ 的 $K$ 为码向量数；PQ 与 SQ 的 $K$ 为各子码本大小的乘积（复合码空间基数），由此使三类方法可在相同名义码率下比较。

### 2.2 主要理论结果

- **失真最小化 vs. 码本利用率**：
  - 在温和的“非退化可分割性”假设下，论文证明每个全局失真最小化器必然实现完全码本利用；但反之不成立——完全码本利用并不保证失真最优（Proposition 2）。
  - 论文推导出 STE 梯度差异 $G$ 与量化失真满足局部关系 $G = O(\|z_e - z_q\|_2^2)$，即失真越小，STE 梯度与真实梯度的偏差越小。
- **公平比较条件**：
  - **条件1：匹配潜在特征分布**——潜在特征全局缩放 $a$ 会使最优失真按 $a^2$ 缩放，不同特征统计量会混淆量化器本身的比较。
  - **条件2：匹配名义码率**——须匹配 $R = T\log_2 K$；论文在受控实验中采用了更强的条件 $T_A=T_B$ 且 $K_A=K_B$。
- **VQ-PQ-SQ 失真层级**：
  - 结构上 SQ ⊆ PQ ⊆ VQ，因此最优失真满足 $E_{VQ}^* \leq E_{PQ}^* \leq E_{SQ}^*$。
  - 在最坏情况分布上三者失真均以 $\Theta(d/K^{2/d})$ 缩放（Proposition 3）。
  - 当数据具有内在低维结构时，VQ 失真可达 $O(K^{-2/d_{\text{eff}}})$，显著优于 PQ 和 SQ 的 $O(K^{-2/M})$ 或 $O(K^{-2/d})$ 缩放（Proposition 4）。

### 3.1 数据集

- **主实验**：ImageNet-1K。
- **泛化验证**：FFHQ、CelebA-HQ（潜在空间受控实验）；CelebA-HQ（像素空间受控实验）。

### 3.2 评估场景与协议

- **潜在空间受控比较**：采用预先训练的 VAR tokenizer 和 VQ-Transplant 框架。替换量化模块时冻结预训练编码器与解码器；解码器适应阶段冻结编码器和量化器、仅适应解码器。所有方法共享同一编码器，从而满足"匹配潜在分布"的条件。
- **像素空间受控比较**：使用 PixelUnshuffle/PixelShuffle 操作，不依赖预训练编码器，直接将原始像素送入量化管道，进一步验证结论的普适性。
- **控制变量设置**：所有方法均设置 $T = 512$（潜在空间）或 $T = 4096$（像素空间），复合码空间基数 $K = 65{,}536$，从而严格匹配名义码率。

### 3.3 对比方法

- **VQ 变体**：Vanilla VQ、EMA VQ、Online VQ、Wasserstein VQ、MMD VQ。
- **PQ 变体**：Vanilla VP2、EMA VP2、Online VP2、Wasserstein VP2、MMD VP2（每个 token 划分为 2 个 8 维子向量，各配 256 大小的子码本）。
- **SQ 变体**：FSQ、LFQ、BSQ。

### 3.4 评估指标

- 失真 $E$、码本利用率 $U$；
- 重建质量：PSNR、SSIM、LPIPS、r-FID、r-IS。

## 六、主要结论与发现

1. **失真最小化是量化内在有效性的首要优化目标**，而非码本利用率最大化。低失真编码器在温和条件下必然充分利用码本，且失真最小化可降低 STE 梯度偏差，提高训练稳定性与重建质量。
2. **公平的量化比较**必须同时控制潜在特征分布与名义编码码率；否则潜在统计量差异或码率差异将混淆量化器本身的比较。
3. **VQ–PQ–SQ 失真层级得到理论与实验双重验证**：在匹配潜在特征统计和相同码率下，VQ 的整体失真最低，PQ 次之，SQ 最高。MMD VQ 在 ImageNet-1K 取得 $E=0.201$（PQ 最优为 0.209，SQ 最优为 0.231），重建质量同样领先（r-FID 0.86 vs. 0.93 vs. 1.07）。
4. **高码本利用率不保证高重建质量**：多个 PQ/SQ 方法达到 100% 利用率但失真高于 VQ，且相关分析显示失真与重建保真度高度相关，而利用率相关性较弱且不显著。

## 七、方法论与实验设计的亮点

- **统一理论框架**：将三类量化方法纳入统一率失真框架，首次为现代离散视觉 tokenization 的比较确立了系统的概念基准。
- **清晰的公平比较条件**：识别出潜在特征统计量与编码码率两大混淆因素，提出的两条公平比较条件具有较强的指导性意义。
- **理论证明与实验互相支撑**：论文不仅给出结构包含关系和最坏情况失真界，还以定量下界证明了 VQ 对内在低维结构的利用能力优于坐标固定的 PQ/SQ 分解。
- **受控实验范式**：VQ-Transplant 量化模块替换策略最大限度消除了端到端训练中的体系差异，使实验能够在量化器层面进行公平比较。
- **多维度稳健性验证**：通过跨数据集（ImageNet-1K、FFHQ、CelebA-HQ）、跨空间（潜在空间、像素空间）、跨码率（不同 $K$ 与 $T$）等多维度实验验证同一结论，显著增强了说服力。

## 八、不足与局限

- **码率定义的边界**：论文使用名义固定长度码率 $R=T\log_2 K$ 而非熵编码下的期望码率，因此不直接刻画熵约束量化、变长编码或自适应比特分配等更贴近实际压缩的场景。
- **失真度量的局限**：理论分析仅采用平方欧氏失真，未覆盖感知、语义或任务相关的失真度量；低失真不一定意味着下游生成质量更好（论文引用了"重建-生成权衡"相关研究作为佐证）。
- **理论最优与实际算法之间的差距**：失真层级关系针对每个量化器族内的最优可实现失真，不保证所有实际 VQ 优化算法在有限数据和有限优化条件下必然超越每个 PQ/SQ 方法。
- **下游生成性能未评估**：论文结论限于量化的内在有效性与重建保真度，未回答失真与生成模型可建模性及下游生成质量的互动关系，该问题被列为未来工作。
- **算力与复现细节披露有限**：论文仅报告 GPU 数量和类型，未给出精确的训练总时长等信息，表 1 中也未为所有对比方法完整标注所需的计算开销。
- **潜在编码器依赖**：主实验基于 VAR tokenizer 单个预训练潜在空间，虽辅以像素空间实验增强普适性，但不同编码器的潜在分布特征可能影响定量结论的外推。
