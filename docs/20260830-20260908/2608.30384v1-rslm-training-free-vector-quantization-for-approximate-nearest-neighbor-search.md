## 摘要
通过引入RSLM（旋转缩放Lloyd-Max），一种将嵌入压缩到每维度1-4比特的无训练向量量化编解码器家族，我们降低了典型大规模近似最近邻（ANN）搜索系统的内存成本和内存带宽，同时降低了其复杂度，并在多个基准数据集上保持或提高了召回率。最先进的系统使用粗粒度分区过滤候选，通过近似评分缩小候选集，然后用更高精度的表示（通常每维度≥8比特）对最佳结果进行重新评分。我们的相对化编解码器可以将这一需求降至每维度2-4比特。我们利用ANN系统的特性对残差向量而非完整向量进行编码，既用于近似评分阶段，也用于重新评分阶段。由于最大内积搜索（MIPS）对向量范数非常敏感，我们对量化向量的L2范数进行了校正。我们的主要创新在于校正最终重建向量的L2范数，而不仅仅是残差的范数。这种重新缩放替代了更复杂的方案，如各向异性损失。与通用量化方法相比，残差化方案为我们提供了更有利的质量与大小权衡。我们的高性能实现利用了具有类线性复杂度的块级级联快速Walsh-Hadamard变换（FWHT）、AVX SIMD优化码本，以及缩放因子的隐写编码，以实现完美的缓存行对齐。

## Abstract
By introducing RSLM (Rotated Scaled Lloyd-Max), a family of training-free vector quantization codecs compressing embeddings to 1--4 bits per dimension, we reduce memory cost and memory bandwidth of a typical large-scale Approximate Nearest Neighbor (ANN) search system, while reducing its complexity and keeping or improving recall across multiple benchmark datasets. State-of-the-art systems filter candidates using coarse partitions, approximately score them to narrow the set, and then rescore the best with higher precision representations (often >=8 bits per dimension). Our relativized codecs can bring this down to 2--4 bits per dimension.   We use the properties of the ANN system to encode residual vectors instead of full vectors, both for the approximate scoring phase and the rescoring phase. Since Maximum Inner Product Search (MIPS) is very sensitive to vector norms, we correct the $L_2$ norms of quantized vectors. Our major innovation is that we correct the $L_2$ norm of the final reconstructed vector rather than just the residual. Our rescaling replaces more complicated schemes, such as Anisotropic loss. The residualization scheme gives us a more favorable quality vs size trade-off than generic quantization methods.   Our high-performance implementation leverages a block-wise cascaded Fast Walsh-Hadamard Transform (FWHT) with linear-like complexity, AVX SIMD-optimized codebooks, and a steganographic encoding of scaling factors for perfect cache-line alignment.

- **核心问题**：大规模近似最近邻（ANN）检索系统通常采用多阶段流水线：先用粗粒度分区（IVF/树索引）剪枝候选集，然后用低比特量化进行近似评分，最后对少量候选用高比特表示（通常 ≥8 bits/维）重排。该系统面临两大硬件瓶颈：
  - **DRAM 容量**：存储十亿级高维向量的内存成本过高；
  - **DRAM 到 CPU 的内存带宽**：限制在线查询吞吐与延迟。
- **现有量化方案的局限**：
  - **数据依赖（data-dependent）方法**（如 PQ、ScaNN AH）：需要离线 k-means 训练码本，训练复杂度高，且容易受数据分布漂移影响；
  - **已有的 data-oblivious 方法**（如 TurboQuant、RaBitQ、EDEN、BlockQuant）：存在稠密正交旋转复杂度 O(D²) 或超线性 O(D log D) FWHT、维度受限于 2 的幂、需要存储额外旋转矩阵/元数据等问题；
  - 通用全向量量化方法没有充分利用 ANN 系统中的**残差结构**（即相对粗分区中心或近似向量的向量）。
- **本文的意义**：提出 Rslm（Rotated Scaled Lloyd-Max）——一个完全**无训练**的量化编解码器家族，可在 1–4 bits/维下同时用于 ANN 的近似评分与候选重排阶段，将重排阶段的比特率从传统的 ≥8 bits/维降低到 2–4 bits/维，在不损失召回率（甚至略有提升）的情况下显著降低内存占用与带宽消耗，简化系统复杂度。

## 2. 方法论

### 2.1 总体框架

Rslm 对向量执行三阶段流水线：
1. **预处理正交变换**（旋转），使各坐标方差均匀化，逼近标准正态分布；
2. **固定 Lloyd-Max 码本量化**；
3. **范数校正**——通过一个每向量缩放因子精确恢复 L2 范数。

### 2.2 核心技术细节

- **（1）块式级联 FWHT（Block-wise cascaded FWHT）**：
  - 将向量切分为固定大小块（B ≤ 128），分别执行 FWHT；
  - 计算复杂度为 **O(D log B) = O(D)**，即线性复杂度，显著优于稠密旋转的 O(D²) 与全局 FWHT 的 O(D log D)；
  - 处理任意维度（如 D=2049）时无需零填充，而是通过**重叠尾部块**和**跨块交换/转置**完成全局混合；
  - 两遍级联流程：第一遍符号翻转 → 块式 FWHT → 块内置换 + 跨块转置 → 第二遍符号翻转 → 第二遍块式 FWHT。

- **（2）Lloyd-Max 码本（固定、无训练）**：
  - 码本通过对标准正态分布合成样本做 k-means 得到，完全数据无关（data-independent）；
  - 码本配置：1-bit 用 4D 码本 K=16；2-bit 用 2D 码本 K=16；3-bit 和 4-bit 用 1D 码本 K=8 / K=16；
  - 限制码本大小 ≤16 是为了适配 AVX2 `VPSHUFB` 指令的 16-byte lane 限制，避免性能严重退化。

- **（3）L2 范数校正（核心贡献）**：
  - 传统方法只校正残差向量的范数；Rslm 校正的是**最终重建向量（近似向量 + 量化残差）**的 L2 范数；
  - 缩放因子 s = ‖x‖₂ / ‖x̂‖₂，使得重建向量与原始向量范数精确一致；
  - 这种简单方案在经验上优于需要调参的 ScaNN 各向异性损失（anisotropic loss），且无需训练；
  - 对比：SSQ（Scaled Scalar Quantization）会**膨胀**量化后向量的期望范数（噪声方差导致）；PQ 基于 Voronoi 质心性质会**收缩**期望范数。Rslm 精确消除了这两类范数畸变。

- **（4）缩放因子编码方式**：
  - 局部缩放用 UE7M9（unsigned 16-bit 浮点，无符号位）+ 2 字节后缀；
  - 全局缩放用 UE4M12（因全局 scale 接近 1.0，需要更高尾数精度）；
  - Rslm4Lite 变体：在前 16 个维度中使用 8 个质心（3-bit），腾出每维最高位共 16 bits，将 16-bit 缩放因子**隐写嵌入**量化码中，实现**零元数据开销**和完美缓存行对齐。

- **（5）残差量化（相对量化）**：
  - 将 Rslm 应用于残差向量 r = x − a（a 是来自第一阶段 IVF/树分区或其他量化器的近似向量），再配合预计算的 ⟨q, a⟩ 进行得分合成：⟨q, a + r̃⟩ = ⟨q, a⟩ + ⟨q, r̃⟩；
  - 支持两种模式：
    - **局部缩放（RelApprox）**：独立校正残差 r 的范数；
    - **全局缩放（RelApproxGlobal）**：对 (a + r̃) 整体施加一个全局缩放 s = ‖x‖₂ / ‖a + r̃‖₂，秩排序时最终得分为 s·(⟨q,a⟩ + ⟨q,r̃⟩)。

## 6. 主要结论与发现

1. **残差化是决定性优势**：对所有数据集和比特率，相对量化（residual）相比全向量量化显著降低召回损失。4-bit 残差 Rslm 可达 **100% Recall@20@30**；3-bit 在所有数据集上 ≥98.9%；
2. **2-bit 残差量化已足够实用**：RelApproxGlobal-Rslm2 在 5 个数据集中 4 个取得 ≥99.3% 的 Recall@20@40（glove 100 维为 97.7%）；这对重排向量的 DRAM 占用可实现 4x–8x 缩减；
3. **校正最终重建向量的范数（而非仅残差）至关重要**：全局缩放（RelApproxGlobal）在几乎所有配置上明显优于局部缩放（RelApprox），实验证实了这一点对 MIPS 排序具有决定性影响；
4. **旋转预处理可解决非零均值与方差偏斜问题**：wiki_full、bigann、openai 上无旋转编码（Slm4/SSQ4Lite）严重退化（60–90%），经过块式 FWHT 旋转后 Rslm4 可达 ≥92%（bigann）乃至 ≥99%（wiki_full、openai）；
5. **无训练码本可达到甚至超越训练码本**：在 1-bit 与 2-bit 的低比特端，Rslm_Global 明显优于 ScaNN AVQ 和 Faiss PQ；在 4-bit 全向量场景与 TurboQuant 相当；
6. **缓存行对齐的吞吐收益显著**：Rslm4Lite 依靠零元数据开销在大池随机访问模式中明显胜过 Rslm4；SIMD 优化让固定码本在吞吐上能与无码本方案（SSQ4Lite）竞争；
7. **维度越高，量化越稳健**：wiki_full（D=3072）上 2-bit 也可达 94% Recall@20@30，符合信噪比随维度线性增长的理论预期。

## 7. 优点

- **方法设计上的亮点**：
  - 真正的“无训练”端到端方案：从码本、旋转到缩放全部数据无关或逐向量自适应，省去了 k-means 训练部署环节；
  - 最终重建向量范数校正思想简洁而高效，替代了复杂的各向异性损失训练，物理意义明确；
  - 块式级联 FWHT 设计巧妙：O(D) 复杂度、任意维度处理（重叠尾块）、精确可逆；
  - 硬件优化细致：码本大小 ≤16 匹配 SIMD shuffle、UE7M9 无符号浮点格式、Rslm4Lite 的隐写嵌入实现零元数据与完美缓存行对齐；
  - 同时覆盖 ANN 流水
