## 摘要
混合精度量化（MPQ）为大型语言模型（LLM）的每个线性层分配不同的位宽，以在固定预算下最小化量化引起的质量损失，但混合专家（MoE）模型在每个MoE块的每个专家中都包含这些层，因此分配空间远大于密集模型。现有方法要么在统一每块预算下在每个块内分配，要么通过加性代理跨块分配，这两种方法都不能直接优化在耦合块的选项上的模型级目标。我们提出了Q-Strata，一种双层分配器，它使用廉价代理对块内分配进行排序，并使用在组装后的量化模型上评估的模型级目标进行跨块分配。其内层阶段针对精细间隔的预算缓存每个块的候选帕累托前沿，使外层阶段只需为每个块设置一个预算，而不是为每个线性层设置位宽。通过将搜索缩减为每块一个预算，外层阶段直接优化此模型级目标，捕捉加性代理遗漏的块间耦合。在Mixtral-8x7B-Instruct、Qwen1.5-MoE-A2.7B和DeepSeek-V2-Lite上，Q-Strata在低位宽设置下始终比均匀位宽GPTQ及最先进的MoE MPQ方法MxMoE和GEMQ实现更低的WikiText2困惑度。代码可在https://github.com/snu-mllab/Q-Strata/tree/main获取。

## Abstract
Mixed-precision quantization (MPQ) assigns a different bitwidth to each linear layer of a large language model (LLM) to minimize the quantization-induced quality loss under a fixed budget, but Mixture-of-Experts (MoE) models contain these layers in every expert of every MoE block, so the allocation space grows far larger than in a dense model. Existing methods either allocate within each block under a uniform per-block budget, or allocate across blocks through an additive proxy, and neither directly optimizes a model-level objective over the choices that couple the blocks. We propose Q-Strata, a bi-level allocator that ranks within-block assignments with a cheap proxy and allocates across blocks with a model-level objective evaluated on the assembled quantized model. Its inner stage caches a Pareto frontier of candidates per block over finely spaced budgets, leaving the outer stage to set one budget per block instead of a bitwidth for every linear layer. With the search reduced to one budget per block, the outer stage optimizes this model-level objective directly, capturing the inter-block coupling that additive proxies miss. On Mixtral-8x7B-Instruct, Qwen1.5-MoE-A2.7B, and DeepSeek-V2-Lite, Q-Strata consistently achieves lower WikiText2 perplexity than uniform-bitwidth GPTQ and the state-of-the-art MoE MPQ methods MxMoE and GEMQ in the low-bit regime. The code is available at https://github.com/snu-mllab/Q-Strata/tree/main.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大型语言模型部署高度依赖权重量化压缩；MoE（Mixture-of-Experts）大模型包含大量专家权重，内存占用大，量化是压缩它最直接的途径。
- **混合精度量化（MPQ）**：为不同线性层分配不同比特宽度，以求在固定比特预算下最大化量化质量。但 MoE 模型中将分配扩展到每个 MoE 块中的每个专家（每个专家有 up/gate/down 三个线性层）会导致决策空间增长为 \(|Q|^{3LE}\)，远比稠密 LLM 大。
- **现有方法局限**：
  - MxMoE、MC-MoE 等只在每个 MoE 块内做位宽分配，所有块共享统一预算，**不能跨块调配**；
  - GEMQ 虽可跨块分配，但依赖"加性代理"近似模型损失，**无法精确刻画跨块压缩带来的耦合效应**。
- **核心含义**：本论文主张把 MoE 的混合精度量化分解成两个"地层"：块内分配由廉价局部代理驱动，块间分配由整体模型级目标直接驱动。由此避免高维搜索爆炸，又能捕捉跨块互作，取得比均匀位宽和先进 MoE MPQ 方法都低的困惑度。

### 2. 论文提出的方法论：思想、关键技术、算法流程

**总体框架——Q-Strata（双层分配器）**

- **内层——候选生成与缓存**
  - 对每个 MoE 块 \( l \)，计算块级输出重建失真：  
    \( D_l(x_l) = \sum_{e,i} \|\hat h_l^{(e,i)}(x_{l,e,i}) - h_l\|^2 \)，其中只量化一个线性层、其余保持全精度。
  - 该失真函数只依赖块内分配且对每层可分解，因而可形式化为**多选背包问题（MCKP）**，用 Gurobi ILP 精确求解。
  - 在预算网格 \( \mathcal{B}=\{\beta^{(1)}<...<\beta^{(K)}\} \) 上对每块搜索每一预算下的 Pareto 最优解，并缓存为候选集 \( \mathcal{S}_l \)。

- **外层——面向模型级目标的跨块预算分配**
  - 模型级目标 \( \mathcal{L}(x) \) 定义为量化模型与全精度模型在下一次词符分布间的 JSD（校准集上），并约束平均位宽。
  - 外层只在"块层级"选择每块预算，因此搜索空间从 \(|Q|^{3LE}\) 降至 \(|\mathcal{B}|^L\)，决策数量大幅减少。
  - 为了优化 \( \mathcal{L} \)：
    - 从所有块取最大预算开始，逐步下降其中一个块的预算，不断选择"边际损失上升最小"的块继续降低，直到均值满足预算约束 τ；
    - 使用 **lazy greedy**：在最小堆中保存每块边际上升值及时间戳，若边缘值因其他块的压缩而过期，则只重算所需块，从而大幅减少模型级前向评估次数；
    - 当 \(-\mathcal{L}\) 满足 **DR-submodularity（近似）** 时，lazy descent 可复现 eager greedy 的选择；文中通过 DeepSeek-V2-Lite 的随机路径实验验证该性质近似成立（边际损失随压缩加剧而接近单调上升）。

- **稠密模型的扩展**
  - 外层贪婪算法也可直接应用于稠密模型，层级改为单个线性层；
  - 因各层参数数不同，需用 budgeted greedy，按"每节省单位比特的损失"排序移动。

  - 每种方法均在多种平均位宽预算（如 3.25 / 3.5 / 3.75 bit）下比较以验证比特效率曲线。

### 4. 实验结果与关键发现

- **对多样位宽预算均实现 SOTA 困惑度（PPL）**：
  - 在 Mixtral-8×7B、Qwen1.5-MoE-A2.7B、DeepSeek-V2-Lite 等模型上，同等平均位宽下 Q-Strata 的 WikiText2 困惑度系统性低于 Uniform GPTQ、MxMoE、MC-MoE 及 GEMQ；
  - 收益随预算收紧（如 3.25 bit 对 3.75 bit）更为明显，说明跨块整体调配在强压缩下价值更大；
  - 例如在 Mixtral 上约 3.5 bit 预算时，Q-Strata 相对均匀位宽基线可将 PPL 降低超过 1.0，相对最强基线也可取得可观且一致的 PPL 下降。

- **零样本与少样本下游任务**：
  - 在 PIQA、BoolQ、WinoGrande、ARC-easy、ARC-challenge、HellaSwag 六个 zero-shot 任务的 **平均准确率** 上，Q-Strata 普遍优于所有基线，且更少出现某些任务上均匀位宽反超混合精度方法的情况；
  - 在 MMLU、GSM8K 上进一步验证语言理解与推理能力保持更好，证明优化下一位词符分布的 JSD 能有效转为下游任务能力保持。

- **消融与机制验证**：
  - **块内层**：与次优块内启发式相比，MCKP 内层产生的 Pareto 候选集带来的增益不可忽略，说明在固定预算下块内精确搜索也贡献了大部分收益；
  - **块间层**：单靠块内 Pareto 候选加均匀/统一预算不足以取得最优——模型级跨块分配还额外降低 PPL，验证了论文关于“跨块耦合不可忽略”的核心假设；
  - **DR-submodularity 验证**：在 DeepSeek-V2-Lite 上测量边际损失随预算下降的变化轨迹，发现预算越小边际损失单调性越强，近似满足 lazy greedy 所需条件；
  - **剪枝/跳过无关校准样本**：仅需少量校准数据即可稳定复现增益，说明外层目标对样本量不敏感。

- **效率分析**：
  - 内层只依赖前向传播与 Gurobi ILP 求解，不涉及梯度计算；外层 lazy greedy 通过“边际到期再重算”机制显著减少前向次数，使总开销远小于穷举/逐层贪婪基线；
  - 即使对 8×7B 级别模型，Q-Strata 可在可接受时间（数个小时级）内完成整模型位宽分配与量化，而不会大幅加重部署前准本流程。

### 5. 主要贡献、局限与开放性讨论

- **贡献**：
  1. 首次提出将 MoE 混合精度量化分解为“块内位宽搜索 + 块间预算分配”双层问题，在不牺牲建模精度的前提下使搜索空间从 \(|Q|^{3LE}\) 剧减至 \(|\mathcal{B}|^L\)；
  2. 内层将块内重建失真构建为可分解的多选背包（MCKP），借助 ILP 严格求 Pareto 最优候选；
  3. 外层直接优化模型级 JSD 目标，用带 DR-submodularity 验证的 lazy greedy 逼近最优块间预算分配；
  4. 广泛实验证明相比均匀位宽、MxMoE/MC-MoE/GEMQ 等先进方法在 PPL 与下游任务上均取得更优结果；
  5. 同时支持稠密 LLM 的逐层混合精度分配，扩展性强。

- **局限**：
  - 外层贪心依赖“跨块边际损失近似独立/单调”的经验假设，虽有实验验证但缺乏严格理论边界；
  - 内层候选生成只有在“逐层独立量化损失有效”时才最优，对强层间耦合或不可分解的量化误差结构覆盖不足；
  - 目标函数只针对下一个词符分布的 JSD，迁移到长程生成一致性、循环稳定性等更复杂目标时还需扩展；
  - 决策速度仍受 Gurobi ILP 与模型级前向评估制约，对超大 MoE（如千亿级激活模型）的开销仍需工程优化。

### 6. 结论

Q-Strata 以“双地层”方式解决了 MoE 混合精度量化中维度爆炸与跨块耦合难以兼顾的问题：内层用 MCKP 精确枚举块内位宽组合，外层以 JSD 为模型级目标在块间做 lazy greedy 预算分配。大量实验表明该方法在多种 MoE LLM 与不同比特预算下均显著优于现有均匀及 MoE-MPQ 方法，同时保持实用的搜索与量化效率，为大规模 MoE 的高效部署提供了一条可扩展且高质量的路径；其模块化设计也可顺承扩展到稠密模型和新的模型架构。
