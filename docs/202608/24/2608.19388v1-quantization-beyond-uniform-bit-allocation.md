## 摘要
量化是处理现代模型生成的嵌入规模不断增长的基本技术。现有的量化方案大多与嵌入无关，并且跨维度均匀分配比特。然而，最近的模型生成的嵌入具有显著的几何结构。在这项工作中，我们研究了在固定内存预算下，可变比特分配方案能否提高量化质量。我们提出了一种简单的可变比特分配框架，该框架将嵌入划分为连续的桶，并在桶之间非均匀地分配存储空间。使用贪心分配策略，我们为乘积量化（PQ）和标量量化（SQ）实例化了该框架。我们在已知具有套娃属性（MRL）的嵌入上进行了一系列实验，并一致地观察到，在相同存储预算下，非均匀分配优于均匀基线。最大的改进出现在低位（低比特）区域，其中均匀分配对于MRL嵌入尤其低效。在相同压缩率下，可变分配将PQ的召回率提高了最多8%，将SQ的召回率提高了最多18%。我们的结果为大规模检索系统的结构感知压缩和索引技术指出了一个新的方向。

## Abstract
Quantization is a fundamental technique to handle the growing sizes of embeddings generated by modern models. Existing quantization schemes are largely embedding agnostic and allocate bits uniformly across dimensions. However, recent models produce embeddings with significant geometric structure. In this work, we investigate whether a variable bit allocation scheme can improve quantization quality under a fixed memory budget. We propose a simple variable bit allocation framework that partitions an embedding into contiguous buckets and allocates storage non-uniformly across them. Using a greedy allocation strategy, we instantiate this framework for both Product Quantization (PQ) and Scalar Quantization (SQ). We perform a series of experiments on embeddings known to have the Matryoshka property (MRL), and consistently observe that non-uniform allocations outperform uniform baselines at identical storage budgets. The largest improvements occur in the low-bit regime, where uniform allocation is particularly inefficient for MRL embeddings. At the same compression rates, variable allocation improves recall by up to 8\% for PQ and up to 18\% for SQ. Our results suggest a new direction for structure-aware compression and indexing techniques for large-scale retrieval systems.

## 1. 论文的核心问题与整体含义

- **研究动机与背景**：随着现代 ML 系统中嵌入向量规模的持续增长，向量检索面临严重的存储与计算压力。量化（Quantization）是压缩嵌入、降低内存/磁盘占用的核心手段，其中乘积量化（PQ）和标量量化（SQ）应用最广。然而，现有量化方案大多是“嵌入不可知”的，即对嵌入的所有维度采用**均匀比特分配**，没有利用嵌入自身的几何结构。
- **关键观察**：近年来的许多现代嵌入模型（如 OpenAI text-embedding-3-large、Cohere embed-v4）都具有 **Matryoshka（套娃）性质（MRL）**：前部维度承载了不成比例的结构信息，截断到少部分维度仍能保持较高召回率。论文由此提出一个核心问题：**在固定内存预算下，非均匀（可变）比特分配能否比均匀分配取得更好的量化质量？**
- **整体含义**：论文给出了肯定的回答——利用 MRL 嵌入的维度重要性差异，有偏地分配比特可以显著提升量化性能，尤其在低比特率（sub-1 bit）区间，为大规模检索系统的结构感知压缩与索引提供了新方向。

## 2. 论文提出的方法论

- **核心思想**：将嵌入的全部 `D` 个维度划分为 `K` 个连续的桶（bucket），每个桶分配不同的字节数（比特预算）。通过贪心搜索找到最优分配向量 `b = (b_1, ..., b_K)`，使量化后的检索召回率最大化。
- **贪心分配框架（Algorithm 1）**：
  1. 初始化所有桶为均匀分配 `b_init`（64 字节或 32 字节）；
  2. 每轮迭代，依次尝试给每个桶增加固定增量 `δ`（8 或 4 字节），计算在验证查询集上的召回率 `R(b + δe_k, V)`；
  3. 将增量永久给予带来最大召回提升的桶；
  4. 重复直到达到目标总预算（例如 1 bit per dimension）。
- **Greedy Product Quantization（PQ）**：
  - 每个桶内按其分配的字节数 `b_k` 将 `d_k` 维划分为 `b_k` 个连续子向量；
  - 每个子向量用 256 个中心的 k-means 码本（1 字节/码字）；
  - 余数维度采用“前载”均匀分布（如下标的第一个子向量多一维）。
- **Greedy Scalar Quantization（SQ）**：
  - 允许的位宽为 `{0, 2, 4, 8}`（避免 1-bit 的“模式分裂”问题，0-bit 表示直接丢弃该维度）；
  - 根据桶内总比特数 `8*b_k` 选择基础位宽 `W_base`，并用均匀步长“升级”部分维度到更高位宽；
  - 每个维度独立进行标量量化。
- **利用 MRL 性质的代理指标**：观察嵌入各维度方差沿维度索引衰减，早期维度方差更高、信息更集中。尽管算法未显式使用 MRL 定义，优化得到的分配结果强烈偏向初始维度，自动恢复了 MRL 结构。

## 6. 论文的主要结论与发现

- **核心结论**：在相同存储预算（压缩率）下，非均匀比特分配一致地优于均匀分配——PQ 相对召回提升最高 **8%**，SQ 最高 **18%**。
- **关键观察**：
  - 最大的收益出现在 **sub-1 bit 极低比特区间**，此时均匀分配对 MRL 嵌入尤其低效；这个区间也是实践中扩大规模最需要的压缩域。
  - 优化后的比特分配显著偏向初始维度，符合 MRL 嵌入的方差分布特征；这种偏斜在 SQ 中比 PQ 更明显，而 SQ 恰好也是获得最大相对增益的场景。
  - 增益具有模型与数据集依赖性：OpenAI 嵌入上的提升通常高于 Cohere 嵌入，这与 OAI 嵌入呈现更清晰的方差分层（Figure 2）一致；
  - 在高比特预算下，基线召回已很高，可变分配的增益趋于边际递减。
- **总体定位**：这是一个探索性、数据驱动的工作，验证了“结构感知量化”的可行性，并为后续理论化与工程化提供了出发点。

## 8. 不足与局限

- **算法效率差**：贪心搜索在每轮迭代都要重新评估所有候选桶并训练码本，离线索引构建开销极大，不适用于万亿级数据规模的实际部署。
- **无理论支撑**：
  - MRL 缺少严格数学/几何定义，论文仅用“方差衰减”作为经验代理；
  - 无法回答“最优比特分配是否有闭式解”或是否存在可证明误差界。
- **实验覆盖有限**：
  - 仅两个嵌入模型、6 个数据集，且大中数据集被截断到 50 万条；
  - 未做消融（桶数、步长、初始预算、阈值选择等）；
  - 未与其他先进量化方法（如 RaBitQ、AQ、动态精度方法）进行横向对比。
- **系统落地挑战**：可变位宽导致自定义数据类型，破坏 SIMD 友好的均匀内存布局，牺牲内存访问效率，实际向量索引系统需要额外适配。
- **启发式偏差风险**：贪心优化基于验证集上的召回，可能在验证集上过拟合；不同数据集/模型上“最优”分配差异较大，缺乏可迁移的通用规则。
- **特殊限制**：SQ 中刻意避开 1-bit 宽度（因模式分裂问题），使分配离散化选择受约束；0-bit 丢弃维度可能损害某些下游任务的可靠性（如相似性近似）。
