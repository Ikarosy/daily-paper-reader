## Abstract
Deploying vision-language models (VLMs) on mobile devices is challenging due to their significant memory and compute requirements. We present a framework for quantizing VLMs for efficient inference on resource-constrained hardware. Our approach combines a quantization pipeline that uses the model itself to generate training data and does not require access to the training setup, with a novel 2.7-bit-per-parameter format supporting efficient execution on Arm CPUs. We validate our approach by compressing the Llama 3.2 11B Vision Instruct model to 3.7 GB with 8-bit activations, preserving strong performance on a set of standard visual question answering tasks.

## 2. 方法论

论文提出的框架由三个部分组成，流程为：合成数据生成 → 量化感知训练 → 移动端部署。

### 2.1 核心思想

- 使用**量化感知训练（QAT）**结合**知识蒸馏（KD）**，将原始全精度模型作为教师（teacher），量化模型作为学生（student），在合成数据集上训练学生以匹配教师输出。
- 关键创新在于：**不需要原始训练数据**，而是利用模型自身生成合成多模态训练数据，并通过精心设计的提示采样策略提升数据多样性。
- 数值格式方面，提出 **S3D8 格式**，将数值格式设计与硬件（Arm SIMD 指令）协同优化，实现低比特存储与高效解码。

### 2.2 量化感知训练（QAT）目标

- 令教师模型为 $f_T(\cdot; \theta_T)$（bfloat16 高精度），学生模型为 $f_S(\cdot; \theta_S)$，量化算子为 $Q(\cdot)$（前向传播使用量化参数 $\hat{\theta}_S = Q(\theta_S)$，反向传播通过直通估计器（STE））。
- 对每个样本 $(I, x, y)$（图像、提示、教师生成的响应），在生成的响应 token 上计算教师与学生下一 token 分布之间的 KL 散度作为蒸馏损失：
$$\mathcal{L}_{KD}(I, x, y) = \frac{1}{|y|} \sum_{t=1}^{|y|} D_{KL}(p_T^{(t)} \| p_S^{(t)})$$
- 最小化该目标，使量化学生模型在目标低比特表示下保持教师的多模态生成行为。

### 2.3 合成 QAT 数据管线

- **图像来源**：使用 ImageNet 训练集（1,281,167 张自然图像），保持通用性、独立于下游评估任务。
- **文本目标**：通过查询教师模型生成，保存其生成的响应序列作为蒸馏目标。
- **提示采样策略**（核心贡献之一）：
  - 以概率 $p_{temp}=0.75$ 使用指令微调模板，其余概率使用普通模板，兼顾指令跟随与预训练行为。
  - 构建 495 个人工与自动组合的通用图像理解问题池。
  - 以概率 $p_{inst}=0.7$ 添加指令块，包含回答约束、长度约束（偏向短/中长度，少量长响应）与格式约束。
  - 不引入任何下游任务数据或基准特定提示，避免对特定任务过拟合。
- **消融验证**：固定提示（"Describe the image:"）会导致生成输出多样性不足，显著损害下游任务性能；采样提示则大幅提升任务表现（图 3b）。

### 2.4 S3D8 格式

- **格式定义**：每 8 bit 存储 3 个权重，包含 1 个共享的 5-bit 质心索引和 3 个符号指示位（每权重 1 bit），即 "signed 3D 8-bit"。
- **反量化公式**：
$$\tilde{W}_{ij} = \alpha_i \cdot s_{ij} \cdot C_{q_{\lfloor i/3 \rfloor, j}, \, i \bmod 3}$$
  - $\alpha \in \mathbb{R}^n$：per-channel 缩放因子（bfloat16）
  - $s \in \{-1,1\}^{n \times k}$：per-element 符号
  - $C \in \{0,...,127\}^{32 \times 3}$：共享质心表（32 个 3 维绝对质心）
  - $q$：量化索引
  - 平均大小约 $(8/3 + 16/k)$ bit/元素。
- **质心构造**：先用 per-channel absmax 归一化权重并取绝对值，零填充后 reshape 为 3 元素向量，使用 Lloyd-Max 算法（k-means++ 初始化）最小化平方重建误差得到 32 个质心。QAT 阶段质心冻结，仅更新通道缩放、量化索引和符号。
- **硬件协同设计**（关键工程贡献）：
  - 将每个字节打包**连续的输出通道**（而非输入通道），减少融合内核中的填充和对齐逻辑。
  - 利用 Arm CPU 的 64 项表查找指令（TBL），将符号位与质心索引融合为查找索引，直接输出带符号 INT8 值。
  - 精心设计位布局（`[S2 EOR S0, S1, Q4..0, S0]`），仅需 5 条 SIMD 逻辑指令即可构造 3 个查找索引（配合置换查找表），解码 48 个元素（代码见 Listing 1、2）。
  - 解码后的 INT8 可直接用于 Arm dotprod/i8mm 扩展的高吞吐算术。

## 6. 主要结论

- S3D8 格式在 2.7 比特/参数附近提供了优于 INT、student-t、lloyd-max 标量格式的性能-压缩权衡；相比于同尺寸 INT 格式约有 22% 的额外压缩收益（在同任务性能下）。
- QAT 在极端低比特下显著优于 GPTQ 与直接投射；GPTQ 优于直接投射但差距有限。
- 提示采样策略对于无训练数据的 QAT 至关重要——固定提示会导致合成数据多样性不足，损害下游泛化。
- S3D8 的硬件协同设计使其在移动端内存带宽受限的自回归生成场景下不仅不拖慢推理，反而超越 INT8 速度；在计算受限的大 batch 场景下与 INT8 基本持平。
- 端到端结果表明，亚 3-bit VLM 压缩是资源受限设备上多模态推理的可行路径。

- **方法上的系统性**：将数值格式设计、训练流程、数据生成与硬件内核设计作为一个整体协同优化，而非孤立解决单一环节。
- **数据生成的实用性**：在无法访问原始训练数据的实际工程约束下，用教师自身生成数据，并设计了工程上简洁有效的提示采样策略（模板混合、组合提示池、指令块随机化）。
- **硬件-格式协同设计的深度**：S3D8 的位布局和查找表置换使得解码仅需 5 条逻辑指令 + 3 次查表，对 Arm SIMD 指令集的利用非常精巧，提供了完整的代码与反汇编级验证。
- **验证完整性**：不仅报告端到端任务性能，还提供了解码带宽、矩阵乘吞吐率、端到端 tokens/s 等落地指标；消融实验覆盖数据策略、格式对比、层精度分配多个维度。
- **开源实现**：提供完整量化流程与 C++ 推理实现，含自定义 safetensors 文件格式，便于复现与扩展。

## 8. 不足与局限

- **泛化性受限**：实验仅在 Llama 3.2 11B Vision Instruct 单一模型上验证，未测试其他 VLM 架构（如 Gemma 3、Qwen3-VL），结论的普适性有限。
- **硬件覆盖窄**：S3D8 解码依赖 Arm 的 64 项表查找指令（TBL），其他架构（x86、GPU、NPU）需要专门设计内核，移植成本未知。
- **评估任务范围有限**：仅使用 4 个 VQA 类基准（且均为 Llama 3.2 官方评估套件内的任务），未覆盖图像描述、开放域对话、多图推理等更广泛的多模态能力。
- **探索性不足**：固定对所有层使用统一量化格式；保留部分层为 INT8 的初步尝试未带来显著收益，但未进一步探索更细粒度的

但未进一步探索更细粒度的混合精度分配策略（如按层敏感度自适应选择比特数），这可能是进一步提升压缩率与性能权衡的潜在方向。

## 9. 未来研究方向

- **扩展至更多模型架构**：将 S3D8 与量化框架应用于 Gemma 3、Qwen3-VL 等其他主流 VLM，验证格式的架构无关性；同时探索纯文本 LLM 上的适用性，扩大方法影响面。
- **更广泛的硬件后端**：为 x86 AVX、GPU Tensor Core 以及移动端 NPU 设计对应的 S3D8 解码内核，或探索可移植的表查找替代方案，以覆盖更多部署场景。
- **细粒度混合精度**：结合层敏感度分析或自动搜索算法，为不同模块（视觉编码器、投影层、解码器各层）分配不同比特数，在固定存储预算下进一步优化性能。
- **更全面的任务覆盖**：将评估扩展到图像描述、开放域视觉对话、多图推理、指代表达理解等更多模态能力，以全面衡量亚 3-bit 压缩对 VLM 能力的影响。
- **与结构化剪枝、蒸馏协同**：探索将 S3D8 量化与权重剪枝、模型蒸馏等正交压缩技术结合，在极端压缩率下实现更优的精度-效率前沿。

## 10. 总体评价

本文在移动端 VLM 部署这一实际工程问题上做出了扎实且有影响力的贡献。其核心价值不仅在于提出了 S3D8 这一新颖的数值格式，更在于展示了**格式设计、数据生成、量化训练与硬件内核的联合优化**这一方法论范式。在"无原始数据 + 低于 3-bit + 移动 CPU 高效执行"的三重约束下，作者给出了完整的、可复现的解决方案，并在任务精度与运行时性能两个维度上提供了详实的实验证据。尽管在模型泛化性、硬件覆盖与任务广度上仍有局限，但该工作为资源受限设备上的多模态模型部署提供了一个高质量的基线，也为后续研究者指明了若干明确且有价值的探索方向。对于工业界移动端 AI 部署工程实践而言，本文的方法直接可用；对于学术界而言，其"数据-格式-硬件"协同设计的思路具有方法论上的启发意义。

**核心贡献一览**：

| 维度 | 贡献 |
|------|------|
| 数值格式 | S3D8：每 8 bit 存储 3 个权重（≈2.7 bit/参数），含共享质心表 + 逐元素符号位 |
| 数据策略 | 无训练数据的合成多模态 QAT 数据管线，含模板混合与组合式提示采样 |
| 硬件设计 | Arm TBL 查表指令驱动的超低开销反量化内核，解码 48 元素仅需 5 条逻辑指令 |
| 系统验证 | 端到端压缩至 3.7 GB（含 8-bit 激活），Pixel 8a 上实现 3.8 tokens/s 解码，精度较 bfloat16 下降仅 0.083 |

**一句话总结**：本文通过 S3D8 格式与无数据 QAT 流程的协同设计，证明了在移动端 Arm CPU 上以约 2.7 bit/参数实现高性能视觉语言模型推理是完全可行的，为该领域的落地部署提供了标杆性的方案。
