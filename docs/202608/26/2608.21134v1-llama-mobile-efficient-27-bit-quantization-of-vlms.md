## 摘要
在移动设备上部署视觉语言模型（VLM）因其巨大的内存和计算需求而具有挑战性。我们提出了一种在资源受限硬件上对VLM进行量化以实现高效推理的框架。我们的方法结合了一个量化流程，该流程使用模型自身生成训练数据，且无需访问训练设置，并采用一种新颖的每参数2.7位格式，支持在Arm CPU上高效执行。我们通过将Llama 3.2 11B Vision Instruct模型压缩至3.7 GB（带8位激活）来验证我们的方法，同时在一组标准视觉问答任务上保持强劲性能。

## Abstract
Deploying vision-language models (VLMs) on mobile devices is challenging due to their significant memory and compute requirements. We present a framework for quantizing VLMs for efficient inference on resource-constrained hardware. Our approach combines a quantization pipeline that uses the model itself to generate training data and does not require access to the training setup, with a novel 2.7-bit-per-parameter format supporting efficient execution on Arm CPUs. We validate our approach by compressing the Llama 3.2 11B Vision Instruct model to 3.7 GB with 8-bit activations, preserving strong performance on a set of standard visual question answering tasks.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉语言模型（VLM）如 Llama 3.2 Vision、Gemma 3 等参数量大、计算密集，难以直接部署到内存和算力受限的移动设备上。虽然量化是降低模型内存占用和提升推理效率的有效手段，但**激进的低比特量化**（尤其低于 3 比特/参数）在实际中仍面临两大挑战：
  1. **数值格式的选择**：需要找到在极低比特下仍能保持模型性能的压缩格式。
  2. **量化流程的有效性**：量化感知训练（QAT）效果好，但高度依赖训练数据分布，而实际部署场景常常**无法访问原始训练数据**。

## 2. 论文提出的方法论

### 2.1 总体架构

论文提出的框架包含三个核心组件：
1. **合成数据生成**：利用模型自身生成 QAT 所需的训练数据，不依赖原始训练集。
2. **量化感知训练（QAT）**：以原始全精度模型为教师，量化模型为学生，通过知识蒸馏最小化两者输出的 KL 散度。
3. **S3D8 数值格式**：针对 Arm CPU SIMD 指令集设计的 2.7-bit/参数权重格式，支持高效解码与推理。

### 2.2 合成数据生成管线

- **图像来源**：使用 ImageNet 训练集（约 128 万张自然图像），与下游评估任务无关，避免过拟合。
- **文本目标**：以教师模型（原始 bfloat16 模型）对图像-提示对生成的响应作为蒸馏目标；采样温度 0.6，top_p=0.9，最大序列长度 512。
- **提示采样策略**（核心创新）：
  - 以概率 p_temp=0.75 应用指令模板，其余用普通模板，兼顾指令微调行为与预训练行为。
  - 从 495 个通用图像理解问题的提示池中随机采样（如"Describe the image."或由 action/target/audience/style 组合生成）。
  - 以 p_inst=0.7 概率附加指令块（含遵循性、长度、格式约束），长度约束偏向短/中回答（短 40%、中 38%、长 22%）。
- **关键发现**：固定提示（如单一"Describe the image:"）导致生成文本多样性不足，显著损害下游任务性能。

### 2.3 量化感知训练目标

- 以教师和学生在每个解码步骤的下一词元分布之间的 **KL 散度**作为蒸馏损失，只计算在教师生成回复上的损失。
- 梯度通过量化器使用**直通估计器（STE）** 传播。
- 学习率按比特数缩放：$\eta = 2^{-(b+14)}$，b 为每参数平均比特数。

### 2.4 S3D8 格式设计

- **核心思想**：每个字节存储 3 个权重——5 位共享质心索引 + 3 位符号指示位。解码时通过 Arm 64 项表查找指令（TBL）直接得到带符号的 INT8 值。
- **数学表示**：$\tilde{W}_{ij} = \alpha_i \cdot s_{ij} \cdot C_{q_{\lfloor i/3 \rfloor}, j \bmod 3}$，其中 $\alpha$ 为逐通道缩放、$s$ 为逐元素符号、$C$ 为 32×3 的质心表、$q$ 为量化索引。
- **质心训练**：先按输出通道绝对最大值归一化，取绝对值后使用 Lloyd-Max 算法（k-means++ 初始化）拟合 32 个质心；QAT 期间质心冻结，仅更新缩放、索引和符号。
- **物理布局优化**：
  - 每个字节打包**不同输出通道**的权重，避免约简轴上的对齐/填充问题。
  - 位布局设计为仅需 5 条逻辑指令即可生成 3 个查找索引，解码 48 个元素。
  - 查找表直接包含符号信息，避免解码后额外处理符号。
  - 端点效率：对于足够大的矩阵，平均每元素约 8/3 + 16/k 比特。

- **S3D8 格式优势显著**：在 2.68 bpp 下，S3D8 平均任务退化仅 0.083（0.744→0.661），显著优于同尺寸的 INT（0.347）、student-t（0.565）和 lloyd-max（0.436）。在相同任务性能下，S3D8 比 INT 格式多约 22% 的压缩。
