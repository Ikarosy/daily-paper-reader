## 摘要
近期无训练的后训练量化方法通过闭式残差补偿恢复模型精度。为限制额外的模型存储开销，若干现有方法通过拟合优度对层选择进行门控，仅保留那些补偿能产生正残差拟合分数的层，并丢弃其余层。本文表明，在低比特W4A4设置下，这种门控机制无法区分难以预测的量化误差与数值求解器失败。秩亏的输入激活会产生严重病态或数值奇异的Gram矩阵，导致闭式求解器不稳定并产生虚假的负拟合分数。因此，现有拟合优度门控会错误地将受影响的层分类为不可补偿并将其丢弃。然而，当使用数值稳定的求解器计算补偿时，许多被丢弃的层仍能提供显著的误差恢复。为解决此问题，我们提出一种无参数的截断伪逆求解器，在求逆之前移除坍缩方向。在ViT-B的W4A4设置下，我们的无训练方法达到81.42%的top-1准确率，优于先前的后训练方法和基于微调的基线。结合联合低秩与量化压缩，所提方法在54.7 MB下达到80.26%准确率的可部署操作点，在模型大小与准确率之间提供了良好平衡的权衡。

## Abstract
Recent training-free post-training quantization methods restore model accuracy through closed-form residual compensation. To constrain additional model storage overhead, several existing methods gate layer selection by goodness-of-fit, retaining only those layers whose compensation yields a positive residual fit score and discarding the rest. In this paper, we show that, under the low-bit W4A4 setting, this gating mechanism fails to distinguish poorly predictable quantization error from numerical solver failure. Rank-deficient input activations yield severely ill-conditioned or numerically singular Gram matrices, causing the closed-form solver to become unstable and produce spuriously negative fit scores. Consequently, existing goodness-of-fit gates misclassify affected layers as uncompensable and discard them. Many of these discarded layers can nevertheless provide substantial error recovery when their compensation is computed using a numerically stable solver. To address this problem, we propose a parameter-free truncated pseudoinverse solver which removes collapsed directions prior to inversion. On ViT-B with the W4A4 setting, our training-free method achieves 81.42\% top-1 accuracy, outperforming prior post-training methods and fine-tuning-based baselines. Combined with joint low-rank and quantization compression, the proposed method reaches a deployable operating point of 80.26\% accuracy at 54.7 MB, providing a well-balanced trade-off between model size and accuracy.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体框架

论文提出一个三层逐层（layer-wise）补偿框架，包含三个组件（对应Algorithm 1和2）：

1. **逐层补偿**（Layer-wise Compensation）
2. **数值稳定求解**（Numerically Stable Solving）
3. **双轴压缩**（Dual-axis Compression）

### 2.2 逐层补偿

- 对Transformer块内的**每个独立线性层分别挂载补偿器**（而非每块共享一个），共4个线性层各配一个独立补偿器。实验表明独立补偿比块级补偿带来+3.1%的准确率提升。
- 部署形式：`output = Q(x) + (x · A) · B + b`，其中A、B为低秩因子。
- **顺序补偿策略**：由于补偿某层会改变下游层的实际输入，算法采用逐层依次补偿的方式——先补偿第ℓ层并立即将补偿后的版本接回模型，再捕获下一层的真实输入去求解该层参数，确保校准阶段与部署阶段输入分布一致。

### 2.3 数值稳定求解（核心贡献）

**问题建模**：
- 量化误差 E = Y_fp − Y_q；补偿目标为最小化 ∥XW_c + b_c − E∥²。
- 吸收偏置后解为：`[W_c; b_c] = G⁻¹ X̃^T E`，其中 G = X̃^T X̃ 为Gram矩阵。

**失效机制**：
- G对称半正定，逆为 G⁻¹ = Σ (1/λᵢ) vᵢvᵢᵀ。W4A4激活量化将原本略有差异的输入维度压缩为几乎相同的方向，降低有效秩，使层越过坍缩阈值，近零特征值导致其倒数趋于无穷，补偿参数爆炸、整体崩溃。
- 坍缩的直接指纹是**秩亏**：最小特征值在float32精度下与零不可区分（落入 ≈ ε·λ_max 的噪声底限内），表现为补偿参数范数爆炸、R²急剧为负。
- 论文特别区分：**大条件数（κ可达10⁷–10⁹）并不单独预测坍缩**；坍缩的充分条件是Gram矩阵数值奇异。

**截断伪逆（Truncated Pseudoinverse）**：
- 设置阈值 τ = rcond · λ_max，对特征值截断：λᵢ > τ 时取倒数，λᵢ ≤ τ 时直接置零。
- 解变为 `[W_c; b_c] = V Λ⁺ V^T X̃^T E`。
- 被忽略的方向不包含可靠信息，丢弃它们不损害有效补偿但消除了数值爆炸。
- 截断伪逆保留R² ≥ 0保证：增广输入中截距方向的特征值随样本数缩放，始终逃过截断，常数预测器仍在可行集内。
- **关键对比**（与岭回归的差异）：岭回归对所有方向做收缩（1/λ → 1/(λ+α)），而伪逆只对坍缩方向置零、对保留方向不收缩（无偏）。实验表明截断伪逆（81.42%）与岭回归（81.64%）精度几乎相同，证明增益来自**丢弃坍缩方向**而非收缩效应。

### 2.4 低秩与量化双轴压缩

**轴1：激活感知低秩分解**：
- 近似 W_c ≈ A·B（秩r）。与标准SVD截断最小化参数空间误差不同，论文最小化**输出空间误差**：min ∥X(W_c − W_r)∥² s.t. rank(W_r) ≤ r。
- 解为：W_r = G^(−1/2) T_r(G^(1/2) W_c)，即对Gram矩阵白化后再做SVD截断。白化使保留的秩集中在激活实际通过的方向。
- G^(1/2)和G^(−1/2)由截断的G特征分解计算，使用与稳定求解器相同的rcond阈值，保证即使在数值奇异层上白化仍有定义。

**轴2：补偿因子量化**：
- 对低秩因子A和B施加**通道级对称量化**至int8/int4，每列计算缩放因子s = max|列|/q_max，存储整数矩阵加fp16标量。
- 偏置b_c保持全精度不量化。两轴正交、可组合。

## 6. 论文的主要结论与发现

- **核心发现一**：W4A4设置下闭式补偿求解器对秩亏激活结构本质上脆弱，激活量化将这脆弱性放大为数值崩溃，且崩溃层被R² > 0门控误判为“不可补偿”而丢弃。
- **核心发现二**：被丢弃的层恰恰包含补偿价值最高的层（ViT-B的b0.fc2移除损失1.05%），现有门控机制“丢弃了本应保留的层”。
- **核心发现三**：秩亏（而非单纯大条件数）是崩溃的触发器；该机制跨CNN和Transformer架构通用。
- **核心发现四**：截断伪逆带来的增益源于数值稳定性而非收缩/正则化效应。
- **主结果**：ViT-B/W4A4/ImageNet上无训练达到81.42% ± 0.06 top-1准确率，超越QwT（76.3%）、QwT*微调基线（78.5%）、QwT-v2（75.6%）和IGQ-ViT（79.3%）。
- **压缩结果**：双轴压缩后在54.7 MB下保持80.26% ± 0.11准确率，同时优于完全补偿的QwT（76.3%/59.1MB）和极轻量QwT-v2（75.6%/45.6MB），比需要微调的QwT*高出1.76个百分点且体积小4.4MB。
- **分配策略发现**：补偿预算应按全局规模均匀分配；将高秩分配策略完全反转为“重要性低者高秩”仅造成0.02%的差异，说明层重要性不预测秩敏感性。
- **压缩策略发现**：在固定体积约束下，高秩+更激进的量化优于低秩+温和量化——补偿受益于保留的子空间维度而非单参数精度。
