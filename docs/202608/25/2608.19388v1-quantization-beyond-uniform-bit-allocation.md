## 摘要
量化是处理现代模型生成的嵌入规模不断增长的基本技术。现有的量化方案在很大程度上与嵌入无关，并在各维度上均匀分配位。然而，近期模型产生的嵌入具有显著的几何结构。在这项工作中，我们研究了在固定内存预算下，可变位分配方案能否提高量化质量。我们提出了一个简单的可变位分配框架，将嵌入划分为连续的桶，并在它们之间非均匀地分配存储。通过贪婪分配策略，我们为乘积量化（PQ）和标量量化（SQ）实例化该框架。我们对已知具有Matryoshka属性（MRL）的嵌入进行了一系列实验，并一致观察到在相同存储预算下，非均匀分配优于均匀基线。最大的改进出现在低位区域，其中均匀分配对MRL嵌入尤其低效。在相同的压缩率下，可变分配使PQ的召回率提高多达8%，SQ的召回率提高多达18%。我们的结果为大规模检索系统的结构感知压缩和索引技术提出了新方向。

## Abstract
Quantization is a fundamental technique to handle the growing sizes of embeddings generated by modern models. Existing quantization schemes are largely embedding agnostic and allocate bits uniformly across dimensions. However, recent models produce embeddings with significant geometric structure. In this work, we investigate whether a variable bit allocation scheme can improve quantization quality under a fixed memory budget. We propose a simple variable bit allocation framework that partitions an embedding into contiguous buckets and allocates storage non-uniformly across them. Using a greedy allocation strategy, we instantiate this framework for both Product Quantization (PQ) and Scalar Quantization (SQ). We perform a series of experiments on embeddings known to have the Matryoshka property (MRL), and consistently observe that non-uniform allocations outperform uniform baselines at identical storage budgets. The largest improvements occur in the low-bit regime, where uniform allocation is particularly inefficient for MRL embeddings. At the same compression rates, variable allocation improves recall by up to 8\% for PQ and up to 18\% for SQ. Our results suggest a new direction for structure-aware compression and indexing techniques for large-scale retrieval systems.

## 1. 核心问题与研究动机

- **背景**：随着现代ML系统规模扩大，嵌入向量维度从数百到数千不等，如3000维向量单条占用12KB磁盘，十亿级数据集需数TB存储，导致最近邻检索面临严重的可扩展性挑战。
- **核心问题**：现有量化方案（如PQ、SQ）是“嵌入不可知”的，在所有维度上均匀分配比特预算，忽略了嵌入的内在几何结构。特别是，许多现代嵌入模型（如OpenAI text-embedding-3-large、Cohere embed-v4等）具有**Matryoshka属性（MRL）**，即前导维度承载了不成比例的结构信息。
- **核心假设**：在固定内存预算下，将更多比特分配给前导维度，而非均匀分配，能够显著提升量化质量。
- **整体意义**：这是首个系统性地探索“感知嵌入结构”的非均匀比特分配框架，为大规模检索系统中的结构感知压缩与索引提供了新方向。

## 2. 方法论

- **核心思想**：将嵌入划分为连续桶（bucket），通过贪心搜索为每个桶分配不同比特预算，从而利用MRL嵌入的方差衰减特性（前导维度方差更大、信息更丰富）。
- **关键观察依据**：论文实证发现MRL嵌入具有显著的“方差层级”——维度索引增大时，滚动窗口方差明显下降（图2）。这成为非均匀分配的几何代理。
- **贪心分配框架（Algorithm 1）**：
  1. 将嵌入的D维划分为K个连续桶，每个桶大小为dₖ。
  2. 初始化均匀比特分配向量 b⁰。
  3. 每次迭代中，逐一尝试为每个桶增加固定步长δ字节，在验证集上评估候选配置的召回率。
  4. 选择边际召回增益最大的桶，永久分配该δ字节。
  5. 重复直至达到目标内存预算。
- **贪心乘积量化（Greedy PQ）**：每个桶内根据分配的字节数（每个子向量用256中心码本）拆分为对应数量的连续子向量，余数维度向前端子向量前置分配，独立训练k-means码本。
- **贪心标量量化（Greedy SQ）**：支持0/2/4/8比特的码宽选择，基于总比特预算先确定基线宽，再用均匀步长策略将部分维度升级到更高级别；0比特对应直接丢弃（剪枝）该维度，1比特被显式避免（因会破坏单峰分布）。

## 3. 实验设计

- **数据集**：6个BEIR标准数据集——MS Marco（500k基向量）、DBpedia-Entity（500k）、Quora（500k）、FiQA（57,638）、SciDocs（25,657）、SciFact（5,183）。较大数据集截断至前50万条以确保可复现，查询使用标准评测划分。
- **嵌入模型**：OpenAI text-embedding-3-large（3072维）与Cohere embed-v4（1536维），均生成全维嵌入。
- **量化方法**：对比PQ与SQ两种量化技术在均匀分配与贪心非均匀分配下的表现。
- **评测指标**：100-recall@100，通过暴力L2精确距离在解量化后的数据库向量上计算，隔离了量化误差本身，排除了近似索引带来的干扰。
- **预算设置**：从约0.17 bpd到1.0 bpd，步长1/12 bpd。所有嵌入均划分为8个等大小桶。
- **基线**：
  - 均匀比特分配的PQ / SQ；
  - 根据比特预算直接截断前导维度的简单压缩（见表2）。
- **超参数**：训练码本/缩放因子时随机采样10%语料向量；贪心搜索起始为均匀分配（te3-l：每桶8字节；embed-v4：每桶4字节），步长分别为8字节和4字节，运行40次迭代到1 bpd目标。

## 6. 主要结论与发现

- **非均匀分配一致优于均匀分配**：在相同存储预算下，非均匀分配在所有数据集/模型/量化方法的组合上都获得正向收益，无一例外。
- **收益幅度**：PQ最大相对提升约8%，SQ最大相对提升约18%（100-recall@100）。SQ的收益更显著，且与其更激进的不对称分配策略一致。
- **低比特率区域是最大收益区**：在sub-1 bit（尤其sub-0.5 bit）区域，均匀分配对MRL嵌入明显低效，非均匀分配在最需要压缩的场景下获益最大；在接近1 bpd时收益递减（因为均匀基线本身就已有很高召回）。
- **最优分配符合MRL直觉**：贪心发现的分配方案总是集中更多比特在前导桶，后向桶的比特递减，与方差衰减模式高度吻合（图3）。OpenAI嵌入的方差层级更分明，其收益也更高。
- **简单截断不是答案**：仅截断前导维度的基线方法在高压缩率下召回率很低（如表2所示），变位分配比简单截断显著更好。

## 7. 方法亮点

- **简单有效**：仅通过引入“可变位分配”一个概念，就可在无需修改码本训练算法的情况下提升量化质量，实用性强。
- **后训练量化**：无需重新训练或微调嵌入模型，部署成本低，符合工业界实际使用习惯。
- **与MRL属性高度契合**：虽然算法本身不显式利用MRL，但自动学到了符合MRL直觉的分配模式，验证了“结构感知压缩”这一方向的有效性。
- **框架通用性**：可同时适配PQ和SQ两种最主流量化范式，且可推广到其他量化方法。
- **诚实且干净的评价协议**：暴力L2搜索隔离量化误差，避免与索引误差混淆；公开代码（DiskANN分支），可复现性良好。

## 8. 不足与局限

- **贪心算法效率低**：迭代候选评估开销大，尤其是PQ每步需重新训练码本（尽管有缓存），在大数据集/大维度下不实用，难以扩展到更多桶或更高预算。作者承认这不是实用方案，需设计更高效的分配算法。
- **缺乏数学定义**：论文依赖经验性方差作为MRL的代理，但MRL嵌入本身缺乏严格的数学表征，限制了理论的深化和最优分配的闭合形式推导。
- **实验覆盖有限**：仅测试了两个嵌入模型（OpenAI与Cohere）、8个固定桶、一个召回阈值（Recall@100）和L2距离；未覆盖更多模型、桶数消融、更多相似度度量、端到端ANN索引（而非暴力搜索）场景。
- **子空间独立假设的局限**：PQ假设各子空间独立，而真实高维数据中维度间往往存在相关性；非均匀分配并未显式建模这类相关性。
- **SQ位宽选择的离散跳跃**：SQ的允许宽度仅为{0,2,4,8}，0比特即“丢弃”维度，信息丢失可能过于激进，且2比特到4比特的跨越在分配时也较为粗暴。
- **系统工程挑战**：动态大小数据类型的存储导致内存访问不对齐、SIMD利用效率下降，尤其在需要对齐和并发场景下实现难度大；论文未评估实际端到端系统的延迟与吞吐。
- **缺乏消融研究**：未系统研究桶数量、步长、初始化策略、候选搜索策略等对最终性能的影响。
