## 摘要
仅权重的训练后量化（PTQ）使得在严格内存预算下部署大型语言模型成为可能，但在2-3比特下精度往往崩溃。现有的免反向传播PTQ优化器存在两个局限性：分组决策忽略了剩余连续后缀可以吸收的修正，且离散细化通常保持仿射量化网格固定。我们提出SCHUROPT，它解析地消除后缀的最优连续响应，产生具有Schur补曲率的精确分组二次形式，然后交替进行闭式逐行缩放/零点重拟合与整数码上的坐标下降。在固定GPTQ目标下，SCHUROPT在2比特Qwen3-4B上将平均零样本精度提高了11.88个百分点（pp）。然而，在更高精度下，更紧的重构并不一致地改善端到端模型指标。因此，SCHURQUANT将SCHUROPT与量化前缀教师重构、参考权重正则化、残差加性目标以及教师决策令牌加权相结合。在八个Llama和Qwen模型上，SCHURQUANT在评估的免反向传播PTQ基线中取得了最高的平均零样本精度，在2比特下比最强基线高出9.65 pp。

## Abstract
Weight-only post-training quantization (PTQ) enables the deployment of large language models under tight memory budgets, but accuracy often collapses at 2-3 bits. Existing backpropagation-free PTQ optimizers have two limitations: group decisions ignore the correction that the remaining continuous suffix can absorb, and discrete refinements typically keep the affine quantization grid fixed. We introduce SCHUROPT, which analytically eliminates the suffix's optimal continuous response, yielding an exact groupwise quadratic with Schur-complement curvature. It then alternates closed-form row-wise scale/zero-point refitting with coordinate descent over integer codes. With the GPTQ objective fixed, SCHUROPT improves mean zero-shot accuracy on 2-bit Qwen3-4B by 11.88 percentage points (pp). At higher precision, however, tighter reconstruction does not consistently improve end-model metrics. SCHURQUANT therefore combines SCHUROPT with quantized-prefix teacher reconstruction, reference-weight regularization, residual-add targets, and teacher-decision token weighting. Across eight Llama and Qwen models, SCHURQUANT achieves the highest mean zero-shot accuracy among the evaluated backpropagation free PTQ baselines, outperforming the strongest baseline by 9.65 pp at 2 bits.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大规模语言模型（LLM）的部署日益受限于内存容量与带宽，而非算术吞吐量，在边缘设备上尤为突出。仅权重的后训练量化（weight-only PTQ）通过少量校准数据将预训练权重转换为低精度，无需重新训练，是解决部署内存压力的关键手段。
- **核心问题**：常规PTQ在2–3比特的超低比特量化下，困惑度（PPL）和下游任务精度会急剧崩溃。现有PTQ方法可分解为两个独立部分：
  1. **目标函数（objective）**：决定最小化何种误差（如输出重构损失、考虑前一层的激活误差等）。
  2. **优化器（optimizer）**：决定目标函数如何在整数网格上求解（如GPTQ的逐列舍入与误差传播）。
- **现有优化器的两大缺陷**：
  1. **分组决策忽略连续后缀的修正能力**：现有的坐标下降方法在评估当前量化分组时，使用原始曲率块 Gcc，隐含地将尚未量化的连续后缀视为固定，但实际上后缀可以吸收一部分量化误差。
  2. **离散细化通常固定仿射量化网格**：尺度（scale）和零点（zero-point）往往在初始化后不再更新。
- **论文整体思路**：提出 **SCHUROPT**——通过Schur补（Schur complement）解析地消除连续后缀的最优响应，得到条件化后的精确分组二次目标，再用闭式解更新尺度/零点，并用坐标下降优化整数码。进一步发展出 **SCHURQUANT**，将SCHUROPT与目标函数增强（教师重建、参考权重锚定、残差加性目标、教师决策令牌加权）结合，显著提升低比特量化精度。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 统一问题形式（充分统计量）

- 优化目标为（式7）：
  L(W) = (1/2)‖(WX − Y)Ω^(1/2)‖_F² + (λ/2)‖W − W_ref‖_F²
- 展开得到充分统计量（式8）：
  G = XΩXᵀ + λI，C = YΩXᵀ + λW_ref
- 目标化为（式9）：L(W) = (1/2)tr(WGWᵀ) − tr(CWᵀ) + const
- 该接口使优化器与具体目标解耦：GPTQ目标、QEP式教师重建、残差加性目标等都只需提供不同的 (G, C)。

### 2.2 Schur补条件化（核心创新）

- 将当前量化分组记为 Wc，后缀记为 Wr。设曲率矩阵分块为 G = [[Gcc, Gcr], [Grc, Grr]]。
- **命题1（Schur约简）**：固定已量化前缀 WF，解析消除后缀 Wr 的最优连续响应后，局部等价目标为：
  L_local(Wc) = (1/2)tr(WcSWcᵀ) − tr(TWcᵀ) + const
  其中：
  S = Gcc − Gcr Grr⁻¹ Grc
  T = Ceff_c − Ceff_r Grr⁻¹ Grc
  Ceff_c = Cc − WF GFc，Ceff_r = Cr − WF GFr
- **直觉**：Gcc是当前分组的直接曲率，Gcr Grr⁻¹ Grc是连续后缀能吸收的部分，因此 S ⪯ Gcc，即条件化后的有效曲率比原始块更小、更精确。
- **高效计算**：维护 P = (G[t:,t:])⁻¹ 的分块，利用块逆恒等式：
  - S = Pcc⁻¹
  - Grr⁻¹ Grc = −Pcrᵀ S
  - P_next = Prr − Pcrᵀ S Pcr
  每块仅需一次 g×g 矩阵求逆和 O(m²g) 更新，而非重新做 O(m³) 分解。

### 2.3 精确的行级量化器参数更新

- 量化当前分组为 qi = ai(zi − oi·1)，其中 zi 为整数码、ai 为尺度、oi 为零点（对称量化时 oi=0）。
- 由于式(15)按输出行分离，所有行可并行更新。
- **命题2（行级尺度/零点闭式更新）**：固定整数码 zi 和候选零点 o，最优尺度为：
  a⋆i(o) = max(di(o)/Ai(o), εa)
  最优零点通过枚举 2^b 个候选（b 为位宽）得到，代价极低。

### 2.4 整数码的坐标下降

- 固定 (a, o) 后，对每个坐标 (i,j)，从 2^b 个候选级别中选取使局部目标最小的值（式17）：
  ℓi,j(v) = (1/2)Sjj v² + (Φi,j − qi,j Sjj − ti,j)v
- 维护状态 Φ ← QS，每次坐标更新后用秩一操作 Φi,: ← Φi,: + Δi Sj,: 更新状态，单次扫描复杂度为 O(dout·g·(2^b + g))。

### 2.5 目标函数增强（SCHURQUANT）

- **参考权重锚定（Reference-weight anchor）**：加入 (λ/2)‖W − W_ref‖_F²，贡献 λI 到 G、λW_ref 到 C。
- **残差加性目标（Residual-add target）**：用残差流输出 Y = h + f(h) 而非仅投影局部输出作为教师目标。
- **教师决策令牌加权（Teacher-decision token weighting）**：逐层比较当前量化前缀模型和干净教师模型在每个校准位置上的 top-1 预测，翻转位置赋予 ρ 倍的权重（ρ=8），并结合残差大小进行归一化。

### 2.6 完整算法流程（Algorithm 1）

1. 输入充分统计量 (G, C)、参考权重 W_ref、位宽 b、分组大小 g、细化轮数 R、阻尼系数。
2. 初始化 P ← (G + ε_damp·diag(G)·I)⁻¹，工作矩阵 W ← W_ref。
3. 逐块处理输入列（t = 0, 1, ..., din/g − 1）：
   - 分块 P 得到 S ← Pcc⁻¹，K ← −PcrᵀS。
   - 计算有效线性项 T。
   - 用行级 min–max 初始化 (Z, a, o)。
   - 重复 R 轮：更新 (a, o) → 坐标下降扫描 Z。
   - 最终重拟合 (a, o)，写入当前量化分组。
   - 更新 P ← Prr − Pcrᵀ S Pcr。
4. 返回量化后的权重矩阵。
- 算法保证每步更新不增加 L_local，有限码空间保证收敛到坐标级不动点。当 g=1、固定 (a,o)、仅做最近舍入时，退化为GPTQ。

## 6. 论文的主要结论与发现

1. **Schur条件化是优化器的核心贡献**：在固定GPTQ目标、2比特Qwen3-4B上，SCHUROPT将PPL从258.96降至81.95，平均零样本精度从36.77%提升至48.65%（**+11.88 pp**）。
2. **2比特下优势巨大**：SCHURQUANT在全部8个模型上平均零样本精度为50.83%，超过最强基线QEP（41.18%）**9.65 pp**，超过GPTQ **11.58 pp**。
3. **3比特下仍保持优势**：平均65.11%，比QEP高2.16 pp，在8个模型中7个最佳（Llama3-8B上比GPTQ高6.05 pp）。
4. **4比特下优势减弱**：平均67.54%，仅比最强基线高0.68 pp——在更细粒度网格上，最近舍入与更优离散分配的差距自然缩小。
5. **PPL与下游精度并非总一致**：如3比特Qwen3-8B，GPTQ的PPL更低（10.92 vs 11.16），但SCHURQUANT的零样本精度反而更高（+2.33 pp），说明困惑度不应作为唯一评估标准。
6. **目标函数增强的必要性**：在高精度下，更紧的重构并不一致地改善最终模型指标——仅优化目标（SCHUROPT）在3/4比特下PPL反而恶化，需结合目标增强（SCHURQUANT）才能获得最佳综合表现。
7. **收敛快速**：细化轮数 R=4 后PPL基本饱和，R=16 为稳定选择。
